# Count a blast's files from its callers and its file's includers apart

- **Status:** accepted
- **Date:** 2026-10-17
- **Updated:** 2026-10-17
- **Initiative:** `03-code-graph`
- **Governs:** `crates/kartta-graph/src/analyze.rs` (`includers_within`, `Blast::affected_files`)
- **Pinned by:** `crates/kartta-graph/tests/graph/analyze.rs`
  (`the_blast_counts_the_callers_reached_by_depth_and_the_files_around_them`)

A change to a symbol touches the files of the callers its blast reaches and the files that include its own file. The
two are found apart, the includers a depth at a time, so the count does not depend on the order the callers' walk
visits files.

## Decision

- `affected_files` counts the files, other than the symbol's own, that hold a caller the walk of
  [ADR 3.22](/design-docs/adr/3.22-change-impact-analysis.md) reached, or that include the
  symbol's file within the walk's depth.
- The includers are found one depth at a time, as `dependents` finds them
  ([ADR 3.19](/design-docs/adr/3.19-file-dependents.md)), and not through the
  visited set of the callers' walk, so a file that holds a caller is still followed to its own includers.
- A segment finds its file's includers once and every symbol's blast counts against them.

## Why

A file that holds a reached caller and also includes the symbol's file is one file, and its own includers depend on the
symbol's header whichever way the walk met it. Counting through the callers' visited set makes the count depend on the
order of the walk.

## Consequences

A file counts once whether it holds a caller, includes the file, or both; the count says how many files, not which.
Accepted.

## Rejected

- **Includers found depth first, through the callers' visited set** — the count depends on the order of the walk: it
  counted fewer files than the includers within the bound for 1,037 symbols on the C++ game-engine tree (2026-10-17).

## Revisit if

A consumer needs the affected files listed, not counted, which would make the two sets worth keeping apart in the
answer. Not asked for.
