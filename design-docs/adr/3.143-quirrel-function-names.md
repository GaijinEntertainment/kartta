# Name a Quirrel function value by its binding

- **Status:** accepted
- **Date:** 2026-10-16
- **Updated:** 2026-10-23
- **Initiative:** `03-code-graph`
- **Governs:** `crates/kartta-lang-quirrel/src/walk.rs` (`function_value`, `value_binding`, `module_table_name`,
  `data_field`, `class_name`, `assignment_target`, `is_squirrel_extends`)
- **Pinned by:** `crates/kartta-lang-quirrel/tests/extract.rs`
  (`a_function_value_takes_its_binding_name_before_its_own`,
  `a_module_table_owns_its_declared_functions_and_no_other_table_does`,
  `an_unbound_function_value_gives_its_calls_and_uses_to_the_function_around_it`,
  `the_squirrel_extends_keyword_is_no_use_and_its_base_is_one`)

Most Quirrel functions are values: a table slot, a `let`, the target of `<-`. A caller writes the binding's name, so
that name is the symbol's, and a function value with no binding names no symbol, its calls and uses going to the
function around it. A name only a binding gives is a guess where the binding is not the one callers reach.

## Decision

1. **A function value takes the name of its binding:** a table slot, a `let` or `local`, or the target of an `=` or
   `<-`, `hud.draw` or `let build = function() {...}`. A function declared with a name of its own keeps it, unless a
   binding names it first.
2. **Owners.** A member of a named or bound class is a method of the class. An assignment to a field access binds a
   method of the whole receiver expression as written, `gui.Widget.build` one of `gui.Widget`; a computed target binds
   nothing. A table that a file-scope `let` or `local` binds is a module table: a function it declares,
   `let t = { function f() {} }`, is the method `t.f`, and a function one of its slots binds, `{ f = @() 1 }`, stays a
   free function. A table anywhere else owns nothing. A class expression takes the name of the slot, the declaration or
   the identifier it is bound to, and one bound to a field access or passed as a value stays anonymous.
3. **Fields.** A data slot with a plain name, of a class or of a module table, is a field of that owner; a computed
   `[k] = v` or quoted `"k": v` slot names no field. A non-function file-scope `let`, `let TOP = 1`, declares no
   symbol.
4. **A function value with no binding and no name of its own** names no symbol. Its calls and uses belong to the
   innermost function around it, and to the file only at the top level.
5. **Bases.** `class C(Base)` names `Base` as its parent. Squirrel's `class C extends B {}` is no Quirrel, and its
   grammar reads it as names inside an ERROR: an `extends` there records nothing, and the base stays a use. Outside an
   ERROR, `extends` is a name like any other.

## Why

- The name a caller writes is the binding's, so a symbol named any other way is one no call meets.
- A function a module table declares is reached as `t.f()`, and the same name kept free bound every bare call of it to
  a namesake: every bare `min()` of the game-engine tree bound the `Math.min` of the compiler's test data.
- A module returns its table, and an importer calls the table's slots by the bare names a `from` import takes, which
  reach no member of a table, so a slot-bound function stays free.
- A file-scope call has its file as the caller
  ([ADR 3.112](/design-docs/adr/3.112-file-scope-names.md)), so a lambda that a named function returns
  or passes credited the file and left the function without its callees: 52,788 calls of 3,399 scripts on the
  game-engine tree
  (2026-10-23).

## Consequences

- A call inside a nameless value binds where the same call shape binds inside a function, wrong tiers included: of 60
  sampled pairs the change gained, 8 callees were wrong. Accepted.
- A module variable declares no symbol, so its reads bind nothing. Naming the about 35,000 non-function file-scope
  declarators of that tree is a decision of its own.

## Rejected

- **A function value named by its own name or by its position** — the name no caller writes, so calls never meet it.
- **A module table that owns its slot-bound functions too** — loses the bare calls an importer makes of a module's
  API, about 110 right pairs on that tree, for 358 pairs at 25 of 30 sampled right.
- **A table member owned but kept a free function in kind** — binds exactly as a method does, since the owner and not
  the kind keeps a bare call away.
- **No use for any name inside an ERROR** — drops the base of `class C extends B` with the keyword, and the uses of the
  compiler's deliberately broken test scripts.

## Revisit if

Importers reach a module's slots through the table rather than through `from` imports' bare names. Held with moderate
confidence: the share was sampled, not counted.
