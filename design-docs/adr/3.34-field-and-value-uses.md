# Record each read and write of a field or a value, and bind it when a query asks

- **Status:** accepted
- **Date:** 2026-10-18
- **Updated:** 2026-10-24
- **Initiative:** `03-code-graph`
- **Governs:** `kartta_lang::{UseRef, Receiver, Access, DataUses}`, `crates/kartta-graph/src/{resolve,calls}.rs`,
  `Graph::references`
- **Pinned by:** `crates/kartta-graph/tests/graph/typed.rs`, `crates/kartta-graph/tests/graph/members.rs`

"Who reads or writes `Config.Timeout`?" needs the field accesses beside the calls, and an agent grepping a short member
name reads thousands of unrelated lines. Each file records its uses of names outside a call as written,
with how each touches its target and what it is written on, and a query binds the uses of the name it asks about, so
each query pays the binding and the build pays only the uses' storage.

## Decision

**What a use records.** A `UseRef` keeps the innermost symbol around the use, the name as written, its `Receiver`, its
`Access` and its line. The access is a read (a value taken, or a member taken through the name, as `EventType.Created`
reads `EventType`), a write (the left side of `=`, a key or an element of a literal that builds the owner), an update
that reads and writes (`+=`, `++`), or a use as a type, which reads no value
([ADR 3.174](/design-docs/adr/3.174-type-use-access.md)). The receiver is bare; a module qualifier; the
enclosing member's own receiver (`this`, `self`, or none written where the language reads a bare name as a member); or
a path, the type a value's declarations spell as the language's receivers convention says (ADR 3.29), empty where the
language cannot name it. A use at file scope binds no edge, and the graph keeps only its name
([ADR 3.112](/design-docs/adr/3.112-file-scope-names.md)). Which sites each language records is its
own rule:

- Go: [ADR 3.60](/design-docs/adr/3.60-go-data-sites.md), and its anonymous structs
  [ADR 3.170](/design-docs/adr/3.170-go-anonymous-structs.md);
- TypeScript and JavaScript:
  [ADR 3.62](/design-docs/adr/3.62-jsts-data-sites.md);
- Python: [ADR 3.63](/design-docs/adr/3.63-python-data-sites.md);
- C++: [ADR 3.64](/design-docs/adr/3.64-cpp-data-sites.md), and its namesake
  classes [ADR 3.65](/design-docs/adr/3.65-cpp-namesake-classes.md);
- daslang, Quirrel, Lua and Rust: [ADR 3.66](/design-docs/adr/3.66-uncalled-name-reads.md);
- PHP, Ruby and Bash, and why Puppet and BLK record none:
  [ADR 3.67](/design-docs/adr/3.67-callables-named-by-data.md).

DSHL records the uses ADR 3.18 states. A use is kept in 16 bytes, as
[ADR 3.68](/design-docs/adr/3.68-use-storage-layout.md) states, and `Graph::stats` counts the reads,
the uses as a type among them, the writes and the updates apart.

**How a query binds it.** Uses are bound when a query asks, as calls are (ADR 3.7), and nothing is stored. Each
receiver binds at the tiers [ADR 3.173](/design-docs/adr/3.173-data-use-binding.md)
states.

**Who reads them.** `Graph::references` answers a field's, a variable's or a constant's sites by access
([ADR 3.175](/design-docs/adr/3.175-data-references-by-access.md)). `find_unused` judges a language's
data by its uses only where it sets `DataUses::Every`, Go alone
([ADR 3.110](/design-docs/adr/3.110-data-dead-code.md)), and the impact walks go
from a field, a variable or a constant to its users in every language
([ADR 3.132](/design-docs/adr/3.132-data-symbol-reach.md)). Each binds the uses when a query
asks; the build does no work for them.

## Why

- A quarter to a half of every graph's definitions are fields, variables and constants, and before this no query could
  select one: `find_references` answered no symbol, or a namesake type or method.
- Binding when asked keeps a use valid however other files change, as ADR 3.7 argues for calls.

## Consequences

- The uses and their name index are the cost: the heap after a warm Go monorepo build holds 364 MB against 317 MB
  (2026-10-18). Accepted.
- `references` of a busy field takes tens of milliseconds, `Point3::x` with 4,275 sites on the C++ tree. Accepted.
- `find_unused` leaves the data of every language but Go unjudged, since none records every read and write. Accepted.
- An owner-qualified name that several packages' types end with selects no symbol; ADR 3.35 answers with the
  candidates.
- A DSHL shader or block a `pass` or `supports` names is a read. Accepted.

## Rejected

- **Resolve uses at the build and store edges** — what ADR 3.7 rejected for calls: a transient peak 1.3-1.7 times
  larger, and re-resolution across files on every edit.
- **Extraction when a query asks, through the trigram index** — a common member name reaches thousands of files a
  query, and the content index is optional.
- **Argument binding and stored def-use chains** — the first duplicates `find_callers`; the second takes two to four
  times the call storage, and a three-hop chain survives whole in about an eighth of cases.

## Revisit if

Binding a name's uses when asked grows past the answer's budget, as `find_unused` and the impact walks bind every name
they weigh. The busiest field measured binds in tens of milliseconds; held with high confidence on the measured trees.
