# Read a conditional that splits a brace with its first branch taken

- **Status:** accepted
- **Date:** 2026-10-22
- **Updated:** 2026-10-24
- **Initiative:** `03-code-graph`
- **Governs:** `crates/kartta-lang-cpp/src/repair.rs` (`untaken_branches`, `ConditionalScan`, `BraceSplit`,

- **Pinned by:** `crates/kartta-lang-cpp/src/repair.rs`
  (`a_conditional_whose_first_branch_unbalances_its_braces_is_read_with_that_branch_taken`,
  `a_function_whose_conditional_branches_each_open_a_brace_ends_at_its_own_brace`,
  `a_function_whose_conditional_splits_a_call_and_a_brace_ends_at_its_own_brace`,
  `only_a_first_branch_that_leaves_a_brace_open_splits_where_an_error_holds_the_directive`,
  `a_comment_holds_no_directive`, `a_raw_string_holds_no_brace`)

The C++ grammar reads each branch of a preprocessor conditional as a run of whole statements. A first branch that
leaves a brace open, `#ifdef _XBOX` `{` `#else` `if (x) {` `#endif`, makes the `#else` an unknown directive inside the
block it opened, or, where the branch also leaves a call or a condition open, a bare token of the error that swallows
it; the later branch's brace then opens a block nothing closes, and the definition runs to the end of the file, as the
grammar runs `PxcBruteForceOverlapBackface` from line 753 to 1379. The second parse reads such a file as the
preprocessor would with its first branches taken, at the price of the code in the branches not taken.

## Decision

1. The repair fires where the first tree holds a branch directive, `#else`, `#elif`, `#elifdef` or `#elifndef`, as an
   unknown directive, or as a bare token of an error.
2. It then blanks, before the second parse
   ([ADR 3.3](./3.3-repair-what-the-c-plus-plus-grammar-cannot-parse.md)), every conditional of the file that has a
   later branch and whose first branch leaves a brace open: its opening directive and everything from its first later
   branch through its `#endif`. Where an unknown directive fired it, so is every conditional whose first branch closes
   a brace it did not open, `} else if (a) {`.
3. A directive inside a comment or a string literal, a raw string included, is none, and a brace there counts for
   nothing.

## Why

- Every such conditional, not only the misread one, because blanking one changes how the grammar reads the next:
  repairing the misread one alone ended four tinyexr functions inside a later `#else`, `DecodeTiledLevel` among them.
- The first branch keeps the code a definition's braces enclose; of the misread conditionals' definitions, 27 of 28
  whose end changed now end at their closing brace, and 467 regain their namespace or class, 30 of 30 sampled right
  (C++ game-engine tree, 2026-10-22).
- A bare token fires the repair in 8 game-engine files, and there it ends `TIFFClientOpen` at line 502 rather than 749
  and gives 79 names their namespace back (2026-10-24).
- A first branch that closes a brace and opens it again, doctest's `} namespace doctest {`, stays as written after a
  bare token: blanking it there takes the namespace off about 150 names of `doctest.h`.

## Consequences

- The code of a branch not taken leaves the extraction: its definitions, calls and uses, in the 64 game-engine files
  an unknown directive repairs and the 6 a bare token does. Accepted.
- 775 of the 43,356 game-engine files hold a bare branch token and pay a byte scan of their conditionals, and 8 of
  them a second parse they did not take before (2026-10-24). Accepted.
- A definition can still end wrong where the misreading has another cause: curl's `ossl_connect_step2` (accepted).

## Rejected

- **Take the first branch of every conditional the tree misread, whatever its braces** — changes 136 files and drops
  671 definitions, most of them alternatives the grammar would have read.
- **Take the last branch** — loses 4,049 calls where the first gains 122.
- **Keep every branch and blank only the braces a branch leaves unmatched** — binds 53 calls more, but ends 7
  definitions fewer at their brace, `Curl_netrc_scan` and PhysX's `stab` among them, and leaves 76 more names without
  their namespace.
- **Fire on a bare token only where its own conditional's first branch leaves a brace open** — the same extraction on
  every game-engine file, for a match of each token against the scan's conditionals.

## Revisit if

A tree-sitter-cpp release reads a conditional's branches as alternatives rather than as runs of statements. Medium
confidence that none will soon.
