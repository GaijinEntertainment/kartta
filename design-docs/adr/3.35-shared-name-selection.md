A name several symbols share selects one of them, those it names whole before those it only ends: the call queries of
[ADR 3.7](/design-docs/adr/3.7-call-resolution.md) take the one with the most callers or sites, and
[ADR 3.20](/design-docs/adr/3.20-implementor-resolution.md) the most implemented. A selector
carries a path prefix and a line that together reach any of them, and an answer lists the most ranked of those it
passed over with the file and line it starts on, so an agent learns which symbol it got and asks again for another at
the cost of one more call.

## Decision

- **A name taken whole selects first.** A query selects among the symbols whose qualified name is the name as written,
  and only where none is among the other symbols of that name, as a bare name's members and the declarations a
  namespace or a package qualifies. Within that tier the call queries take a callable before any other symbol, then
  the count the query ranks by decides, and path order on a tie. A file's role takes no part.
- **A selector carries a path prefix and a line.** `Selector` is a name, an optional start of a root-relative path: one
  file's path, or a directory's with its closing `/`, and an optional one-based line, the one `Definition::line` gives;
  `None` looks in every file or at every line, and a `&str` converts to a selector without either. Every selection tier
  keeps only the symbols in the files under the prefix that start on the line before it ranks them, so a prefix reaches
  any copy of a symbol, copies that share one qualified name included, and narrows an owner-qualified name that several
  symbols end with to the one under it, and a line reaches one of several symbols of a name in one file: C++ overloads,
  a declaration beside its out-of-line definition, a template beside its specialization. A declaration under the prefix
  and on the line answers as the callable it links to, wherever its definition lives. `callers`, `callees`,
  `references`, `implementations`, `definitions` and both ends of `call_path` take one, and a name read with the other
  separator ([ADR 3.48](/design-docs/adr/3.48-other-separator-reading.md)) keeps its selector's prefix and line.
- **An owner-qualified name only its suffix matches.** Where a name with a separator matches no qualified name and no
  bare name whole, a query selects it only when every symbol that ends with it is one symbol: one callable for the call
  queries, one type for `implementations`. Otherwise the graph selects nothing, and `kartta::unmatched` gives the MCP
  and C ABI answers the symbols to list, with the file and line that pick one.
- **An answer lists the most ranked of what it passed over.** A walk over calls, `references` and `implementations`
  carry `candidates`, and a call path carries them for each end. `candidates` holds at most the selector's
  `candidate_limit` of the symbols `passed_over` counts, every one when the caller sets no limit, the highest count
  first, then path order, each with the count the query ranks by: callers for a
  walk over calls and for each end of a call path, sites for references, direct implementors for implementations.
  `passed_over` counts the other symbols `Graph::definitions` lists for the name that the selector looks at. The counts
  come from the name's resolution, which ranking the root already did for every symbol of the name, and implementations
  reuse the counts their selection took. The limit sits on the selector, which each of these queries and each end of a
  path takes; the MCP server and the wire pass 5 ([ADR 4.23](/design-docs/adr/4.23-mcp-default-limits.md),
  [ADR 4.57](/design-docs/adr/4.57-wire-params-answers.md)).
- **The kinds a query selects among are part of its contract.** `is_referent`, every kind but an enum's variants, and
  `is_parent`, classes, structs, interfaces, traits, enums, namespaces and type aliases, state what `references` and
  `implementations` pick among, so a consumer that explains a name that selected nothing lists only definitions a
  prefix could pick.

## Why

- A symbol whose qualified name is a bare name has no other name to be asked by, while a member or a qualified
  declaration keeps its own, which its `<candidate/>` lists as `qn=`. Ranked together, the picks of 28 names move on
  the TypeScript repository; its own qualified name selects each new pick in one call, and each symbol passed over is
  then reached only through a path prefix and a line (2026-11-27, #1312).
- A count told an agent that something was passed over, not what, so it had to search to learn which copy it got, and
  copies that share a qualified name, as a vendored package beside the same package in a second checkout, were reached
  by no name at all.
- A file holds several definitions of one qualified name often: on the C++ game-engine tree, 251,262 callables and
  types in 72,985 such groups, of which a selector by file reached 73,029; by file and line, 239,504 select themselves
  and 11,742 declarations the definition they link to (2026-10-23, #401).
- A call path takes a prefix at each end, so an agent that sees the copy it meant among an end's candidates asks again
  with that copy's path instead of settling the end with another tool first.
- A count rarely tells apart the symbols a name only ends with: of 5,256 names several types end with on the C++
  game-engine tree and the Go monorepo snapshot, the most implemented leads on 69 and no match has an implementor on
  4,839 (2026-10-31, #506).

## Consequences

- A bare name asked for a member picks a free function of that name however rarely it is called, and the member
  costs one more call by the `qn=` its candidate lists. Accepted.
- Ranking the passed-over symbols costs a name with many of them their counts: `find_implementations` of `Iterator` on
  the C++ game-engine tree counts the implementors of the 45 types it passes over, 0.86 ms where it took 0.10 ms
  (2026-10-19, #106). Accepted.
- An owner-qualified name several symbols end with costs one more call where a count would have found the symbol meant,
  as a primary template with the most implementors: 2 of 30 sampled among the names the count leads on (#506). Accepted.
- Definitions of one name that start on one line, as in minified code, stay apart by nothing: the line selects among
  them by the same ranking, and 16 of the 251,262 asked on the C++ game-engine tree select another (2026-10-23).
  Accepted.

## Rejected

- **Rank every symbol of a bare name together** — a free function that a member of its name out-calls is then
  reached only through a path prefix and a line, where the member keeps its qualified name (#1312).
- **Answer the union of the symbols a name selects** — one list that mixes copies and namesakes
  ([ADR 3.20](/design-docs/adr/3.20-implementor-resolution.md)).
- **Pick among an owner-qualified name's suffix matches, the first or by rank** — an answer where the name names none
  for certain: ranked by callers, 5 of 30 sampled picks were the symbol meant (#506); a listing and a prefix pick the
  one meant at the cost of one more call.
- **A selector by file only** — a directory prefix also tells a vendored tree from the checkout, and a file's path is a
  prefix of itself.
- **A line inside the symbol's span** — a class spans its own constructor's line, and both are named `Circle`, so a
  line inside a span picks among nested namesakes.
- **A signature as the key** — not every language keeps one, and every `<candidate/>` already carries the line in its
  `loc`.
- **A `file:line` path prefix** — one argument parsed two ways, and a directory's prefix holds no line.
- **Every passed-over symbol in the MCP and wire answers** — `Provider` passes over 59 types on the Go monorepo
  snapshot and `visit` 1,773 callables on the C++ tree; their five, with `passed_over` counting the rest, keep an
  answer's growth to a few hundred bytes.
- **Five fixed in the engine** — a consumer that wanted every candidate could not ask for it, and the wire carried the
  same cut (#1244).
- **The limit as an argument of each query** — `implementations` already takes four arguments, and a call path needs
  one per end, which the selector carries.

## Revisit if

Agents asking again after a shared name's answer pick a copy past the fifth candidate often enough that five is too few.
Not measured.
