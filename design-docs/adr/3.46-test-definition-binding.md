# Bind no test definition by name for a call from outside test code

- **Date:** 2026-10-23
- **Governs:** `crates/kartta-graph/src/resolve.rs` (`can_bind_by_name`, `one_type_outside_tests`,
  `resolve_outside_scope`), `crates/kartta-graph/src/confidence.rs` (`UNIQUE`, `SAME_DIR`)
- **Pinned by:** `crates/kartta-graph/tests/graph/calls.rs`
  (`the_one_callable_of_a_name_binds_a_test_definition_only_for_test_code`,
  `a_test_definition_counts_against_the_one_callable_of_its_name`,
  `a_call_outside_test_code_binds_the_one_type_that_a_test_type_stands_in_for`,
  `a_runtime_method_binds_no_test_definition_as_the_one_callable_for_a_call_outside_test_code`,
  `nearness_binds_a_test_definition_only_for_test_code`), `crates/kartta-languages/tests/test_code.rs`

The tiers that bind by name alone, the one callable of the name and the three proximity steps of
[ADR 3.172](/design-docs/adr/3.172-bare-call-binding.md), find a
test's stub among the definitions of a product call's name. Test code is built apart from the code it tests: a call from
outside test code binds no test definition there, and the definition still counts, so no other definition is guessed
in its place, except the one type that a test's type stands in for.

## Decision

- **No test definition by name.** A call from outside test code binds no test definition at the one callable of the name
  or at the three proximity steps.
- **Test definitions still count.** The test definition still counts among the definitions of its name. Where it is the
  one callable, the call binds nothing and counts as not admitted; where nearness picks it, as the nearest of its name,
  the call binds nothing and counts as ambiguous, and a definition farther away is not taken in its place.
- **The type exception.** Where the definitions of the name outside test code are one type, or a constructor that stands
  for its type, such a call binds it at 60. A member does not take part in this exception.
- **Scope tiers.** The scope tiers keep test code apart already: a package names its directory only through code outside
  test code ([ADR 3.7](/design-docs/adr/3.7-call-resolution.md)), and a module's file shows a test definition only to
  its crate's tests ([ADR 3.45](/design-docs/adr/3.45-module-file-bindings.md)).

## Why

- Every sampled product call that bound a test definition was wrong, in every language, as Python's `time.time()`
  binding a test's `FakeClock.time` (C++ game-engine tree, Go monorepo snapshot, this repository and tree-sitter,
  2026-10-23, #395).
- A test function most often stubs a builtin or a library outside the graph, so the one function outside test code is
  no surer to be the one called. Code outside test code constructs no test type, so a test's type of the name stands in
  for the type outside it, or holds a fixture: the exception binds C++ pairs of which about 96% are right (#395).

## Consequences

- Test support that a language's test rule reads as product code loses right pairs, about 5% of the C++ pairs the rule
  drops, breakpad's `synth_elf.cc` calling the `Section` members of `test_assembler.h` (#432).
- The type exception binds 106 wrong C++ pairs: c50's `Verbosity()` macro calls to Catch2's enum, breakpad's
  `std::wstring` calls to EASTL's typedef, and the 3ds Max plugin's SDK `Point3` calls.
- A scope tier can still bind a test definition for a product call at 80: Rust's same-file tier into an inline
  `mod tests` (#235). A C++ declaration links no test definition for a call outside test code
  ([ADR 3.74](/design-docs/adr/3.74-cpp-declaration-links.md)).

## Rejected

- **Test definitions out of the tail, or out of nearness alone** — the call binds the namesakes the stub had shadowed:
  5,885 Quirrel `loc()` calls take a game's own `loc` for the native localizer (2026-10-23).
- **The one type or member** — 97% of the Python member pairs it adds are `TestContext.sleep` namesakes
  (2026-10-23).

## Revisit if

Every language's test rule reads its test-support files (#432), so that the one function outside test code is more
often the one called. Medium confidence.
