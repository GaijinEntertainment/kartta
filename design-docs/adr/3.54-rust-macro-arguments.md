# Read the calls and the reads a Rust macro's arguments write from its tokens

- **Date:** 2026-10-23
- **Governs:** `crates/kartta-lang-rust/src/walk/arguments.rs`
- **Pinned by:** `crates/kartta-lang-rust/tests/extract.rs`

tree-sitter-rust parses a macro invocation's arguments as a token tree, so a call or a read inside `assert!`,
`format!`, `vec![..]` or a user macro is no expression. The walk reads the calls and the reads out of the tokens, by the
shapes an expression takes, for the macros of every crate; what the tokens cannot tell, where a closure or an arm ends,
it bounds by the token tree, and a lowercase word, which a macro takes by name as often as a value, it does not read.

## Decision

- **A word before a `(` tree is a call**, a call of the function around the macro, with the receiver and the path a call
  expression of that shape records ([ADR 3.56](/design-docs/adr/3.56-rust-call-receivers.md)):
  a name, `helper(x)`; a path, `crate::m::f(x)`, `Vec::<u8>::new()` or `::root::f()`, its turbofish skipped; and a
  member, `C.opens(x)`, `self.name()` or `x.collect::<Vec<_>>()`, a chained operand recording the empty receiver. A
  word before `!` is a nested macro invocation, whose arguments are read the same way. A bare call binds an item its
  block declares as a local call, and a path call keeps its path as one outside a macro does. A call takes the line of
  its name.
- **A capitalised word an expression would read is a use**, recorded as
  [ADR 3.66](/design-docs/adr/3.66-uncalled-name-reads.md) records one outside a macro: a bare word,
  `assert_eq!(x, LIMIT)`, a path's last segment through the path, `Kind::A` or `Self::MAX`, and the base of a field
  access, `CONFIG.timeout`, never the field. A lowercase bare word is no use, and neither is a path from the root,
  `::a::LIMIT`, which names no item of the file outside a macro either. A callee, a macro, a path's segment, a
  field's label, a named argument, `format!("{x}", x = 1)`, a field, a type and the struct its fields build,
  `Point { x }`, read no value; [the walk](/crates/kartta-lang-rust/src/walk/arguments.rs) states how the tokens tell
  each.
- **A bare name a pattern binds is no call and no use**, as
  [ADR 3.53](/design-docs/adr/3.53-rust-local-calls.md) decides for calls: a
  parameter or a local of the function around the macro; a name that a closure's parameters, a `let` after its
  initializer, a match arm or a `matches!` pattern in its guard bind, to the end of the token tree it is written in; and
  a name an `if let`, a `while let` or a `for` binds, in the block it opens. A constructor, a path or a field's label in
  such a pattern, `Some(x)` or `Point { x: at }`, binds nothing.
- **A pattern holds no call and no use.** `matches!`'s pattern, from the first `,` to its guard; a `let` or `for`
  pattern; a match arm's pattern; and a `(` tree before `=`, a guard's `if` or an unguarded arm's `=>` name
  constructors, `Some(Kind::A(_))`. A `macro_rules! matches` that the file defines before the invocation, in the block
  or module around it, reads as any macro.
- **Code the macro generates holds no call or use of the site**: arguments that interpolate, `#name` or `#(..)*` as
  `quote!` writes them, drop every call and use of their macro and of none around it; an attribute, `#[derive(Debug)]`;
  and the parameters and body of a `fn` the arguments declare. The name and the types of any item they declare are no
  use, though a `const`'s or a `static`'s value is read, as `thread_local!` writes one.
- **A keyword is no callee.** A token tree keeps `in`, `move`, `ref`, `dyn`, `else` and a few more as identifiers, so
  `for x in (items)` calls nothing; `r#in(x)` is a call.
- **Macro definitions.** The bodies of `macro_rules!` definitions, templates each expansion fills, are not read.

## Why

- No call in a macro's arguments was recorded, and nothing in an answer said so: `find_callers` of `Banner::opens`
  listed its 7 callers outside tests and none of the 7 tests in `banner.rs` that call it 24 times through `assert!`
  (this repository, 2026-10-23, #231).
- No read there was either, so `find_references` of a constant read only in assertions listed nothing: wasmtime's
  constants, statics and unit structs gain 247 uses (2026-10-29, #436).
- Reading the tokens finds the same calls as re-parsing each tree but for a few shapes, at less cost: one thread
  extracted this repository's Rust in 0.304 s against 0.381 s re-parsing and 0.282 s reading no arguments
  (2026-10-23, #231).
- A macro takes a lowercase word by name, `cov_mark::check!(a_test)` or `T![kw]`, which binds the function of that
  name: reading every word, 12 of 30 sampled uses on rust-analyzer were right, and reading capitalised words alone,
  36 of 36 there and 29 of 30 sampled on wasmtime (2026-10-29, #436).
- A pattern names constructors, which a pattern outside a macro records no call for.

## Consequences

- A closure's, a `let`'s or an arm's names hide a bare call to the end of the token tree, past where the binding ends.
  Accepted.
- The calls in `macro_rules!` bodies and in `quote!` templates are not read: 19 call shapes here and 82 in tree-sitter
  in macro bodies. Accepted.
- Each word of the arguments is weighed against its neighbours: one thread extracts wasmtime's Rust in 42.05 G
  instructions against 41.64 G reading the calls alone, +0.98% (2026-10-29, #436). Accepted.
- A function or a module the arguments name as a value is no use: 14 right uses of the 264 every word gives on
  wasmtime, 6 functions passed by value and 8 modules `isa_builder!` names in a path. Accepted.
- The type `offset_of!` names reads as a unit struct would: 6 of wasmtime's 247 uses. Accepted.
- A name a format string captures, `"{LIMIT}"`, sits in a string literal and is no use. Accepted.
- A `matches` macro that a `use` imports reads as the standard one. Accepted: no file of the measured trees does so.

## Rejected

- **Re-parsing each token tree through an included range** — a parse per tree costs about 16 µs whatever its length,
  and it still misses the initialisers of `thread_local!` statics and the receivers in `json!` objects.
- **The standard expression macros alone** — misses right calls in other macros, `tree_sitter_fingerprint!(grammar(),
  ..)`, the log crate's `info!` and tree-sitter's `add_line!`, and reading every macro costs nothing more per call.
- **No pattern rule** — records each constructor in a pattern as a call.
- **Every word but one that names a function** — reads 8 more uses on wasmtime, the modules `isa_builder!` names, and
  2 false ones, `cfg!(asan)`, for a set of the file's functions and a deferred read per lowercase word.

## Revisit if

tree-sitter-rust parses a macro's arguments as expressions where they are ones, which is unlikely, since a macro's
arguments need not be expressions at all; or Rust code names its constants and statics in lowercase, which the
compiler's `non_upper_case_globals` lint warns against.
