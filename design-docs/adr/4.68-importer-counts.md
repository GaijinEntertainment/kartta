# Name what a file's language counts as an importer in find_importers and dependents

- **Date:** 2026-11-06
- **Governs:** `crates/kartta-mcp/src/render/symbols.rs` (`importers`), `kartta_lang::Conventions::includers`, the
  `find_importers` tool, `crates/kartta-ffi/src/wire/graph.rs` (`DependentsView`), `bindings/go/wire/graph.go`
  (`Dependents.Includers`), `bindings/node/src/wire.ts` (`Dependents.includers`)
- **Pinned by:** `crates/kartta-mcp/tests/graph.rs` (`find_importers_says_what_the_language_counts_as_an_importer`),
  `crates/kartta-languages/tests/includers.rs` (`every_language_of_the_set_states_what_it_counts_as_an_includer`),
  `crates/kartta-ffi/tests/golden/dependents.json`, `crates/kartta-ffi/tests/golden/dependents-bounds.json`

`find_importers` and the wire's `dependents` count the files that include a file, and each language records a narrower
relation than the word "imports" reads as: a Rust module counts the `mod` that loads it, not the files that `use` it.
Every answer over a file a graph holds names what its language counts, in the words the language states, every language
kartta ships stating them, for 81 to 191 bytes an MCP answer and 64 to 201 a wire one.

## Decision

- **The statement.** A language states the files it records as including a file as `Conventions::includers`, a phrase
  that follows "counts" and calls the file asked of "this file", which its graph hands out
  ([ADR 3.1](/design-docs/adr/3.1-language-plugin-contract.md)). Each phrase states what the language's resolver records
  today, and the zero it gives by rule where it has one: a Rust crate root, a Go `_test.go` file.
- **The answer.** An answer over a file the graph of `family` holds reads "the `family` graph counts ...": a `<note>`
  before the `<file/>` records, and the whole text of an answer with `count="0"`. An answer over a file no graph holds
  keeps the note of why none does. A language that states nothing, one kartta does not ship, gives the answer without
  either.
- **The wire.** A `dependents` part of [ADR 4.2](/design-docs/adr/4.2-c-abi-wire.md) whose file a graph holds carries
  the phrase as `includers`, beside the `graph` that names the family, and leaves the key out where the language states
  none, as [ADR 4.57](/design-docs/adr/4.57-wire-params-answers.md) adds a key. Go's `wire.Dependents.Includers` and the
  TypeScript `Dependents` type carry it.
- **Which languages state it.** Every language kartta ships, held to it by the set's test.
- **The description.** The description says the note names what the file's language counts, with Rust as its example.

## Why

- On this repository `crates/kartta-mcp/src/llmxml.rs` answered `count="1"`, the `mod` in `lib.rs`, while seven files
  name `crate::llmxml`, and a crate root answered a bare `count="0"`, though the tool's description promises every file
  that imports the file (2026-11-06, #1041). The Rust Reference calls a `use` declaration an import
  (`items/use-declarations.md:15`) and loads a bodiless `mod` from a file (`items.mod.outlined.intro`).
- The language crate knows which forms its resolver records; a statement it makes beside them cannot name a form the
  server would have to guess.
- The phrase is a `&'static str` the graph already holds in its conventions; the answer formats it once per call, and
  adds 81 bytes on a BLK file to 191 on a Rust one, measured over dagor's and the Go monorepo snapshot's parity answers
  on 2026-11-06.
- A wire consumer read a Rust module's one `dependents` file, or a crate root's none, as every file that depends on it
  (#1207). The key adds 95 bytes to the C++ part of `tests/golden/dependents.json`, the phrase borrowed and serialized
  once per answer.

## Consequences

- A Rust module's importers stay the `mod` declarations that load it, so the files that `use` it are not listed;
  recording resolved `use` paths as includes is #1206.
- The wire's phrase is words for a reader, not a value a program branches on; a consumer that acts on it passes it to
  an agent or a person. Accepted: no language states its includers as anything a program could read.

## Rejected

- **A table of languages in the server** — a language crate outside kartta could not state its phrase, and the table
  falls behind the resolvers, as [ADR 4.19](/design-docs/adr/4.19-unrecorded-type-uses.md) found for type uses.
- **A `Language` trait method** — the statement describes what the graph built from the family records, which the
  graph's conventions already carry to every consumer; a method would need an engine accessor per file.
- **One generic sentence for every language** — it cannot say that a crate root or a `_test.go` file counts none by
  rule, which is the zero the agent misreads.
- **A flag on the wire's part, as `type_uses_unrecorded` marks a references part
  ([ADR 4.35](/design-docs/adr/4.35-wire-unrecorded-uses.md))** — every shipped language states a phrase, so the flag
  would be true on every held answer and say nothing of which forms count.

## Revisit if

Every language records each of its import forms as an include, so the word "imports" reads true unqualified; low while
Rust records only `mod` declarations.
