# Serve the Go module from `bindings/go` under Gaijin's module prefix

- **Date:** 2026-11-02
- **Governs:** `bindings/go/go.mod`, `bindings/go/kartta.h`, `bindings/go/doc.go`, the header step of the `go` job of
  `.github/workflows/ci.yml`
- **Pinned by:** the header step of the `go` job of `.github/workflows/ci.yml`
- **Implementation:** pending — `dev.gaijin.team` serves no `go-import` entry for the module yet (#131)

A consumer fetches a Go module with no checkout, so the module's path, layout and header cannot rest on one. The module
takes `dev.gaijin.team/go/kartta` from `bindings/go`, with its client at the root and a copy of the header inside it;
the trade is a header that exists twice and a CI step that holds the copies equal.

## Decision

- **The module's path.** The module `dev.gaijin.team/go/kartta` stays in `bindings/go`, its client at the module's root.
  Before the first release tag, the server behind `dev.gaijin.team` takes a `go-import` tag that names that directory:
  `dev.gaijin.team/go/kartta git https://github.com/GaijinEntertainment/kartta bindings/go`.
- **The module's version.** Its version `vX.Y.Z` is the tag `bindings/go/vX.Y.Z`, on the commit of the release `vX.Y.Z`,
  and takes the archive of that release.
- **The header.** `bindings/go/kartta.h` is a copy of the crate's header, and the `go` job's header step fails when the
  two differ.

## Why

- Gaijin's Go modules live under `dev.gaijin.team/go` (#131).
- A Go module's zip holds its own directory alone, with the repository's `LICENSE`, so an include outside `bindings/go`
  fails on any build outside a checkout (#131).

## Consequences

- The header exists twice, and an edit changes both. Accepted: the header step fails until they match.
- `go test` on the module from a consumer's cache skips the golden replay, because the golden files stay beside the
  crate. Accepted: the replay runs in a checkout.

## Rejected

- **A module path on `github.com`** — it sits outside the prefix of Gaijin's Go modules (#131).
- **The client in a `kartta` directory of the module** — it imports as `dev.gaijin.team/go/kartta/kartta` (#131).
- **A symlink to the crate's header** — a module zip leaves symlinks out.

## Revisit if

- `dev.gaijin.team` stops serving Gaijin's Go modules, or the binding leaves this repository. High confidence.
