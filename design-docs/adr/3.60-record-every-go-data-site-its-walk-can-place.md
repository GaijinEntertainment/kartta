# Record every Go data site its walk can place

- **Status:** accepted
- **Date:** 2026-10-18
- **Updated:** 2026-10-24
- **Initiative:** `03-code-graph`
- **Governs:** `crates/kartta-lang-go/src/walk/uses.rs`, `crates/kartta-lang-go/src/walk/syntax.rs` (struct tags),

- **Pinned by:** `crates/kartta-lang-go/tests/extract.rs`
  (`a_member_taken_on_a_value_is_a_use_spelled_with_its_type_and_how_it_is_touched`,

  `a_range_or_a_receive_that_assigns_writes_the_names_on_its_left`,

  `crates/kartta-graph/tests/graph/typed.rs`, `crates/kartta-graph/tests/graph/dead_code.rs`

Go spells a type for every value its declarations name, so a member use can carry the type path that ADR 3.173's
first member tier follows, and a package's names are visible to every file of its directory. The Go walk records each
data site it can place in a body, so `find_unused` can judge Go's data by its uses, at the cost of a walk that sees one
file and leaves a few bare names to a qualifier guess.

## Decision

- A selector that is not a call's callee is a member use with the operand's type path (ADR 3.29), so a method taken as a
  value, `RunE: c.run`, is a use of the method. An operand of no type the walk can spell records the empty path, and Go
  keeps `UntypedMembers::FileField`, so such a use takes the file's one field of the name (ADR 3.173).
- A key of a struct literal writes its field, the literal's type spelled where written and taken from the enclosing
  slice or map literal where elided. An element of a struct literal without keys, `P{1, 2}`, writes the field in its
  place, where the file declares the struct: a package-level or local type, an alias or a defined type of one, or an
  anonymous struct. An embedded or blank field takes a place and records nothing, and a literal of a type declared in
  another file, or one that does not set every field, records none. An anonymous struct's keys and elements are ADR
  3.61's.
- An identifier in a body that no local, parameter, type parameter or declaration binds, that is not predeclared, a
  callee or `_`, is a bare use of a package-level value or function. A selector operand that is no local, no
  predeclared name and no `var` or `const` the file declares at package level is recorded as the qualifier of a
  qualified use, which the graph binds through the import of that name, else as a member of the package value or type
  it names, a method expression `handlers.series` among them (ADR 3.173). Such an operand is also a bare use, unless an
  import of the file spells it: a sibling file of the package may declare it, and Go lets no package-level name share
  an import's, so the read of an import's name binds nothing. The graph binds a bare use in its own file, a
  dot-imported package or its package directory (ADR 3.173).
- `=`, a `range` or a `select` receive that assigns with `=`, `++`, `--` and `op=` mark the outermost expression on
  their left: `=` writes, the rest update; `a.b` in `a.b.c = v` is read. `:=` declares its names and records no use of
  them.
- Go sets `DataUses::Every`: its fields, variables and constants are judged by their uses
  ([ADR 3.110](./3.110-judge-a-language-s-data-only-where-it-records-every-read-and-write.md)).
- The walk reads each field's struct tag and marks the field `is_reflected` where some `key:"value"` pair holds a value
  other than `-`, or the tag holds no such pair: a library takes the field by its name.

## Why

- A Go member call or use reaches a method or a field of its value, and a package's function only through the import,
  so the type path settles nearly every member site: of the member sites in a sample of 20,400 fields and values on the
  Go monorepo, 45,707 bound through the path and 169 by the file's one field (2026-10-18).
- A bare read of a package-level value binds right where some file of the package declares it: 30 of 30 sampled.
- A sibling file's value read through a selector, `cfg.Timeout` or `client.Do()`, is a read like any other: on the Go
  monorepo snapshot, the reads of such values and of their members bound right in 90 of 90 sampled (2026-10-23).
- Go sets every field of a literal without keys in the order its type declares them, which only the declaring file
  holds: of the snapshot's positional struct elements outside generated files, 96% build a struct their own file
  declares (2026-10-24).
- A field `encoding/json` or an ORM fills by its tag is read where no use names it; without the mark `find_unused` would
  list it as dead.

## Consequences

- An import whose package clause its path does not spell, `item_store` for `example.com/item-store`, records a bare
  read of its name at each selector, which binds nothing: a 16-byte use (ADR 3.68) per such site. Accepted.
- A sibling file's value that shares its name with a spelling an import's path gives, and not the import's package
  clause, records no read of itself at a selector, though its member binds, and `find_unused` can list it. Accepted.
- A value of an anonymous interface records the empty path, and its member uses go to the file's one field. Accepted.
- A positional literal records a write per element: 262,152 more uses on the snapshot, nearly all in vendored lookup
  tables, 16 bytes each (ADR 3.68), 4 MB more heap after a build (2026-10-24). A positional literal of a sibling file's
  or another package's struct records no write, and `find_references` misses it. Accepted.

## Rejected

- **Package and import tiers by name** for a member whose path is cut — 12 of 24 sampled right, below the 90% a tier
  needs: test tables and anonymous structs bind namesakes.
- **A member path in place of the qualifier** for an operand no import spells — an import whose package clause its path
  does not spell loses its member, which a path through a package binds to no definition.
- **A positional write bound when a query asks**, for a struct another file declares — the graph would keep each
  struct's places, embedded and blank fields among them, which no symbol holds, for 4% of the elements.

## Revisit if

A Go file's walk can see its package's other files, so a selector's operand is known to be an import or a sibling's
value. Not planned; the cost is a read of an unspelled import's name per selector.
