# Record every Go data site its walk can place

- **Status:** accepted
- **Date:** 2026-10-18
- **Updated:** 2026-10-23
- **Initiative:** `03-code-graph`
- **Governs:** `crates/kartta-lang-go/src/walk/uses.rs`, `crates/kartta-lang-go/src/walk/syntax.rs` (struct tags),
  the Go `Conventions` (`Receivers::TypePaths`, `DataUses::Every`), `SymbolFlags::is_reflected`
- **Pinned by:** `crates/kartta-lang-go/tests/extract.rs`
  (`a_member_taken_on_a_value_is_a_use_spelled_with_its_type_and_how_it_is_touched`,
  `a_name_no_local_binds_is_a_read_or_a_write_of_what_the_package_declares`,
  `a_range_or_a_receive_that_assigns_writes_the_names_on_its_left`,
  `a_struct_tag_that_hands_its_field_to_a_library_marks_the_field_reflected`),
  `crates/kartta-graph/tests/graph/typed.rs`, `crates/kartta-graph/tests/graph/dead_code.rs`

Go spells a type for every value its declarations name, so a member use can carry the type path that ADR 3.34's first
member tier follows, and a package's names are visible to every file of its directory. The Go walk records each data
site it can place in a body, so `find_unused` can judge Go's data by its uses, at the cost of a walk that sees one file
and leaves a few bare names to a qualifier guess.

## Decision

- A selector that is not a call's callee is a member use with the operand's type path (ADR 3.29), so a method taken as a
  value, `RunE: c.run`, is a use of the method. An operand of no type the walk can spell records the empty path, and Go
  keeps `UntypedMembers::FileField`, so such a use takes the file's one field of the name (ADR 3.34).
- A key of a struct literal writes its field, the literal's type spelled where written and taken from the enclosing
  slice or map literal where elided. An anonymous struct's keys are ADR 3.61's.
- An identifier in a body that no local, parameter, type parameter or declaration binds, that is not predeclared, a
  callee or `_`, is a bare use of a package-level value or function. A selector operand that is no local, no
  predeclared name and no `var` or `const` the file declares at package level is taken as an import's name and recorded
  as the qualifier of a qualified use. The graph binds a bare use in its own file, a dot-imported package or its package
  directory (ADR 3.34).
- `=`, a `range` or a `select` receive that assigns with `=`, `++`, `--` and `op=` mark the outermost expression on
  their left: `=` writes, the rest update; `a.b` in `a.b.c = v` is read. `:=` declares its names and records no use of
  them.
- Go sets `DataUses::Every`: its fields, variables and constants are judged by their uses (ADR 3.23).
- The walk reads each field's struct tag and marks the field `is_reflected` where some `key:"value"` pair holds a value
  other than `-`, or the tag holds no such pair: a library takes the field by its name.

## Why

- A Go member call or use reaches a method or a field of its value, and a package's function only through the import,
  so the type path settles nearly every member site: of the member sites in a sample of 20,400 fields and values on the
  Go monorepo, 45,707 bound through the path and 169 by the file's one field (2026-10-18).
- A bare read of a package-level value binds right where some file of the package declares it: 30 of 30 sampled.
- A field `encoding/json` or an ORM fills by its tag is read where no use names it; without the mark `find_unused` would
  list it as dead.

## Consequences

- A package value a sibling file declares, read through a selector, `cfg.Timeout`, records a qualified use of `cfg`,
  which binds only through an import, so that read is lost. Accepted.
- A member through a type a body declares binds through the file's first type of that name, so a second body's namesake
  takes its uses. Accepted.
- A value of an anonymous interface records the empty path, and its member uses go to the file's one field. Accepted.

## Rejected

- **Package and import tiers by name** for a member whose path is cut — 12 of 24 sampled right, below the 90% a tier
  needs: test tables and anonymous structs bind namesakes.

## Revisit if

A Go file's walk can see its package's other files, so a selector's operand is known to be an import or a sibling's
value. Not planned; the loss is a sibling's value read through a selector.
