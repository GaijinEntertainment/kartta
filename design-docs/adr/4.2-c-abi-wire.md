# Reach the engine through one JSON call over a small C ABI

- **Date:** 2026-10-18
- **Governs:** `crates/kartta-ffi`, `crates/kartta-ffi/include/kartta.h`, `crates/kartta-ffi/src/wire/`, `bindings/go`,
  `Code` of `bindings/node/src/wire.ts`
- **Pinned by:** `crates/kartta-ffi/src/abi.rs` tests, `crates/kartta-ffi/tests/dispatch.rs`,
  `crates/kartta-ffi/tests/golden.rs`, `crates/kartta-ffi/tests/reference.rs`, `bindings/go/kartta_test.go`,
  `bindings/go/version_internal_test.go`

Go and Node consumers reach the engine across a C boundary. `kartta-ffi` exports five functions, and every method is a
name and a JSON object of params answered in JSON, so one dispatch serves every binding and test and a new method is a
match arm, never a new export; each answer pays a JSON encoding that costs nothing next to the query.

## Decision

- **The header.** `crates/kartta-ffi/include/kartta.h` is hand-written and committed, and declares `kartta_abi_version`,
  `kartta_open`, `kartta_call`, `kartta_string_free` and `kartta_free`. The Go binding's cgo build compiles the module's
  copy of the header and links what Go code names, and `tests/reference.rs` holds each declaration to the library
  ([ADR 4.52](/design-docs/adr/4.52-wire-reference.md)). Its comment states all a consumer relies on, because a consumer
  of the archive holds no ADR: where the reference is, that a string outlives its handle, that a consumer ignores keys
  it does not know, how to stop calls before `kartta_free` (`cancel` with `{}`, then a join), every form of empty
  params, and that `kartta_call` blocks its thread.
- **Opening.** `kartta_open` takes `{"root": <path>}` and answers a handle, or null with `{"code", "message"}` written
  to the error out-parameter, never a bare null for a caller that asks for the reason; a null out-parameter discards
  it.
- **Calling.** `kartta_call` takes a NUL-terminated method name and the params' bytes and answers `{"ok": <answer>}` or
  `{"err": {"code", "message"}}`, never a null string; null params with a zero length, empty text and `null` read `{}`.
- **Ownership and threads.** Arguments are borrowed for the call; every returned string is the caller's, freed once
  with `kartta_string_free`. Calls on one handle may run at once from any threads; `kartta_free` must not run beside a
  call on the same handle.
- **The stack.** `kartta_call` runs each method on a thread it starts, of 8 MiB, and waits for it, so a caller's thread
  needs about 2 KiB whatever stack its libc gave it. A thread that cannot start answers `internal`. A Rust shell calls
  `Kartta::call` on a stack of its own choosing.
- **ABI version.** `kartta_abi_version` returns 1, which `KARTTA_ABI_VERSION` must equal; the Go binding checks it at
  open, answering `ErrABI`. It changes only when a binding built against an older header would misuse the library.
- **Library version.** A binding refuses a library whose major or minor version differs from its own, with an error
  that names both versions, and opens one that differs in the patch version alone. The Go binding's `Open` reads
  `version` on the new handle and answers `ErrABI`; its own version sits in `bindings/go/version.go`, which
  `scripts/version.sh` sets with every other site. The Node addon is built with its package and loaded at the package's
  version ([ADR 4.40](/design-docs/adr/4.40-node-addon-packaging.md)), so the Node binding makes no such check. Params
  keep refusing unknown fields ([ADR 4.57](/design-docs/adr/4.57-wire-params-answers.md)).
- **Panics.** Every entry point runs under `catch_unwind`: `kartta_open` and `kartta_call` answer `internal` and the
  handle stays usable, and the frees drop a panic. That holds only for a library built with unwinding panics.
- **Crate types.** The crate builds a `staticlib`, which cgo links into Kensai's static musl binaries
  ([ADR 4.56](/design-docs/adr/4.56-go-musl-job.md)), and an `rlib`, which a Rust shell such as the Node addon
  ([ADR 4.3](/design-docs/adr/4.3-node-addon.md)) builds on; it sets no global allocator
  ([ADR 4.31](/design-docs/adr/4.31-c-abi-allocator.md)). serde lives in this crate alone.
- **The wire.** The wire is kartta's own JSON. It keeps the method names Kensai already calls where the meaning holds
  and carries no compatibility layer for the shapes Kensai reads today; Kensai migrates once. Each method's contract is
  a golden file ([ADR 4.36](/design-docs/adr/4.36-wire-method-pinning.md)), and `WIRE.md` is its reference
  ([ADR 4.52](/design-docs/adr/4.52-wire-reference.md)).
- **Methods.** The methods are the names [`Kartta::call`](/crates/kartta-ffi/src/handle.rs) answers, the queries of
  [`query.rs`](/crates/kartta-ffi/src/query.rs) among them. `version` lists the methods and languages a library
  answers, and an unknown method answers `unknown_method`, its message listing the methods. `paths`, `len`,
  `grep_index/build` and `validate_globs` are not methods: `len` is `stats`'s `entries`, the content index is a `build`
  option made in the same walk, and a bad glob answers `invalid_glob` from the call that takes it.
- **Graph and file queries.** A graph query names no graph by default and answers one part per graph its name selects a
  symbol in; `lang` names one graph by a language or its family, and one the build did not make answers
  `invalid_params`, listing those it did. A file query (`outline`, `dependents`, `analyze_segment`) answers the graph
  that claims its file or why none does, and `analyze_change` counts its regions by the same causes
  ([ADR 4.69](/design-docs/adr/4.69-wire-file-query-graph.md)). `search` answers a part for every graph with a hit, a
  graph whose hits all come from the fill-up included.
- **Params and answers.** [ADR 4.57](/design-docs/adr/4.57-wire-params-answers.md) states what a method takes, its
  default bounds, and what its answer carries.
- **Symbol selection.** `callers`, `callees`, `references` and `implementations` take `path_prefix` and `line`, and
  `call_path` `from_path_prefix`, `from_line`, `to_path_prefix` and `to_line`
  ([ADR 3.35](/design-docs/adr/3.35-shared-name-selection.md)); a part that passed symbols over lists at most
  `candidate_limit` `candidates`, a `symbol` and the `count` the query ranks by, per end for `call_path`. How a symbol
  method read a name and why it matched nothing is [ADR 4.34](/design-docs/adr/4.34-wire-name-misses.md); a symbol's
  unrecorded uses, [ADR 4.35](/design-docs/adr/4.35-wire-unrecorded-uses.md).
- **Error codes.** `invalid_request`, `invalid_params`, `unknown_method`, `invalid_root`, `not_built`, `building`,
  `build_failed`, `build_cancelled`, `no_stamps`, `refresh_failed`, `refresh_cancelled`
  ([ADR 4.32](/design-docs/adr/4.32-wire-refresh.md)), `invalid_glob`, `invalid_pattern`, `not_found`,
  `not_a_directory` and `internal`. [`ErrorCode`](/crates/kartta-ffi/src/error.rs) states when each is answered. A
  binding's code type names these and takes any other string, Go's `wire.Code` and TypeScript's `Code` alike, since a
  library newer than the binding may answer a code it does not name.
- **Lifecycle.** How a build replaces a handle's engine is
  [ADR 4.45](/design-docs/adr/4.45-wire-build-lifecycle.md); cancellation is
  [ADR 4.30](/design-docs/adr/4.30-wire-cancellation.md), and following the tree
  [ADR 4.33](/design-docs/adr/4.33-wire-follow.md).
- **The Go binding.** The module `dev.gaijin.team/go/kartta` ([ADR 4.54](/design-docs/adr/4.54-go-module-home.md)) has
  no dependencies. Its `wire` package holds the params, answers and error codes with no cgo, so code that only handles
  answers builds and tests without the library; a `wire.Code` is an error and a `*wire.Error` unwraps to its code, so
  `errors.Is(err, wire.NotBuilt)` matches. The package at its root, `kartta`, links `libkartta_ffi.a` statically through
  cgo: the header from the module, the archive's directory from `CGO_LDFLAGS`, and on Windows the `windows-gnu` archive
  ([ADR 4.60](/design-docs/adr/4.60-go-windows-link.md)). A `Kartta` is safe for concurrent use. Every wire method has a
  typed call, as in the Node package ([ADR 4.3](/design-docs/adr/4.3-node-addon.md)), each answering its `wire` type,
  a graph query's answer as a `wire.Matches[T]` with one part per graph, and `Call` reaches params the wire types do not
  hold, with raw JSON; [the package](/bindings/go/kartta.go) documents each call, `Close` and the cleanup that frees a
  handle nobody closed. The oldest toolchain the module runs on is [ADR 4.63](/design-docs/adr/4.63-go-floor.md)'s.

## Why

- The maintainer set the library version rule on 2026-11-25 (#125): "A1: versions mismatch in minor version would cause
  denial of service. patch versions expected not to change anything, so.."
- The ABI integer alone let an archive of another release open, and then fail as `invalid_params` or drop a key
  silently (#125).
- One dispatch keeps the bindings thin: Go and Node translate JSON and decide nothing, so the rules live once, in Rust
  (#75).
- Answers are kilobytes, where JSON costs nothing next to the query. `paths` answered 150 MB of JSON on three million
  entries, and no consumer called it.
- Each binding gives the whole wire: the maintainer ruled "parity, all ffi planes get full api" (#1048).
- cbindgen is MPL-2.0, which `deny.toml` does not allow, and the surface is five functions.
- A cgo thread on musl has 131,072 bytes. A grep nested 47 groups deep overflowed it in `dist`, and an overflow ends the
  consumer's process past `catch_unwind`. Every recursion a call's params reach has a bound of its own: the 250 levels
  of `regex-syntax`'s nest limit, `serde_json`'s 128, and the braces of
  [ADR 1.4](/design-docs/adr/1.4-query-glob-dialect.md). So a stack above their worst case holds by construction, where
  a stack sized by real trees would only move the limit: ordinary calls take at most 45 KB on this repository and on
  dagor, and the deepest grep 297 KB in `dist` and 2.2 MiB in a debug build (2026-11-02, arm64 Alpine).

## Consequences

- Each answer pays a JSON encoding, which costs nothing next to the query. Accepted.
- Each `kartta_call` starts a thread: 18 µs at the median and 27 KB of footprint plus the stack it touches until it
  ends, on macOS arm64 (2026-11-02), beside 7 µs for a `definitions` and 19 ms for a grep. Accepted: under a millisecond
  decides nothing, and one rule for every method leaves no method to forget.

## Rejected

- **Go typed calls for the methods Kensai calls alone** — a Go integrator then writes its own structs for `callees`,
  `dead_code`, `resolution` and `cancel`, and the maintainer ruled for parity (#1048).
- **A binding that opens an older library of its major version** — the maintainer: a minor version mismatch "would
  cause denial of service" (#125).
- **Params that ignore unknown fields, so a newer binding runs on an older library** — a silently ignored option is
  worse than an error ([ADR 4.57](/design-docs/adr/4.57-wire-params-answers.md)).
- **A list of the surface that freezes at a release** — the maintainer: "we dont freeze anything" (#125).
- **A version strategy for the releases after the first** — the maintainer: "we do not decide versions release
  strategies in advance, it is impossible in general because each release has its own decision" (#125).
- **A drop-in for the ABI Kensai calls today** — its three-step open, grep-index build and graph build cannot map onto
  one fused walk without walking twice, the cost [ADR 3.6](/design-docs/adr/3.6-graph-build-pass.md) removed, and its
  bare arrays have nowhere to put a count.
- **Typed C structs, or a schema'd binary format** — every answer a C layout marshalled in Go and again in JS, and every
  new count an ABI break.
- **A `cdylib` beside the archive** — no consumer loads one, each crate type is a full link per build, and a shared
  library beside the archive makes `-lkartta_ffi` link dynamically on macOS.
- **A sixth export, `kartta_version`** — a handle on `.` reaches `version`, `kartta_abi_version` needs no handle, and
  one more ABI item freezes (#1047).
- **A stack size on the module's link line** — `#cgo LDFLAGS` cannot state it: cmd/go's allow-list passes `-Wl,-z` for
  `relro`, `now` and `execstack` alone (`security.go`), and a C consumer of the archive holds no such line.
- **A lower nest limit for greps** — it refuses patterns that work, leaves a glob's regex to `globset`, which takes no
  limit, and leaves a plain grep a third of the stack in `dist`.

## Revisit if

A consumer's answers grow large enough that encoding them as JSON shows beside the query that made them. High
confidence: every answer but a `glob` without a limit is bounded by default. A recursion that a call's
input reaches with no bound of its own reopens the stack, and so does a method whose query is cheap enough that 18 µs
shows; high confidence in both, measured on 2,003 calls. A Node package that loads a library it was not built with
reopens the version check for Node; high confidence.
