# Name the pruned name a listing failed on, and count nothing pruned

- **Date:** 2026-10-17
- **Governs:** `crates/kartta-fs/src/list.rs` (`Index::not_found`), `ListError::Pruned`
- **Pinned by:** `crates/kartta-fs/tests/index.rs` (`a_listing_through_a_pruned_name_says_which_name_pruned_it`)

A build prunes names it never indexes ([ADR 1.19](/design-docs/adr/1.19-pruned-names.md)), so a listing asked for a
path through one finds nothing, as it finds nothing for an absent or ignored path. The failure names the pruned name, at
a check made only on the failure; no answer counts the entries a name pruned, since the index keeps no trace of them.

## Decision

- **The pruned name.** A listing asked for a path through a pruned name, `.git` included, fails as `ListError::Pruned`
  and names the first pruned name of the path. An absent or ignored entry answers `ListError::NotFound`. Whether
  anything is there on disk is not known to either.
- **Checked on failure.** The check runs only once the lookup failed, at a comparison per name of the path.
- **Nothing counted.** A listing that holds a directory does not count the pruned entries in it, and a build does not
  report how many entries each name pruned.

## Why

- An agent that reads `NotFound` for a pruned path concludes the entry is absent; naming the name lets it tell a path
  through a name the build prunes from one absent or ignored, and choose its next call.
- A count in a listing would cost memory per pruned entry, and a count of what lies beneath a pruned directory would
  read what pruning exists to skip; [ADR 1.8](/design-docs/adr/1.8-listing-counts.md) counts only what is free.
- A misspelled name needs no report: it leaves the entries it was meant to prune in the index, where every listing shows
  them.

## Consequences

- A listing does not say that a directory held pruned entries; only a path asked through a pruned name learns of one.
  Accepted.

## Rejected

- **Count the pruned entries in each listed directory** — memory per pruned entry, where the index keeps none.
- **Report per name how many entries a build pruned** — what such a count would catch, a misspelled name, already shows
  in every listing.

## Revisit if

A consumer needs to know a directory held pruned entries without asking a path through one. Medium confidence; no
consumer has asked.
