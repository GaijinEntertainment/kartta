# Ship the Node addon as one npm package per target

- **Status:** accepted
- **Date:** 2026-10-18
- **Updated:** 2026-10-18
- **Initiative:** `04-consumer-surfaces`
- **Governs:** `bindings/node/npm/`, `bindings/node/src/target.ts`, `bindings/node/src/kartta.ts` (`load`),
  `bindings/node/package.json` (`engines`)

The Node package needs a native addon for each platform it runs on
([ADR 4.3](./4.3-reach-the-engine-from-node-through-an-addon-over-the-same-dispatch.md)). Each target ships in an npm
package of its own, which npm installs only where it matches, and N-API lets one build serve every Node; the trade is a
platform with no package getting no addon.

## Decision

- The addon ships for macOS on arm64, and for Linux with glibc on x64 and on arm64, each built and tested in CI on a
  runner of its own target.
- One package per target, `kartta-<target>` with `os`, `cpu` and, on Linux, `libc` set, holds `kartta.<target>.node`,
  the naming napi-rs's tooling uses. A target is `<platform>-<arch>`, with `-gnu` on Linux. Their manifests are
  committed under `bindings/node/npm`.
- The package loads the addon a checkout builds beside it, `kartta.<target>.node`, then the target's package. A host
  with neither throws, naming the targets that ship and how a checkout builds one.
- A release adds the targets' packages to the package's `optionalDependencies` at its own version and publishes each.
  Nothing is published yet.
- `engines` asks for Node 24 or later, the newest LTS line, in the package and in each target's package.

## Why

- N-API is stable across Node majors, so one build per target serves every Node the package supports.
- `os`, `cpu` and `libc` let npm skip a target's package that does not match the host, so an install downloads one
  addon.

## Consequences

- A Windows or a Linux musl host gets no addon, and `open` throws there. Accepted.

## Rejected

- **Windows** — no consumer asks for it, and nothing here tests it.
- **Linux with musl** — its Rust target links the C runtime statically and builds no shared library until told not
  to.

## Revisit if

A consumer asks for Windows or musl. Medium confidence that none will before 1.0.
