# Take the one file that differs only in case where a game's vromfs loads it

- **Status:** accepted
- **Date:** 2026-10-17
- **Updated:** 2026-10-17
- **Initiative:** `03-code-graph`
- **Governs:** `crates/kartta-lang-quirrel/src/resolve.rs` (`loaded`), `crates/kartta-lang-blk/src/resolve.rs`
  (`indexed`), `crates/kartta-lang-blk/src/mounts.rs` (`Mount::place`)
- **Pinned by:** `crates/kartta-lang-quirrel/tests/resolve.rs`
  (`a_target_in_another_letter_case_loads_its_sole_case_variant`), `crates/kartta-lang-blk/tests/resolve.rs`
  (`a_target_that_differs_only_in_letter_case_names_its_sole_case_variant`,
  `a_root_path_matches_its_file_in_letter_case`, `a_mount_target_matches_its_name_in_letter_case_and_its_file_without`)

A game reads its shipped scripts and BLK files from a vromfs, whose lookup lowercases the path over names the packer
stores lowercased, so a path that differs from its file only in letter case loads in the game. Where a path the engine
would load names no file exactly, the resolver takes the one file that differs from it only in ASCII case, so such an
include binds, at the price of a lookup without case for each exact miss.

## Decision

1. **The lookup.** A target is asked exactly first, then through `Repository::files_ignoring_case`
   ([ADR 3.30](/design-docs/adr/3.30-case-insensitive-path-lookup.md)). Several files
   that differ only in case name nothing at that target.
2. **Quirrel.** Under a governing `.sqconfig`
   ([ADR 3.9](/design-docs/adr/3.9-quirrel-imports.md)), each place the loader tries is asked
   so, in the loader's order: the file beside the script, then each base path, or the place below a mount. A file in
   another case beside the script therefore wins over a base path's exact one, as the loader takes it, and where one
   place holds several case variants the next place is asked. A script no `.sqconfig` governs matches case.
3. **BLK.** A relative target and a mount target ([ADR 3.10](/design-docs/adr/3.10-blk-includes.md))
   are asked so. A mount whose ancestors hold the target in different cases abstains, as several ancestors that hold it
   do. A `#` root path matches case.
4. **What keeps its case.** A mount name keeps its case in both languages, as the engine reads it, so `%DARG/x.nut`
   names no file where the config mounts `darg`. Quirrel's `.nut` suffix, which tells a script from a native module,
   keeps it too, so `x.NUT` is a native module. The rest of a path, a mounted path's suffix too, matches without case.

## Why

- The vromfs lookup lowercases, and the packer runs on Windows, whose file system ignores case, so a path written in
  another case loads in the game, and the loader takes the first place that holds the file in any case.
- Without a `.sqconfig` the Quirrel mounts are a guess from the directories around the script, and a lookup without
  case would widen the guess.
- A `#` path is matched against the files that end with it, and a lookup of those regardless of case is a second table:
  of the 138 `#` includes on the game-engine tree none names a file in another case alone (2026-10-17).
- Only an exact miss asks the lookup without case, so a path that matches its file costs nothing more.

## Consequences

- On the game-engine tree the rule resolves the 35 BLK includes that named no file, 20 distinct edges, all in one file
  that writes `gameData` for a `gamedata` directory; no Quirrel include changes, since under a config every specifier
  that names a file names it in its own case (2026-10-17).
- A tree with two files that differ only in case at one target loses the include there. No two files of that tree
  differ so. Accepted.

## Rejected

- **Case-insensitive matching through a scan of every file** — a pass over the tree per resolver for the few paths
  that differ only in case.
- **Case-insensitive matching through `files_in_dir`** — finds a file name that differs in case but not a directory
  name, and lists a directory for each include that does not resolve.
- **Every target without case first, an exact match only to break a tie** — the same edges on a tree built on Windows,
  where no two files differ only in case, and a lookup without case for every include, where only the 993,606 exact
  misses of that tree's BLK and Quirrel resolvers ask.
- **A lookup without case for Quirrel's guessed form too** — gains no include on that tree, measured with the lookup,
  and a match in another case under a guessed mount is a guess on a guess.

## Revisit if

A Quirrel script no `.sqconfig` governs, or a BLK `#` include, names a file in another case alone. Neither is seen on
the tree measured.
