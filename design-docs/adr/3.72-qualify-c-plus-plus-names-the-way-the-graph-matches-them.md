# Qualify C++ names the way the graph matches them

- **Status:** accepted
- **Date:** 2026-10-16
- **Updated:** 2026-10-17
- **Initiative:** `03-code-graph`
- **Governs:** `crates/kartta-lang-cpp/src/walk.rs` (`apply_namespace`, `attribute_to_class`, `nest_in_class`,
  `free_namespace_members`), `crates/kartta-lang-cpp/src/walk/name.rs` (`call_target`)
- **Pinned by:** `crates/kartta-lang-cpp/src/walk.rs` (`namespace_members_store_qualified_names`,
  `nested_types_qualify_by_their_enclosing_class`, `an_out_of_line_definition_through_a_namespace_is_a_free_function`,
  `a_conversion_operator_is_a_member`, `root_qualified_calls_and_bases_keep_the_root`)

A C++ name is qualified by namespaces and classes, and the graph matches a call to a definition by the name it spells
and by an owner. The C++ walk qualifies each symbol in the one form those matches read, so a qualified call and a bare
one both find it, at the price of qualified names that do not always spell the full C++ scope.

## Decision

1. A symbol outside every class is qualified by its enclosing named namespaces, `ns::f`; an anonymous namespace adds
   nothing, and `namespace a::b` adds both names.
2. A class member is qualified by its class's bare name alone, `Widget::area`, without the namespace, and is owned by
   it.
3. A type declared in a class body is qualified by the class's own qualified name, `ns::Widget::Kind`, and owned by the
   class.
4. No namespace yields a symbol; it shows in the qualified names of what it holds.
5. A callee written with a named scope keeps the scope as written, `ns::f`, and one written from the root keeps the
   `::`, `::f`.
6. An out-of-line definition takes its owner from the scope it writes, `int ns::Widget::area()` defines
   `Widget::area`, unless the file opens or uses that scope as a namespace and declares no type the written scope
   reaches through the definition's enclosing namespaces or a namespace the file uses: `void ImGui::EndGroup() {}`
   beside `namespace ImGui` defines the free function `ImGui::EndGroup`.
7. A conversion operator, `operator float() const`, is a method of its class.

## Why

- A qualified call, `d3d::clearview()`, matches the qualified name, and a bare call still matches the bare one.
- The graph's match of a call on `this` to the caller's own class, its lookup of a trailing `Owner::name` pair, and
  every receiver's owner read the bare class name a member keeps (ADR 3.7).
- Every file that reopens `namespace ns` would add a namespace symbol, a duplicate, and the prefix on what it holds
  carries the namespace already.
- A nested type qualified by its class's bare name merges the nested types of namesake classes of different
  namespaces; qualified by the class's qualified name, the implementors credited to several namesake types fell from
  620 to 610 on the C++ game-engine tree (2026-10-17).
- Only the file tells a namespace from a class in `bool d3d::clearview() {}`; read as methods, 3,992 such functions of
  the game-engine tree had an owner no class holds (2026-10-17).

## Consequences

- A member's qualified name leaves out its namespaces, so two namesake classes' members share one qualified name; the
  receiver's spelling tells them apart
  ([ADR 3.75](./3.75-name-a-c-plus-plus-call-s-receiver-by-the-class-its-operand-is-declared-as.md)).
- A construction through a nested type's class, `QueryPool::BlockMask_t(1)`, binds only through the graph's match of a
  callee written from its owner alone (ADR 3.7).
- An out-of-line free function is qualified by its namespaces, not by its whole written scope (#442).

## Rejected

- **Reduce a scoped callee, `Class::m()`, to `m`** — the short name binds another class's method of that name in the
  same file, a wrong edge where the scoped one binds nothing or the right one.
- **Emit a symbol per namespace** — one duplicate per file that reopens it, carrying nothing the prefixes lack.
- **Qualify a member by its namespaces too** — moves every member's name off the form the graph's own-class and
  owner-pair lookups match.

## Revisit if

The graph matches a call by a C++ scope chain rather than by a bare owner and a qualified name. Low likelihood while
calls resolve as ADR 3.7 sets out.
