# Extract DSHL as one namespace that its includes join

- **Date:** 2026-10-16
- **Governs:** `crates/kartta-lang-dshl/src/lib.rs`, `crates/kartta-lang-dshl/src/walk.rs`
- **Pinned by:** `crates/kartta-lang-dshl/tests/extract.rs`

`kartta-lang-dshl` extracts DSHL, the shader language of the Dagor Engine, through `tree-sitter-dshl` 1.0.0, a model
taken from the grammar, the language reference and the shader compiler's source. A shader file and its includes compile
as one script, so every declaration is qualified by its own name and exported, at the price that a declaration's read
of a global an included file declares binds nothing.

## Decision

- **One namespace.** A declaration is qualified by its own name and is exported. Each name of a `shader` is a class, a
  `block` an interface, a `macro` a macro, and a render pass, a render pass group and a framebuffer layout each a class.
  A `define_macro_if_not_defined` is a macro flagged as a fallback
  ([ADR 3.23](/design-docs/adr/3.23-dead-code-judgment.md)).
- **Members.** A variable or a sampler at file scope is a variable, a global the engine sets by name; inside a
  declaration it is a field of that declaration, and a `local` variable is a temporary and no symbol. A preshader
  binding, `tex@smp2d = frame_tex`, is a field, a `bool` a constant, and an `interval` an enum whose ranges are its
  variants, `quality.high`. The members of a shader with several names take the first name as their owner.
- **Parents and calls.** `supports` makes each block it names a parent of the declaration around it, of every name of
  a shader with several, the way a type implements an interface, and a use of that block. A macro invocation, in a
  body or in a condition, is a call the declaration around it makes. The conventions let a call reach only a macro:
  no variable or constant (`values_are_call_targets` off) and no member of the caller's owner
  (`OwnMembers::Unreached`).
- **Uses.** A use is a name in a position that reads a declaration: the operands of a condition or an expression, an
  `assume`, a `##if`, `##bool` or `##declare` directive, a preshader value, an initial value, a `shader ==` condition
  and a `pass` statement. The right side of a comparison, the range in `quality == high` or the `NULL` in `tex != NULL`,
  is no use, and neither is a sampler state, a render state, a channel mask, an intrinsic, a hardware feature or a macro
  argument. A use binds as `ValueUses::Declared` binds ([ADR 3.173](/design-docs/adr/3.173-data-use-binding.md)).
- **File scope.** A call or a use at file scope has no symbol around it; the graph keeps its name, which reaches the
  definitions its file and the files it includes declare, as
  [ADR 3.112](/design-docs/adr/3.112-file-scope-names.md) states.
- **HLSL is opaque text.** No HLSL function, structure or `#define` is a symbol and no HLSL call is recorded. Only
  the `#include` lines of an `hlsl { }` block are read, and they resolve as
  [ADR 3.147](/design-docs/adr/3.147-dshl-include-lookup.md) states.
- **Claimed files.** Only `.dshl` is claimed, in any case.

## Why

- The compiler reads a shader file and its includes, each once, as one script, and DSHL has no package or module, so a
  name is visible bare and nothing in an included file is private to it.
- The grammar spells a sampler state, an intrinsic or a macro argument as an identifier, as it does a variable, so only
  a table of parent node and field tells a read of a declaration from a keyword-like value. The graph binds no use to
  an enum variant, and `NULL` declares nothing: 3,614 names on the public Dagor Engine shader tree of 1,134 files would
  bind to nothing (2026-10-16, #36).
- Every DSHL source in the tree ends in `.dshl`, no `.dshl.inl` occurs, and the `.sh` files in the shader directories
  are compile scripts.

## Consequences

- A read inside a declaration of a global that an included file declares binds nothing, though the includes say where
  it is: DSHL has no package and sets no dot import. The contract holds include-reading use tiers
  (`ValueUses::Imported`, `ValueUses::Included`) that DSHL does not take; neither is measured on DSHL (#505).

## Rejected

- **A package for each directory** — binds a game's shader to the copy of `shader_global.dshl` that another game holds.
- **Parse HLSL with a second grammar** — a separate language over the text ranges, out of this crate's scope.

## Revisit if

A DSHL use is measured under a use tier that reads includes. Due: the tiers exist and are unmeasured on DSHL.
