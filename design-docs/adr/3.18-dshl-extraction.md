# Extract DSHL as one namespace that its includes join

- **Date:** 2026-10-16
- **Governs:** `crates/kartta-lang-dshl/src/lib.rs`, `crates/kartta-lang-dshl/src/walk.rs`
- **Pinned by:** `crates/kartta-lang-dshl/tests/extract.rs`, `crates/kartta-languages/tests/dshl_included_uses.rs`

`kartta-lang-dshl` extracts DSHL, the shader language of the Dagor Engine, through `tree-sitter-dshl` 1.0.0, a model
taken from the grammar, the language reference and the shader compiler's source. A shader file and its includes compile
as one script, so every declaration is qualified by its own name and exported, and a use binds what its own file and
the files its includes reach declare, else the file of its scripts that declares the name, of several the copy nearest
the use, at the price that a read no copy is nearest binds nothing, as a library's of each game's copy.

## Decision

- **One namespace.** A declaration is qualified by its own name and is exported. Each name of a `shader` is a class, a
  `block` an interface, a `macro` a macro, and a render pass, a render pass group and a framebuffer layout each a class.
  A `define_macro_if_not_defined` is a macro flagged as a fallback
  ([ADR 3.23](/design-docs/adr/3.23-dead-code-judgment.md)).
- **Members.** A variable or a sampler at file scope is a variable, a global the engine sets by name; inside a
  declaration it is a field of that declaration, and a `local` variable is a temporary and no symbol. A preshader
  binding, `tex@smp2d = frame_tex`, is a field, a `bool` a constant, and an `interval` an enum whose ranges are its
  variants, `quality.high`. The members of a shader with several names take the first name as their owner.
- **Parents and calls.** `supports` makes each block it names a parent of the declaration around it, of every name of
  a shader with several, the way a type implements an interface, and a use of that block. A macro invocation, in a
  body or in a condition, is a call the declaration around it makes. The conventions let a call reach only a macro:
  no variable or constant (`values_are_call_targets` off) and no member of the caller's owner
  (`OwnMembers::Unreached`).
- **Uses.** A use is a name in a position that reads a declaration: the operands of a condition or an expression, an
  `assume`, a `##if`, `##bool` or `##declare` directive, a preshader value, an initial value, a `shader ==` condition
  and a `pass` statement. The right side of a comparison, the range in `quality == high` or the `NULL` in `tex != NULL`,
  is no use, and neither is a sampler state, a render state, a channel mask, an intrinsic, a hardware feature or a macro
  argument. A use binds as `ValueUses::ImportedThenReached` binds
  ([ADR 3.173](/design-docs/adr/3.173-data-use-binding.md)): a declaration of its own file of any kind, else the one
  file it includes directly that declares the name, else the one file those include in turn, however deep.
- **An interval belongs to its variable.** A use that would bind an `interval`, or that two files of one step tie on,
  binds the one variable of the name its file's include closure holds. With no such variable, or with two, it binds as
  above. A file's own shader or constant of the name keeps the use.
- **What an includer declares.** A use all of that leaves unbound binds, at 60, the one file that declares the name
  among every file sharing an include root with the use's file: the scripts its file compiles in, however many. Of
  several such files, whichever root holds them, the one that shares the most leading directories with the use's file
  binds, at 60, where it shares at least two. Copies equally near bind neither. A use bound to an interval stays bound.
- **File scope.** A call or a use at file scope has no symbol around it; the graph keeps its name, which reaches the
  definitions its file and the files it includes declare, as
  [ADR 3.112](/design-docs/adr/3.112-file-scope-names.md) states.
- **HLSL is opaque text.** No HLSL function, structure or `#define` is a symbol and no HLSL call is recorded. Only
  the `#include` lines of an `hlsl { }` block are read, and they resolve as
  [ADR 3.147](/design-docs/adr/3.147-dshl-include-lookup.md) states.
- **Claimed files.** Only `.dshl` is claimed, in any case.

## Why

- The compiler reads a shader file and its includes, each once, as one script, and DSHL has no package or module, so a
  name is visible bare and nothing in an included file is private to it.
- The grammar spells a sampler state, an intrinsic or a macro argument as an identifier, as it does a variable, so only
  a table of parent node and field tells a read of a declaration from a keyword-like value. The graph binds no use to
  an enum variant, and `NULL` declares nothing: 3,614 names on the public Dagor Engine shader tree of 1,134 files would
  bind to nothing (2026-10-16, #36).
- Every DSHL source in the tree ends in `.dshl`, no `.dshl.inl` occurs, and the `.sh` files in the shader directories
  are compile scripts.
- `ValueUses::Imported` keeps every binding `Declared` holds and adds 3,898 use pairs on dagor's 1,813 DSHL files, right
  in 60 of 60 sampled (2026-10-31, #505). A shader file names what its includes declare: a global, a block it
  `supports`, a render pass.
- The compiler reads every file the includes reach, so walking them adds 2,395 use pairs on dagor, right in 29 of 30
  sampled, and removes none (2026-10-31, #758).
- The compiler takes an `interval` whose name a global holds as an override of that global's ranges, and a condition
  tests the global's value against them. Reading the interval as the variable's moves 55 reads off an interval and binds
  3 that tied, 58 pairs on dagor, right in 30 of 30 sampled of each side (2026-10-31, #788).
- A library file reads what the shader file around it declares, a macro's `shader ==` condition the shaders that expand
  it. Of 2,748 uses on dagor no own closure answers, 655 name one file of their scripts, so walking up adds 779 use
  pairs, right in 54 of 60 sampled, and removes none (2026-10-31, #789).
- A game keeps its own copy of a global's file, and nothing in the tree marks a game, so nearness stands in for one as
  it does for an include ([ADR 3.147](/design-docs/adr/3.147-dshl-include-lookup.md)). It adds 135 use pairs on dagor,
  right in 29 of 30 sampled, and removes none (2026-10-31, #809).

## Consequences

- A name two files of a use's scripts declare binds neither where no copy is nearest past the top directory: 210 uses
  on dagor, as a library file two games include that reads each game's `shader_global.dshl` (#809). Accepted.
- A library file's read binds the nearest declaration of its scripts though another library wrote it for another
  purpose: 2 of the 135 pairs on dagor, each with 1 of the use's scripts compiling both files (#809). Accepted.
- A game whose files share only its top directory ties as a library does. None on dagor (#809). Accepted.
- A use binds the one file though other scripts of its file do not hold it: a `shader ==` condition in a file 69 scripts
  include names a shader one of them declares (#789). Accepted.
- The graph expands no macro, so a read of what a macro writes through its parameter binds a declaration of that name:
  37 of the 779 pairs on dagor read a `bool` one macro names after a shader and bind the shader, and 1 reads a parameter
  and binds a global (#789). Accepted.
- 8 of the 779 pairs bind a game's read to another game's file, through a library file's nearest-copy include. Accepted.
- An interval a library file writes keeps its reads, though a script holds the variable: of the 38 pairs on dagor, 29
  have no variable of the name in any script and 9 have two (#789). Accepted.
- An interval lists no read its variable takes, though the ranges a comparison names are its own: `find_references` of
  the interval answers fewer sites, 55 on dagor (#788). Accepted.
- A variable and a shader of one name in two included files bind the variable, a `shader ==` condition among them. None
  on dagor (#788). Accepted.
- Past the direct includes, 74 of the 2,395 pairs on dagor bind a game's read to another game's copy, through a library
  file whose include resolves to the nearest copy ([ADR 3.147](/design-docs/adr/3.147-dshl-include-lookup.md)).
  Accepted.
- A read of a name its own file declares as a shader binds the shader, even where an include declares a value of the
  name and the compiler reads that value. None on dagor: of 28,663 uses, 1,365 name a shader of their file in a
  `shader ==` or `shader !=` condition, which wants it, and the 17 value reads of such a name bind a value their own
  file declares first (2026-10-31, #759). Accepted.
- A use that its own file and direct includes do not answer reads its file's include closure, computed once per query
  and file, and the definitions of its name. One its closure leaves unbound reads the include roots of its file and of
  the files declaring the name, also once per query and file: the slowest query on dagor takes 0.8 ms (2026-10-31,
  #789).

## Rejected

- **`ValueUses::Declared`** — leaves a read of a global an included file declares unbound: 3,898 pairs on dagor (#505).
- **`ValueUses::Imported`** — leaves a read past the first include unbound: 2,395 pairs on dagor (#758).
- **`IncludeReach::Transitive`** — also binds a macro's one callable only where the closure reaches it, so it removes
  472 call pairs on dagor; 28 of 30 sampled leave a real macro call unbound, whose include the resolver cannot follow
  (#758).
- **The 32-definition limit of [ADR 3.42](/design-docs/adr/3.42-transitive-include-reach.md)** — counts the copies each
  game keeps and every field of the name, and drops 439 of the 2,395 pairs on dagor; no code outside the graph declares
  a DSHL global (#758).
- **`ValueUses::Included`** — it binds no type or macro, so it drops 1,494 pairs on dagor, the `shader ==` conditions
  and the `supports` of a declaration in the same file; 0 of 30 sampled removals were right (#505).
- **Recording `shader ==` and `pass` as `Access::Type`, so that a read takes an included value over its file's shader**
  — moves no binding of dagor's 19,139 use pairs and turns the access of 1,427 of them from read to type (#759).
- **A shader that gives way to a value its file's includes reach, whatever the position** — the one such name on dagor,
  `rendinst_clipmap`, is named only by a `shader ==` condition, which wants the shader (#759).
- **A value position that binds no class** — a shader and a render pass are both classes, and 24 preshader values on
  dagor read a render pass, as `g0@subpass_read = rp_main.gbuf0` does (#759).
- **A rule for ties alone** — binds the 3 reads that tied and leaves 55 on an interval, so `find_references` of
  `special_vision` on dagor still selects an interval and passes the `int` over (#788).
- **Dropping the interval as a target** — unbinds the 38 use pairs on dagor whose closure holds no one variable of the
  name, as a library file that a game's own files include does (#788).
- **The declarations of the includers alone** — leaves out a global another include of an includer declares: 358 uses on
  dagor name one includer, where 655 name one file of their scripts (#789).
- **A list of each file's scripts, merged from the closures of its roots** — the same pairs at 75% more instructions
  over a whole-language sweep on dagor, where the cached roots cost about 20% (#789).
- **The one variable of a use's scripts ahead of an interval or a tie** — moves none of the 38 pairs on an interval and
  adds 4 pairs on dagor (#789).
- **The nearest copy however few directories it shares** — adds 168 use pairs on dagor, all from a library under `prog`
  bound to the copy under `prog/daNetGame` for that one directory, though another game compiles the file too (#809).
- **A package for each directory** — binds a game's shader to the copy of `shader_global.dshl` that another game holds.
- **Parse HLSL with a second grammar** — a separate language over the text ranges, out of this crate's scope.

## Revisit if

The graph learns which build configuration compiles a file: a library file's include would then follow each game's
copy, and the walk would bind a game's read to its own. Confidence in the current tier is high on dagor, the one tree
that holds DSHL.
