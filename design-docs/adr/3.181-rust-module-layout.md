# Find Rust crate roots and module files by Cargo's layout

- **Date:** 2026-10-16
- **Governs:** `crates/kartta-lang-rust/src/resolve.rs`, `crates/kartta-lang-rust/src/manifest.rs`,
  `crates/kartta-lang-rust/src/walk.rs` (`mod` declarations and `#[path]`)
- **Pinned by:** `crates/kartta-lang-rust/tests/resolve.rs`

A Rust file reaches other files only through `mod` declarations, whose targets Cargo's layout decides, and which file is
a crate root decides where a `mod` looks. `kartta-lang-rust` finds crate roots from the conventional layout and each
manifest's library, so a target that a manifest places elsewhere is no crate root.

## Decision

- **Module files.** A bodiless `mod NAME;` includes `NAME.rs` or `NAME/mod.rs`: beside a crate root or a file named
  `lib.rs`, `main.rs` or `mod.rs`, under the directory named for any other file's stem, and one directory deeper for
  each inline module around the declaration, so `mod inner { mod child; }` in `src/lib.rs` pulls in
  `src/inner/child.rs`. A `#[path]` override is relative to the declaring file's directory, or inside an inline module
  to that module's directory, read as written without decoding escapes; an inline module's own `#[path]` is not read.
- **Packages and crate roots.** A directory that holds a `Cargo.toml` is a package. Its crate roots, judged against the
  nearest package, are the file its manifest's `[lib] path` names, `src/lib.rs`, `src/main.rs`, `build.rs`, and each
  target under `src/bin/`, `examples/`, `tests/` and `benches/`, as a file or as a directory with a `main.rs`.
- **Entry points.** A top-level `fn main` in a crate root of that layout other than `src/lib.rs` is the entry point, in
  each of its `cfg` alternatives; a file that only its manifest's `[lib] path` makes a crate root is none.
- **What the resolver reads.** The resolver lists the packages once and reads each manifest only for its library
  ([ADR 3.50](/design-docs/adr/3.50-rust-cross-crate-paths.md)) and its dependencies
  ([ADR 3.179](/design-docs/adr/3.179-rust-crate-reach.md)), so another target that a manifest places off the layout is
  no crate root and no entry. It keeps only what it derived, the packages, each library's name and root and the
  packages each is built with, and compares that on a rebuild, as
  [ADR 3.82](/design-docs/adr/3.82-followed-resolver-rebuilds.md) decides.

## Why

- The packages turn the conventional targets into crate roots: against crate roots told by file names alone they add
  355 includes, the `mod common;` of integration tests, and 104 entry points of build scripts, benchmarks and tests
  without the default harness (cargo registry of 16,978 Rust files, 2026-10-16, #36).
- Every `lib.rs` off the layout in a registry of 447 crates is a library that a `[lib] path` places, as the
  `bindings/rust/lib.rs` of each tree-sitter grammar (2026-10-16, #36); a `[lib] path` of another name, tree-sitter's
  `crates/cli/src/tree_sitter_cli.rs`, included none of its 17 modules until it was a crate root (2026-10-23, #384).

## Consequences

- A target that `[[bin]]`, `[[test]]` or an `auto*` key places off the layout is no crate root: its `mod`s look under
  its stem and its `fn main` reads as dead code. The registry loses 6 entry points of a fuzzing directory whose manifest
  the published package left out (#36). Accepted.
- A `#[path]` value with an escape names the wrong file; none of the registry's 1,601 `#[path]` attributes writes one
  (#36). Accepted.

## Rejected

- **Crate roots by file names alone** — a crate root such as `tests/it.rs` or `build.rs` looks for its submodules under
  its own stem, where none is, and a build script's `fn main` reads as dead code.
- **Reading every manifest target** — finds what `[[bin]]` and the `auto*` keys place off the layout, at the cost of a
  TOML parser and a read of every target key whenever the resolver is built.

## Revisit if

A consumer needs the targets that a manifest places off Cargo's layout. None asks yet; every off-layout `lib.rs` of the
447-crate registry was a `[lib] path` library, which the manifest read covers.
