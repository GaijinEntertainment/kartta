# Mark the definitions find_unused lists that their language exports

- **Date:** 2026-11-27
- **Governs:** `crates/kartta-mcp/src/render/unused.rs`, `crates/kartta-graph/src/dead.rs` (`DeadCode::exported`),
  `kartta_lang::Exports`, `Conventions::exports`
- **Pinned by:** `crates/kartta-mcp/tests/graph.rs`
  (`find_unused_marks_what_a_language_exports_and_counts_it_past_the_limit`),
  `crates/kartta-graph/tests/graph/dead_code.rs`
  (`the_dead_a_language_exports_are_counted_past_the_limit_and_not_where_it_records_no_export`),
  `crates/kartta-lang-quirrel/tests/extract.rs` (`a_bare_call_in_a_member_reaches_the_class_first`)

In a library, `find_unused` lists the public API among its candidates, since nothing in the repository calls it. Each
record its language exports carries a mark and the envelope counts them, read from the export bit the extraction
already stores, so an agent sets the API aside without reading each definition; a language whose bit does not follow
its rule marks and counts nothing, and the answer says so.

## Decision

- **The mark.** A `<symbol/>` record whose definition the extraction marks exported (`Symbol::exported`, the bit
  [ADR 3.22](/design-docs/adr/3.22-change-impact-analysis.md)'s reach bands weigh) carries `exported="true"`.
- **The count.** The envelope's `exported=` counts the dead definitions so marked before the limit, as
  `DeadCode::exported` counts them, and is written only when it is not zero. It counts a part of `total=`, not a list
  ([ADR 4.71](/design-docs/adr/4.71-mcp-count-vocabulary.md)).
- **A language that records no export.** A language whose extraction marks a definition exported that the language
  keeps to its file states `Exports::Unrecorded`: its graph counts none, its records carry no mark, and a `<note>`
  names its graph when that graph found a dead definition. Quirrel states it (#1333): its walk marks every definition
  exported, yet a function, a class, a `let` or a `local` at file scope is local to its file, which hands out only what
  it returns (Quirrel, `doc/content/pages/coming-from/squirrel.md:48`, `doc/content/pages/language/bindings.md:9`).
- **Every other language** marks by its extraction's rule, which its own ADR states. Bash and DSHL let any file that
  loads a definition name it ([ADR 3.13](/design-docs/adr/3.13-bash-extraction.md),
  [ADR 3.18](/design-docs/adr/3.18-dshl-extraction.md)), so each of their records carries the mark. Puppet's walk marks
  every definition too; its grammar gives `private` no meaning (Puppet, `lib/puppet/pops/parser/egrammar.ra:742`), and
  whether every manifest can name every definition is unsettled.

## Why

- On spf13/afero v1.15.0 each of the 21 definitions `find_unused` lists is exported (2026-11-27), so a library's list
  read as candidates for deletion that its callers outside the repository use.
- The bit is stored for every symbol and the reach bands already read it, so the mark costs one test per listed record
  and the count one addition per dead definition. A rule of export kept beside it would drift from the one the bands
  weigh.
- A mark that a language puts on every definition whatever its source says would read a file's private helpers as
  its API.

## Consequences

- The mark is as right as each extraction's bit, and a shape the bit gets wrong marks wrongly, as a C++ class's
  private method marked exported or a JavaScript script's top-level function left unmarked. Not counted (#1335).
- The C ABI wire keeps the bit on each listed definition of a language that records no export, Quirrel's included, and
  its part leaves `exported` out to say so ([ADR 4.57](/design-docs/adr/4.57-wire-params-answers.md)). Accepted.

## Rejected

- **A parameter that leaves the exported definitions out** — each record carries the mark and the envelope the count,
  and a parameter is description text every session pays for, as
  [ADR 4.1](/design-docs/adr/4.1-mcp-server-tools.md) found for a kinds filter.
- **Count the listed records alone** — a list the limit cut would count as if it held every dead definition.
- **Judge export in the server, by each language's rule** — a second rule beside the one the extraction records and
  the bands weigh.

## Revisit if

Quirrel's extraction reads what a file returns as its exports, or a sample of the marked records finds the bit wrong on
a language for most of them. Medium confidence: 30 of 30 sampled marked records and 30 of 30 unmarked ones on dagor
and the Go monorepo snapshot followed their language's rule (2026-11-27), and no language was sampled on its own.
