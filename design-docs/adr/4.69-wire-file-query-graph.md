# Name the graph that answers a wire file query, or why none does

- **Date:** 2026-11-07
- **Governs:** `crates/kartta-ffi/src/wire/graph.rs`, `crates/kartta/src/engine.rs` (`Engine::symlink`), the
  `outline`, `dependents`, `analyze_segment` and `analyze_change` methods
- **Pinned by:** `crates/kartta-ffi/tests/dispatch.rs`
  (`a_file_answer_tells_a_missing_path_an_unclaimed_file_and_a_declined_one_apart`,
  `a_file_answer_tells_a_directory_from_a_held_file`, `a_file_answer_names_where_a_symlink_points`,
  `a_change_counts_its_regions_of_special_files_apart`)

A file query of [ADR 4.2](/design-docs/adr/4.2-c-abi-wire.md)'s wire asks about one path, and the path may name
nothing a graph holds. The answer names the graph that claims the file, or the cause no graph answers, and a change
counts its regions apart by the same causes, so the consumer can choose its next call from the answer alone.

## Decision

- **A file's answer.** A file query (`outline`, `dependents`, `analyze_segment`) answers the `graph` that claims the
  file and if it is `held`, and says why no graph answers:
  - `missing` for a path the index does not hold and `directory` for one it holds as a directory, neither of which
    names a graph;
  - `symlink` for one it holds as a symlink, which no graph holds, and `special` for one it holds as a socket, a fifo
    or a device node, which no graph holds either;
  - `declined` with the language that leaves the held file out and the reason it states;
  - none of them for a held file no language claims.
- **A symlink's target.** `symlink` carries the target as the link stores it, when the walk read it as UTF-8, and, when
  the target names an entry the index holds, inside the root and through no symlink, that entry's path and kind, which
  [`Engine::symlink`](/crates/kartta/src/engine.rs) reads without following a link.
- **A change's regions.** `analyze_change` counts its regions apart by the same causes: `missing_regions`,
  `symlink_regions`, `directory_regions`, `special_regions`, `unclaimed_regions`, and `declined` per language and
  reason, within `unheld_regions`, whose rest are regions of held files the claiming graph holds no record of.

## Why

- A file answer chooses the consumer's next call: a missing path asks for another spelling, a directory for one of its
  files, a symlink for the path its target names, a special file for no read, which blocks on a fifo, and a held file no
  graph answers for, a read or a grep (#1162, #1173, #1177, #1184).
- Counted with the unclaimed files or the claiming graph's rest, a symlink's or a directory's region reads as a file no
  language claims or one that graph lost (#1185).

## Consequences

- A region's cause costs no work past the lookup each region already pays, which gives the entry's kind (#1185).
  Accepted.

## Rejected

- **`not_found` for a file query's missing path**, as `list` answers one — a caller that read an `ok` answer for that
  call meets an error, and `analyze_change` counts such a file in `unheld_regions` rather than refusing it (#1162).
- **`invalid_params` for a directory region**, as `impact_of_change` refuses one — the change answer counts a region it
  cannot read rather than refusing the call, as it counts a missing path (#1162, #1185).
- **`missing` for a directory** — it tells the caller to try another spelling, where the fix is to ask about one of the
  directory's files (#1173).
- **A symlink's target read by its text alone** — a `..` after a symlink leaves the directory the link points to, so
  `dir/../a` names `pkg/a` where `dir` links to `pkg/sub`, and the text names the root's `a`
  (`library/std/src/path.rs:3422-3423` at the pinned Rust).
- **No `graph` on a symlink's or a special file's answer** — it removes a key a released answer holds; `symlink` or
  `special` beside it already says that no graph holds the path.

## Revisit if

The walk holds an entry kind none of these causes names. High confidence: `kartta_walk::EntryKind` is a directory, a
file, a symlink or other, and other is the special files.
