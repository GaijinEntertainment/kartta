# Record no Rust call through a value, and bind a call of a body's item as a local call

- **Date:** 2026-10-16
- **Governs:** `crates/kartta-lang-rust/src/walk/blocks.rs`, `crates/kartta-lang-rust/src/walk/bindings.rs`,
  `crates/kartta-lang-rust/src/walk/calls.rs` (`call`)
- **Pinned by:** `crates/kartta-lang-rust/tests/modules.rs`
  (`a_plain_call_binds_only_a_callable_item_of_a_block_in_its_own_module`,
  `a_path_call_binds_the_item_that_its_module_path_names`, `a_use_or_a_let_shadows_a_block_item`,
  `a_parameter_shadows_a_block_item_in_its_own_function_body`,
  `a_macro_call_binds_only_a_macro_of_a_block_after_its_definition`,
  `an_item_in_an_extern_block_is_an_item_of_the_block_around_it`),
  `crates/kartta-lang-rust/tests/extract.rs::a_call_through_a_parameter_or_a_local_is_no_call`,
  `crates/kartta-languages/tests/engine.rs::a_rust_call_through_a_parameter_or_a_local_binds_nothing`

A function body can declare items no other file reaches, and can bind names to values that a call then invokes. The walk
binds a call of a body's item in the extraction, as a local call, and records no call for a name a pattern binds, so
neither reaches the graph's name tiers to bind a namesake.

## Decision

- **A body's own item.** A call inside a function body of an item that a block around it declares is a local call of
  that item, which the cascade binds first ([ADR 3.172](/design-docs/adr/3.172-bare-call-binding.md), tier 1). Such an
  item is a function, a constant, a static, a unit or tuple struct, whose name is its constructor, a `macro_rules!` or
  an inline module; a struct with named fields names no value. An item of an `extern` block is an item of the block
  around the `extern` block.
- **Where a body's item reaches.** An item is in scope in its whole block, within the inline module around it; a
  `macro_rules!` only after its definition, and also inside an inline module, since a macro is in scope by text order.
- **Which item a call binds.** A plain call binds a value item and a macro invocation a macro item, the innermost of the
  name. A `use` of the name in a block around the call, `self` in a list included, shadows the item, and the call stays
  a call the graph resolves.
- **Path calls.** A path call binds an item of a module of the block that its path names, through `self::` and `super::`
  too.
- **Calls through a value.** A bare call of a name that a pattern binds is no call: a parameter, a `let`, a closure's
  parameter, a match arm, a `for`, an `if let` or a `while let`, as `helper()` in `fn f(helper: fn())` or `run()` after
  `let run = || {};`. It calls the value the name holds, whatever the file imports or declares under the name. A binding
  hides its name from the end of what it reads on: a parameter in its function or closure, a match arm's pattern in the
  arm, a `for`'s in its body, an `if let`'s or a `while let`'s in the operands after it and the branch it runs on a
  match, and a `let`'s to the end of its block. A function's own region ends the lookup, so a function nested in a body
  sees no local of the one around it. A pattern binds its identifiers, never the type a struct or tuple-struct pattern
  names.
- **Inside a macro's arguments.** [ADR 3.54](/design-docs/adr/3.54-rust-macro-argument-calls.md) applies both
  rules there.

## Why

- No other file can reach an item a body declares, so a name tier could only bind a namesake elsewhere.
- A call through a parameter or a local bound a namesake: all 29 such pairs removed on this repository and the Go
  monorepo snapshot were wrong, a parameter `each` of kartta-fs's postings taking kartta-ffi's `fn each` among them
  (2026-10-23, #400). C++ and Quirrel record no call through a value either
  ([ADR 3.75](/design-docs/adr/3.75-cpp-call-receivers.md),
  [ADR 3.144](/design-docs/adr/3.144-quirrel-value-calls.md)).

## Consequences

- A call of a closure or a function pointer binds nothing, so `find_callers` of a function passed as a value lists no
  call made through the value. Accepted.

## Rejected

- **A call through a value kept where the file defines a function of its name**, Quirrel's exception — keeps 2 of the
  23 pairs removed on this repository, both wrong, as kartta-fs's `extension()` calling the closure `let extension =
  || ..` and taking the file's `fn extension` (2026-10-23); a Rust closure or parameter is never the file's named item,
  and a function a body declares binds as a local call already.

## Revisit if

A consumer needs the callable that a closure or a function pointer holds. None asks; every sampled pair through a value
was wrong.
