# Name a PHP anonymous class by the names that lead to it

- **Date:** 2026-10-23
- **Governs:** `crates/kartta-lang-php/src/walk.rs` (`anonymous_class`, `forget_holder`, `held_receiver`,
  `enclosing_type`)
- **Pinned by:** `crates/kartta-lang-php/tests/php.rs`
  (`a_member_of_an_anonymous_class_is_owned_by_the_class_the_walk_names`,
  `an_anonymous_class_is_named_by_its_creator_and_the_name_it_is_assigned_to`,
  `an_anonymous_class_is_constructed_by_the_callable_that_creates_it`,
  `a_call_on_a_variable_holding_an_anonymous_class_names_the_class_as_its_receiver`,
  `a_trait_use_in_an_anonymous_class_is_a_parent_of_that_class_alone`)

The members of `new class { ... }` sit in a class the source gives no name, and `$this->m()` inside it calls one of
them. Such a class becomes an unexported class named by the names that lead to it, which owns its members, so a call
through `$this` binds its own member, at about 2.3 KB of heap for each.

## Decision

- **The name.** An anonymous class is an unexported class symbol named by the names that lead to it joined by `·` in
  braces, which no PHP name holds. The names are the callable that creates it, after that callable's owner, then the
  variable or the property it is assigned to: `{Suite·testRun·job}` for `$job = new class {}` in `Suite::testRun`, and
  `{class}` where no name leads to it, as for a migration's `return new class extends Migration` at file scope.
- **A repeated name.** A name the file has given already takes a count, `{Suite·testRun·2}`. A class created in an
  anonymous class's method takes that class's name without its braces among its names.
- **Members, parents and creation.** Its members are owned by the name and qualified by it,
  `App\{Suite·testRun·job}::handle`. Its `extends`, `implements` and trait uses are its parents. Its creation is a call
  of it, as `new Foo()` calls `Foo`.
- **A variable that holds the class.** A call on a variable that its callable last assigned an anonymous class to
  records the class's name as its receiver, so `$job->handle()` binds the class's member. Another assignment to the
  variable ends it, and a variable of the name in another callable is another variable.

## Why

- With an owner, the caller's owner binds `$this->m()`, and a base the graph holds binds `$this->attach()` in a class
  extending `Mailable`.
- Without an owner, calls bound the anonymous method by proximity from outside the class: all 30 sampled on each of
  Laravel's framework and Symfony were wrong, a validator's `$v->passes()` among them (2026-10-23, #246).
- A name built from the callable and the variable stays put when lines are written above the class, and repeats
  across files rarely: one of Laravel's and Symfony's 1,437 names occurs in two files (2026-10-23, #246).

## Consequences

- The heap after a build holds about 2.3 KB more for each anonymous class, the name and its members' longer qualified
  names (Symfony, 2026-10-23, #246). Accepted.

## Rejected

- **A name by the line, `{class·12}`** — the name moves with every line written above it, and 199 of Symfony's 522
  such names occur in several files.
- **The class owned by its variable, `$job`** — the receiver's owner tier reads that name in every file:
  `$client->request()` across Symfony binds a test's anonymous client, and next to none of 30 sampled new pairs is
  right.
- **Members owned, with no receiver for a variable that holds the class** — 55 true calls on such a variable bind
  nothing, and 32 bind by proximity.

## Revisit if

A shorter name keeps a file's anonymous classes apart. The tier binding through the caller's owner prefers the
caller's file ([ADR 3.41](/design-docs/adr/3.41-own-owner-receivers.md)), so a namesake in another file binds only
where the caller's file holds no member of the name; whether a shorter name keeps the classes apart is not measured.
