# Read a PHP value in parentheses as the value inside, and a call on a `new` as a call on its class

- **Date:** 2026-11-01
- **Governs:** `crates/kartta-lang-php/src/walk.rs` (`inside_parentheses`, `assigned_value`, `called_value`,
  `called_class`, `call_target`, `assignment_target`, `creates_an_anonymous_class`)
- **Pinned by:** `crates/kartta-lang-php/tests/held_classes.rs`, `crates/kartta-lang-php/tests/field_classes.rs`,
  `crates/kartta-lang-php/tests/narrowed_classes.rs`, `crates/kartta-lang-php/tests/php.rs`,
  `crates/kartta-languages/tests/php_parenthesized_values.rs`

The grammar keeps a node for a pair of parentheses where PHP keeps none, so a value written in them read as nothing, and
a call on a `new`, which is nearly always written in them, took the name tiers. Every reader of a value reads past the
parentheses, and a call on a `new` has the created class as its receiver, at the price of the calls on an anonymous
class.

## Decision

- **Parentheses.** A value in parentheses, at any depth and with any comment beside it, is the value inside. A write
  ([ADR 3.202](/design-docs/adr/3.202-php-property-classes.md)), a variable's `new`
  ([ADR 3.199](/design-docs/adr/3.199-php-variable-classes.md)), a chain's end, a closure bound to a variable
  ([ADR 3.155](/design-docs/adr/3.155-php-member-owners.md)), an anonymous class's name
  ([ADR 3.156](/design-docs/adr/3.156-php-anonymous-classes.md)) and an `instanceof` subject all read it so.
- **A call on a value.** A member or scoped call reads the value it runs on as a write reads the value it stores, past
  parentheses and to the end of a chain. `(new X)->m()`, `new X()->m()`, `(new X)::m()`, `($v = new X)->m()` and
  `($w)->m()` under a `$w` that holds `X` have `X` as their receiver, spelled as a variable's is. `($this->c)->m()` and
  `(self::$c)->m()` read the property's table, and `($v)->m()` under no class keeps `$v`.
- **What stays.** A name in parentheses, `(Foo)::m()`, is a constant's value and keeps the empty receiver, as do
  `(new $c)->m()`, `(clone $v)->m()`, `(new X)->a()->m()` and an anonymous class's `(new class {})->m()`.

## Why

- `'(' expr ')'` yields the expression itself and builds no node (`Zend/zend_language_parser.y`, php-src 8.5.12), and
  "the type and value of parenthesized expression are identical to those of the un-parenthesized expression"
  (php-langspec `spec/10-expressions.md`, Primary Expressions). The parser's three marks on a parenthesized expression
  steer a nesting rule, a pipe and `parent::$c::get()` (`Zend/zend_compile.c`) and move no value. Every shape above ran
  on `php:8.5.12-cli`, as did a parenthesized `new` passed as an argument, which takes the same class and which the walk
  reads no differently.
- `(Foo)::m()` calls `m` on the class the constant `Foo` names, not on a class `Foo` beside it (`constant`,
  `Zend/zend_language_parser.y`; run on `php:8.5.12-cli`).
- `new` makes an object of exactly the class it names ([ADR 3.199](/design-docs/adr/3.199-php-variable-classes.md)), and
  `::` on an object fetches that object's class ([ADR 3.202](/design-docs/adr/3.202-php-property-classes.md)).
- On Laravel and Symfony the rule adds 2,245 pairs, removes 652 and promotes 3,416 to 85. Of samples of 30 all are
  right, and so are 30 more of the added pairs off the owners that lead the pool. The assignments alone move 68 of those
  pairs, each read right; the rest are calls on a `new`. A removed pair bound a namesake or the caller's own member, as
  `(new CheckTypeDeclarationsPass(true))->process()` bound `ResolveParameterPlaceHoldersPass::process`
  (2026-11-01, #954).

## Consequences

- An anonymous class has its name only once the walk reaches it, past the call on it, so `(new class {})->m()` keeps the
  empty receiver and the name tiers answer: 37 sites on Laravel and Symfony (2026-11-01, #974).
- A class outside the graph binds nothing and no namesake
  ([ADR 3.167](/design-docs/adr/3.167-php-outside-class-calls.md)): 88 of the removed pairs leave their line unbound,
  each a `new` of such a class, as `(new \ReflectionClass($x))->getAttributes()` (2026-11-01, #954). Accepted.
- A property default of `(null)` reads as a value. No such default on the two trees (2026-11-01, #954). Accepted.

## Rejected

- **Reading parentheses in each reader's kind match** — each reader then spells the same step, and the ones the walk
  grows later miss it.
- **Parentheses for writes alone, leaving `(new X)->m()` to the name tiers** — the writes alone move 68 pairs, and the
  shape that makes up nearly all of the delta stays with a guess.

## Revisit if

The grammar stops keeping a node for parentheses, or PHP gives a parenthesized value a meaning of its own. High
confidence.
