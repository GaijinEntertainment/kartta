# Derive a language's fingerprint from its code and its dependencies' versions

- **Date:** 2026-10-16
- **Governs:** `crates/kartta-lang/src/fingerprint.rs` (`set_source_id`), `crates/kartta-lang/src/tree.rs`
  (`fingerprint`, `tree_sitter_fingerprint!`), `crates/kartta-lang-*/build.rs`, `kartta_lang::Language::fingerprint`,
  `kartta_lang::FINGERPRINT`
- **Pinned by:** `crates/kartta-lang/src/fingerprint.rs`
  (`a_crate_s_source_identity_changes_with_the_grammar_version_its_manifest_pins`,
  `the_lock_resolves_each_dependency_the_manifest_names_and_no_other`,
  `an_update_only_the_lock_records_changes_the_identity`)

A cache hands one extraction to every file with the same bytes
([ADR 3.1](/design-docs/adr/3.1-language-plugin-contract.md)), so what keys it must change whenever what `extract`
computes from those bytes can. A language derives its fingerprint from its crate's code and the versions its
dependencies resolve to, never from a version kept by hand, at the price of a cache that starts cold after any change to
the crate.

## Decision

- **The language owns it.** A language owns its fingerprint, and it changes whenever the grammar, the walk or the shape
  of the result can change what `extract` computes from the same bytes. A cache keeps each fingerprint's extractions
  apart.
- **The source identity.** A language crate's build script calls `kartta_lang::fingerprint::set_source_id`, which sets
  `SOURCE_ID`: the crate's name, its version, and a digest of its `Cargo.toml`, of the versions a `Cargo.lock` in a
  directory above the crate resolves for its `[dependencies]`, and of its `.rs` files under `src`. An update of the
  grammar crate or of tree-sitter changes it, whether the manifest's requirement or only the lock moved.
- **No lock.** A build that sees no lock, such as one from a registry, digests the manifest's version requirements
  alone.
- **Tree-sitter languages.** A language that extracts through tree-sitter takes its fingerprint from
  `kartta_lang::tree_sitter_fingerprint!`: `SOURCE_ID`, then the grammar's version metadata, a digest of its node
  types, and its ABI version and counts of node kinds, parse states and fields, built once per process.
- **`kartta-lang`'s own identity.** `kartta_lang::FINGERPRINT` is the same identity of `kartta-lang` itself, whose
  helpers and encoding shape a cached extraction too; the cache keys an extraction by both, as
  [ADR 3.6](/design-docs/adr/3.6-graph-build-pass.md) names the namespace, so a language's fingerprint covers its own
  code and grammar only.

## Why

- A grammar's own version metadata does not follow its releases: in 2026-10 four of the fifteen grammars kartta ships
  (C++, Puppet, Ruby, TypeScript) carried none, and Rust's said 0.24.1 in crate 0.24.2, so a bump that kept node types
  and table counts left every cached extraction as it was (#108).
- A version kept by hand is a step every change to a language must remember; a missed bump serves extractions of the
  old code.

## Consequences

- Any change to a language crate's sources, a comment included, gives a new fingerprint, and the cache extracts that
  language's files again; accepted.
- A dependency renamed through `package` is not matched in the lock; no language crate renames its grammar or
  tree-sitter; accepted.

## Rejected

- **A version kept by hand** — a change that forgets the bump leaves stale extractions in every cache.
- **The grammar's own version metadata** — missing in four of fifteen grammars, and wrong in Rust's.

## Revisit if

A language's extraction comes to depend on something outside its crate's sources, its manifest and its locked
dependencies, such as a data file read at build time. High confidence: every shipped language extracts from code and
grammars alone.

## History

- 2026-10-19 — The source identity: it digested only the crate's `src` files, so a grammar or tree-sitter bump that
  kept the node types and table counts left the fingerprint unchanged and stale cached extractions were reused (#108)
- 2026-10-18 — The source identity: each crate's build script digested its own source with its own copy of the hash
  and the fingerprint assembly, which `kartta-lang` holds once (#94)
