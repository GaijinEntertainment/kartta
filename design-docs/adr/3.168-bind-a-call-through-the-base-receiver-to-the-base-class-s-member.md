# Bind a call through the base receiver to the base class's member

- **Status:** accepted
- **Date:** 2026-10-24
- **Updated:** 2026-10-24
- **Initiative:** `03-code-graph`
- **Governs:** `kartta_lang::Conventions::base_receivers`, `crates/kartta-graph/src/scope.rs`
  (`member_of_the_caller_s_base`, `held_by_a_base`, `base_types`), `crates/kartta-graph/src/resolve.rs`
  (`resolve_by_tiers`), the `Conventions` of `kartta-lang-quirrel`, `kartta-lang-daslang` and `kartta-lang-php`
- **Pinned by:** `crates/kartta-languages/tests/base_receivers.rs`

Quirrel's `base.m()`, daslang's `super.m()` and PHP's `parent::m()` call the `m` of the class the caller's class
extends, most often from the caller's own override `m`, which the name tiers bound in its place. A language lists the
receivers that name the base, and a call through one binds the base's member from the bases the graph holds, or
nothing, at the price of the bases it cannot name.

## Decision

- `Conventions::base_receivers` lists the receivers a member call writes for the caller's base class: Quirrel `base`,
  daslang `super`, PHP `parent`. Every other language lists none.
- A call through one binds, at 85, the member of its name that the first base the caller's class declares holds, else
  the one the nearest type above that base holds, a type's traits before the class it extends in turn. It binds ahead
  of every name tier (ADR 3.171, tier 5, and ADR 3.172, tiers 6 and 7), and where no type holds a member of the name
  it binds nothing.
- A base is a type of the name it is written with, the one nearest the declaring class's file, never that class
  itself and never an interface, which holds no body to call. The first base is never a trait: PHP's `extends` comes
  before its interfaces and traits.
- A type of another scope that the declaring file neither holds, includes nor shares a directory with names no base,
  since a file reaches such a type through an include, as PHP's `use` of a class the autoload maps.
- A caller in no class the graph holds, a method of a Quirrel class written without a name, resolves through the name
  tiers as any other member call.

## Why

- The caller is most often the override of the name, so the same-file and caller's-owner tiers bound it to itself:
  every one of the 28 Quirrel pairs this rule replaced on the C++ game-engine tree now binds the base's member
  (2026-10-24).
- A bare-named type of another scope stands for a base outside the graph: all 133 PHP pairs the scope check took out on
  Laravel were wrong, PHPUnit's `TestCase` bound as `Illuminate\Foundation\Testing\TestCase` among them (2026-10-24).
- Of the PHP pairs the rule adds on Laravel and Symfony that a reading of each file's `use` map can check, 1,607 of
  1,608 are right (2026-10-24).

## Consequences

- A base written through an alias, PHP's `use Illuminate\Database\Eloquent\Model as Eloquent`, names no type, so the
  call binds nothing: 3 right Laravel pairs lost (#524).
- A namespaced PHP base outside the repository's autoload map, in another directory, binds nothing. Accepted.
- Of two types of the base's name that the file reaches through its includes, the first in path order binds: 1 wrong
  Symfony pair, `FormFlow::__construct` bound to the validator's `Form` constraint. Accepted.

## Rejected

- **Leave the call to the name tiers when no base holds the member** — they bind the caller's own override.
- **Record the base's name as the receiver at extraction, for the receiver's owner tier** — that tier reads one owner,
  where 78 of the 244 Quirrel pairs on the C++ game-engine tree bind a class above the base, and a bare-named owner
  reaches a namesake of a base outside the graph (2026-10-24).
- **Bind nothing for a caller in no class the graph holds** — drops the 3 Quirrel pairs of methods in a class written
  without a name on the C++ game-engine tree, all right (2026-10-24).

## Revisit if

The PHP extraction records the class a `use ... as` alias of a base names, or a language whose base receiver names a
base by a qualified name lists one. High confidence for Quirrel, daslang and PHP.
