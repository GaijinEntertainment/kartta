# Take the query glob dialect from globset

- **Date:** 2026-08-24
- **Governs:** `crates/kartta-fs/src/filter.rs` (`Filter`, `FilterError`)
- **Pinned by:** `crates/kartta-fs/src/filter.rs` (`a_pattern_is_anchored_at_the_index_root`,
  `a_pattern_without_a_slash_matches_a_file_wherever_it_sits`,
  `a_pattern_with_a_slash_stops_a_star_at_the_segment_boundary`,
  `a_double_star_segment_matches_zero_segments_as_well_as_many`, `a_backslash_escapes_the_character_after_it`,
  `a_backslash_in_a_name_is_an_ordinary_character_and_not_a_separator`, `matching_is_case_sensitive`,
  `an_invalid_pattern_is_named_rather_than_the_set`)

A glob in the file index appears in two places that answer to different systems: a `.gitignore` has to agree with git,
and a query has to agree with the tools its caller already types patterns into. Query globs take `globset`'s dialect,
the one ripgrep and `fd` match with, with three rules pinned; `.gitignore` globs stay with `gix-ignore`. The trade is
one more crate beside git's matcher.

## Decision

- **Two dialects.** A glob a caller passes to a query is compiled by `globset`. A glob in a `.gitignore` is matched by
  `gix-ignore` in git's own dialect.
- **Patterns fail up front.** `Filter::new` compiles every pattern at once and fails on the first one that does not
  compile, naming that pattern (`FilterError::Pattern`), so holding a `Filter` proves its patterns parsed and a query
  that takes one cannot fail. A set that compiles pattern by pattern but not as one matcher fails as
  `FilterError::Oversized`.
- **Pinned rules.** Three rules are pinned rather than left to the library's defaults:
  - **Anchored at the root.** A pattern is anchored at the index root, which is what an indexed path is relative to:
    `src/*.rs` never finds `vendor/src/main.rs`.
  - **A slash names a place.** A pattern containing `/` stops `*` at a segment boundary; one without `/` does not. So
    `*.rs` names a file wherever it sits and `src/*.rs` names a place. A `**/` segment matches zero segments as well as
    many.
  - **Backslash escapes.** `\` escapes the next character on every platform.
- **Case.** Matching is case-sensitive.
- **Separate arguments.** What a filter selects, what a query excludes and how many paths it returns are separate
  arguments ([ADR 1.55](/design-docs/adr/1.55-path-query-exclusion.md)).

## Why

- The two dialects differ where a typed query is fragile. Git's wildmatch has no `{a,b}` alternation, so `*.{rs,toml}`
  is a literal name nobody has, and it has no invalid pattern: `src/[` compiles to a glob that matches nothing, and
  the caller's mistake comes back as an empty answer. A pattern a human or an agent types must fail loudly instead.
- `globset` compiles a whole pattern set into one matcher behind literal, extension and prefix prefilters, so a query
  costs one pass per path rather than one per pattern.
- The library's default makes `\` a separator on Windows and an escape on unix, which gives one pattern two meanings.
  An indexed path is forward-slash form everywhere, so `\` is never a separator here and is free to be the escape.
- A glob is a specification the caller wrote out, and a fuzzy query is a guess at one, so the two want opposite
  answers about a spelling that does not quite match: the fuzzy query folds case, the glob does not.

## Consequences

`globset` is the one crate the dialect adds. `aho-corasick` and `regex-syntax`, which it pulls, also arrive through the
content search's regex engine, `grep-regex` ([ADR 1.10](/design-docs/adr/1.10-content-search-engine.md)); its `log`
dependency is off through `default-features = false`. Accepted.

## Rejected

- **`gix-glob`, already in the graph** — git's wildmatch, right for `.gitignore` and wrong here: no `{a,b}`, no
  invalid pattern, and matching pattern by pattern.
- **A hand-rolled glob-to-regex translation** — about 55 lines for the common rules, and a hand-matched dialect is
  where silent divergences live; a divergence here returns a wrong file list rather than an error.
- **The `ignore` crate's matcher** — still git's dialect, and it brings `walkdir` and `same-file` back into a graph
  that dropped them.
- **Folding case in globs, to match the fuzzy query** — on a case-sensitive filesystem `.RS` is a different extension,
  and `*.rs` could no longer be written to mean what it says.
- **Regex queries instead of globs** — a larger surface, unfamiliar for the common cases. Regex can arrive beside globs
  under its own name; the two do not exclude each other.

## Revisit if

`gix-glob` grows alternation and pattern validation, or compile time becomes the driver; then the target the
dependency survey named is measured first. High confidence in the dialect callers type; compile time is not measured.
