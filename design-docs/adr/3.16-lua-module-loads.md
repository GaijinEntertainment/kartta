# Load a Lua module only from a literal name

- **Date:** 2026-10-16
- **Governs:** `crates/kartta-lang-lua/src/walk.rs`, `crates/kartta-lang-lua/src/resolve.rs`
- **Pinned by:** `crates/kartta-lang-lua/tests/lua.rs`

Lua has no import statement: a file loads another at run time through a call of `require`, `dofile` or `loadfile`, and
the host program sets the search path. `kartta-lang-lua` reads a load only from a bare loader with a string literal and
finds the module by the two common search paths, at the price of missing a module the host's own path finds.

## Decision

- **Loaders.** `require`, `dofile` and `loadfile` are loaders when the call names them directly. `M.require("x")` is a
  method of `M`, and a loader with a computed argument, `require(name)` or `require("a" .. "b")`, is an ordinary call.
- **Literals.** All three string forms, `require("a")`, `require "a"` and `require[[a]]`, are literals. An empty literal
  loads nothing.
- **A load is an include.** A bare loader with a literal is a load, which the resolver turns into an include, and
  records no call. It is a load wherever the file calls it, inside a function and at the module's top before any
  function alike.
- **Module names.** `require "a.b"` includes `a/b.lua` or the package `a/b/init.lua` at the repository root first, and
  then the same names in the requiring file's directory.
- **Paths of `dofile` and `loadfile`.** `dofile` and `loadfile` take a path, whose dots are no separators, from the
  file's directory first and then from the root.
- **Modules outside the repository.** A module that the repository does not hold, such as one of the standard library or
  of a rock, includes nothing.
- **Function symbols.** A function bound to a name is a symbol: `M.f = function() end`, `local f = function() end`, and
  a field of a table bound to a name, `local T = { f = function() end }`. Its scope opens when the walk reaches the
  function, so in `f, g = mk(), function() end` the call of `mk` is no call of `g`.
- **Table owners.** A table constructor bound by an assignment owns its fields under the variable in its own place, `U`
  for the second table of `local T, U = {...}, {...}`. A nested table's fields have no owner.
- **Exports.** `local` makes a function bound to a name unexported, but not a method of a local table.

## Why

- The extraction reads one file and does not know the `package.path` that the host program sets, and a computed name
  is one only the run time knows.
- The loader is the run time's own function, so a call of it would bind only where a file redefines it, and the
  include already states the dependency.
- A module loads most of its dependencies at its top, before any function, so a load there must not be lost.
- The `./?.lua;./?/init.lua` entries of the default `package.path` give the root form when the program runs from the
  root, and the relative form when a script runs from its own directory; the run time searches from the working
  directory, not from the requiring file, so the root goes first.
- An assignment of a function to a name, a local or a table field is how Lua commonly defines a method.
- A module hands its local table out with `return M`, so a method of a local table is reachable from other files.

## Consequences

- A module that only the host's configured `package.path` finds adds no include. Accepted.
- The extraction does not check that the file returns the table, so exported is a guess for a method: one of a table
  the file keeps to itself is exported too. Accepted.

## Rejected

- **A call of `require` as well as the include** — the call binds to no symbol, and it costs one row per load.
- **The requiring file's directory before the root** — finds a sibling module before a module of the same name at the
  root, but under the default `package.path` the run time searches from the working directory, not from the requiring
  file.
- **The configured `package.path`** — exact, but the host program sets it, often in code that is not Lua.

## Revisit if

The extraction reads a `.rockspec` or a `.luarc.json`, which name the module directories of a project. Medium
confidence: until then the default search paths are the only ones the extraction can know.
