# Record a function a string or a symbol names as a use

- **Status:** accepted
- **Date:** 2026-10-19
- **Updated:** 2026-10-19
- **Initiative:** `03-code-graph`
- **Governs:** `crates/kartta-lang-php/src/walk.rs` (the callable table), `crates/kartta-lang-ruby/src/walk.rs`,

- **Pinned by:** `crates/kartta-lang-php/tests/php.rs`

  `a_string_no_callable_parameter_takes_names_nothing`,
  `a_callable_string_names_a_function_of_the_namespace_it_spells`),
  `crates/kartta-lang-ruby/tests/ruby.rs::a_method_named_by_a_symbol_is_a_use_of_it`,
  `crates/kartta-lang-bash/tests/extract.rs::a_trap_handler_and_a_completer_named_as_a_word_are_uses`,
  `crates/kartta-lang-puppet/tests/puppet.rs::a_type_named_as_one_is_no_use_of_it`

PHP, Ruby and Bash take a function as a value by its name written as data: a callable string or array, a symbol, a
handler word. A walk reads such a name only where the language runs what it names, a builtin's callable argument, a
`send`, a `trap`, and records it as a use of that function, so `dead_code` reaches a hook's callback, at the cost of
the names the same data spells where the walk cannot tell what runs them.

## Decision

- **PHP.** A literal string in the callable argument of a builtin that takes one, `array_map`, `usort`,
  `call_user_func`, `preg_replace_callback`, `spl_autoload_register` and the like, or of a WordPress hook,
  `add_action` and `add_filter`, positional arguments alone, is a use of the function it names, and `'Cache::flush'` of
  the member of `Cache`. `[$this, 'render']`, `[self::class, 'make']`, `[static::class, ...]` and
  `[parent::class, ...]` name a method of the class around the use, and `[Cache::class, 'flush']` one of `Cache`; in a
  property's default, outside every method, the class makes the use and names its own method through its name. PHP
  reads a callable string as fully qualified, so `'helper'` names the global `helper`, `'App\helper'` the one of
  `App`, and `'Sorter::compare'` the global `Sorter`: a string is a use only where the namespace it spells is the
  file's own, so `'helper'` is a use in a file of the global namespace and none in a file of `App`. A string anywhere
  else, an existence test such as `function_exists('f')`, a pair of strings, and a call spelled through a namespace,
  `App\array_map()`, name nothing; `strlen(...)` is a call already. A bare use binds the function its own file
  declares.
- **Ruby.** `method`, `public_method` and `singleton_method` make a method value from a symbol, and `send`,
  `public_send` and `__send__` run one. With no receiver or `self` the symbol names a method of the object's own type,
  and with a constant receiver one of that class or module; any other receiver names nothing, nor do
  `instance_method` and `respond_to?`. In a class or module body outside every method the class makes the use. At a
  site no class owns, the symbol names a top-level method and the use is bare: at file scope it keeps only its name
  (ADR 3.23), and in `def run`, `def self.run` or `def obj.tick` it binds the file's top-level method. With no receiver
  or `self`, `singleton_method` is recorded only in a class body; with a constant receiver anywhere.
- **Bash.** The handler of `trap cleanup EXIT`, `trap 'cleanup' INT` or `trap "cleanup" HUP`, and the completer of
  `complete -F _tool tool`, name a function as one word; a quoted handler that holds more, `trap 'rm -f "$tmp"' EXIT`
  or `trap "$on_exit" USR1`, is a command line and names nothing. A top-level `trap` makes its use from file scope.
- **Puppet and BLK** record no such use: Puppet takes a lambda only as a block and names a function by a string only
  in `Deferred` and `call`, and BLK holds data and no function.

## Why

- A string is data everywhere else, so only a parameter the language runs as a callable can say it names a function:
  every sampled definition that left WordPress's dead list is named so (2026-10-19).
- PHP resolves a callable string from the global namespace, so a string that spells another namespace names a function
  no bare use in the file could reach.
- A top-level `def` is a private method of `Object`, which every object reaches, so a symbol at a site no class owns
  names one, as Ruby runs it unless the value's class declares its own.

## Consequences

- A hook that names a function of another file, as WordPress's `default-filters.php` names most, binds nothing, and
  `[parent::class, 'm']` binds the class's own `m` before the parent's. Accepted.
- Rails' callbacks, `before_action :authenticate`, name a method by a symbol and are not read. Accepted.
- Puppet's 215 sampled manifests hold one `Deferred` string, of a builtin, so its strings stay unread. Accepted.

## Rejected

- **PHP `ValueUses::Imported`** — reaches nothing more on the trees measured.
- **Ruby `instance_method` read as a use** — read at a class body, it kept 65 unrelated methods on Homebrew out of the
  dead list, nearly all an `initialize`, since it most often only inspects a method.

## Revisit if

A corpus with Rails' callbacks, or another framework that names methods by symbols, shows them as a share of the dead
answers worth reading. Not measured.
