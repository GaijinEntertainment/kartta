# List the methods the game engine binds on Quirrel's native values

- **Status:** accepted
- **Date:** 2026-10-23
- **Updated:** 2026-10-23
- **Initiative:** `03-code-graph`
- **Governs:** `crates/kartta-lang-quirrel/src/runtime.rs`, `crates/kartta-lang-quirrel/src/lib.rs` (`CONVENTIONS`)
- **Pinned by:** `crates/kartta-lang-quirrel/tests/extract.rs`
  (`the_runtime_methods_ascend_without_a_repeat_and_name_the_built_in_delegates`,
  `the_runtime_methods_name_the_engine_s_native_values_and_not_the_scripts_helpers`)

A member call of a runtime method binds no free function
([ADR 3.40](./3.40-bind-a-runtime-method-s-call-only-to-a-member-that-scope-reaches.md)), and Quirrel's scripts call
far more methods on the native values the game engine hands them than on the language's built-in types. The crate's list
takes the methods the engine binds on those values, less the names the scripts' own helpers define, so a call on a
native value stops binding a free namesake and a helper keeps its callers.

## Decision

1. `runtime::METHODS`, Quirrel's `Conventions::runtime_methods`, lists in ascending order the methods Quirrel's runtime
   defines on its built-in types and their delegates: a table's, an array's, a string's, a function's, a class's, a
   generator's, a thread's and a weak reference's.
2. It adds the methods the game engine binds on the native values its scripts hold, `get`, `set`, `setFrom` and
   `getScene` among them: the watched state of `frp`
   (`Watched`, `Computed`, `NativeWatched`, `prog/gameLibs/quirrel/frp/frp.cpp`), `DataBlock`
   (`prog/gameLibs/quirrel/bindQuirrelEx/sqratDataBlock.cpp`), the ECS entity manager and templates
   (`prog/gameLibs/ecs/scripts/sq/sqcoredaECS.cpp`) and `DaGuiObject` (`skyquake/prog/gameLibs/daGUISq/guiSqBind.cpp`).
3. Of the engine's methods, `isEmpty`, `isEqual`, `isValid`, `isVisible`, `isEnabled`, `getName`, `getTypeName` and
   `size` stay out, because the scripts' own helper modules and classes define them and call them through members.

## Why

- With the built-in types alone, a member call on a native value bound a free namesake: `IlsColor.get()` on a watched
  state the free `get` of `fontsState.nut`, `blk.setFrom()` a table slot of the controls scripts, `obj.getScene()` an
  editor's `getScene`.
- On the game-engine tree the list removes 4,556 caller-callee pairs, 29 of 30 sampled wrong (2026-10-23); the watched
  state's methods take 3,243 of them.
- The eight names left out are the scripts' own API as well: 94 of 96 `isEmpty()` pairs the full lists unbind are
  `u.isEmpty()` of the scripts' helper module.

## Consequences

- A member call of a listed method on a script's own object binds only a member scope reaches, so a script method that
  shares a name with an engine method loses a call that nearness would have bound. Accepted.
- A call of one of the eight left-out names on a native value still binds a free namesake. Accepted.

## Rejected

- **Every method the engine binds on those values** — unbinds the scripts' own helpers of a shared name, `u.isEmpty()`
  among them, at 31 of 40 sampled wrong for the values beside the watched state.

## Revisit if

The Quirrel extraction records the type a value holds for its member calls, so a call on a native value names its
type. Not planned.
