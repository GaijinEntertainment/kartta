# State a language's conventions as a const over the default

- **Status:** accepted
- **Date:** 2026-10-21
- **Updated:** 2026-10-21
- **Initiative:** `03-code-graph`
- **Governs:** `kartta_lang::Conventions`, `Conventions::DEFAULT`, the `CONVENTIONS` of each
  `crates/kartta-lang-*/src/lib.rs`
- **Pinned by:** `crates/kartta-lang/src/language.rs` (`default_returns_the_const_default`, the `Conventions` doc
  example)

`Conventions` grows a field whenever the graph needs one more fact from the languages
([ADR 3.1](/design-docs/adr/3.1-language-plugin-contract.md)). It is `#[non_exhaustive]`, so a new field breaks no
language crate, and each language states its value as a `const` block over `Conventions::DEFAULT`, at the price of a
block where a struct literal would read shorter.

## Decision

- `Conventions` is `#[non_exhaustive]`: outside `kartta-lang`, neither a struct literal nor a `..` struct update
  builds one.
- `Conventions::DEFAULT` is the default as a `const`, and `Default` returns it.
- A language that changes a field writes a `const` block that copies `Conventions::DEFAULT` into a mutable binding,
  assigns the fields it changes, and yields it; a field added later stays at its default. Each of kartta's languages
  that changes a field states its conventions so, and `Language::conventions` returns that `const`.

## Why

- A field added to an exhaustive struct breaks every crate that builds it with a literal, a language crate kartta does
  not ship included.
- A `const` costs nothing at run time and gives the value each language built before at run time: the answers were
  identical on dagor and on the Go monorepo snapshot (2026-10-21).

## Consequences

- A language crate cannot tell at compile time that a field it should set was added; the field takes the default
  until the language states it; accepted.

## Rejected

- **A `const fn` setter per field** — the same effect, but every public field repeated as a method to keep in step
  with the struct, where the block assigns the fields themselves.
- **An exhaustive struct** — every field added breaks every language crate.

## Revisit if

A language needs conventions it can only work out at run time, from its configuration, which a `const` cannot hold.
High confidence it does not: every shipped language states fixed conventions.
