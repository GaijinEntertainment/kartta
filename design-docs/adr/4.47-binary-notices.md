# Generate one notices file for the binary artifacts, from what they link

- **Date:** 2026-11-02
- **Governs:** `notices/`, `.github/workflows/ci.yml` (job `notices`), `scripts/dist.sh`

MIT and BSD-3-Clause, which `deny.toml` allows, ask a binary to carry the copyright notice, and nothing in the
repository produced one. One committed file, `notices/THIRD-PARTY-NOTICES.txt`, ships inside every binary artifact. A
small script writes it, by copying each licence file as published, and CI fails when the committed file differs from
what the script writes; the trade is a generator to keep, and a short table of texts by hand for code that no manifest
describes.

## Decision

- **One file.** Both binary artifacts, the static library and the Node addon, ship the same file. It
  covers the whole support matrix, and each row names the artifacts that link the component, so a build for one target
  carries a superset of what it links.
- **Linked code only.** A row exists for what `cargo tree -e normal,no-proc-macro` reaches from an artifact on a target
  of the matrix. Build scripts, proc macros and development dependencies leave no code in an artifact, and stay out.
- **Licence files verbatim.** The script copies every licence file under a package, nested ones included, and reads
  none of them: it picks no branch of an `OR`, and equal texts share one section. It changes only CRLF line endings
  and the blank lines around a text. Nested files carry the terms of vendored code, such as ICU's in `tree-sitter`.
- **Texts no package carries.** `notices/texts/` holds what the packages leave out: the licence from the repository of
  a package that publishes none, taken at its published commit, and the terms of code outside any manifest. That code
  is the Rust standard library and `endian.h` in the `tree-sitter` runtime.
- **The standard library.** Its crates are taken from `rust-src` of the pinned toolchain. `STD_VENDORED` names the
  third-party crates among the rlibs it links on the matrix, because the vendored set also holds crates for other
  targets.
- **The check.** CI runs the script and fails on a difference. A linked package with no licence file and no entry in
  `UNPACKAGED` stops the script, naming it.
- **System libraries.** Libraries of the host system that an artifact links dynamically, or that its platform's
  toolchain supplies, get no row. On the musl targets the static library leaves musl and the unwinder to the
  consumer's link, and the addon links them dynamically.

## Why

- `cargo-about` 0.9.3 classifies files before it copies them, and on `kartta-mcp` on 2026-11-02 that dropped real text.
  It did not recognise the licence files of `chrono`, `rmcp`, `windows-link` and `windows-sys`, and printed a template
  in their place, which loses Microsoft's copyright line and the relicensing terms of `rmcp`. It also listed proc
  macros, and printed two whole source files as licences.
- A file listing more than a build links costs a reader a few lines, and a missing notice breaks the licence.
- A dependency bump changes the file, so a stale file has to fail where the bump lands.

## Consequences

- The file is about 350 KB, and each dependency bump rewrites part of it. Accepted.
- `UNPACKAGED`, `STD_VENDORED` and `UNMANIFESTED` do not follow a bump on their own: a package that starts to ship a
  file keeps its copied text beside it, and a new standard-library dependency needs a hand edit. Accepted.
- The file copies each licence and weighs none of its terms. The terms of the macOS crates derived from Apple SDKs and
  of **System libraries** wait for a human (#1067).
- CI needs `rust-src` and Python for this one job. Accepted.

## Rejected

- **`cargo-about` with a `clarify` entry per crate** — each crate it misreads takes an entry with a checksum, and the
  entries for packages without a file fetch their text from the network on every run.
- **One file per artifact** — three copies of the same texts for a difference that the rows already state.
- **A walk of the standard library's graph from `rust-src`** — its vendored set is partial, and its manifest needs
  nightly `cargo-features`, so `cargo tree` refuses it.

## Revisit if

A license review asks for per-target notices, or the release adds an artifact with a different linked set. High
confidence in copying over classifying.
