# Record a name a script or Rust reads without a call as a use

- **Status:** accepted
- **Date:** 2026-10-19
- **Updated:** 2026-10-23
- **Initiative:** `03-code-graph`
- **Governs:** `crates/kartta-lang-daslang/src/walk.rs`, `crates/kartta-lang-quirrel/src/walk.rs`,
  `crates/kartta-lang-lua/src/walk.rs`, `crates/kartta-lang-rust/src/walk/values.rs`,
  `crates/kartta-lang-rust/src/walk/bindings.rs`
- **Pinned by:** `crates/kartta-lang-daslang/tests/extract.rs` (`a_function_taken_by_its_address_is_a_use_of_it`,
  `quoted_code_records_a_call_as_a_use_of_its_name_and_no_call`), `crates/kartta-lang-quirrel/tests/extract.rs`,
  `crates/kartta-lang-lua/tests/lua.rs` (`a_name_taken_as_a_value_is_a_use_of_it`,
  `a_parameter_a_local_or_a_name_being_declared_is_no_use`), `crates/kartta-lang-rust/tests/extract.rs`
  (`an_item_taken_as_a_value_is_a_use_of_it`,
  `a_binding_hides_its_name_from_its_end_to_its_block_s_and_a_read_binds_in_its_module`)

daslang, Quirrel, Lua and Rust record calls and no data use, so a handler subscribed, a comparator passed or a
function placed in a dispatch table reached nothing, and `dead_code` judged it dead. Each walk records a name its code
reads where no call takes it as a bare use of the definition its file declares, hidden by the language's own bindings,
so such a function is reached, at the cost of the uses stored and of a namesake bound where a binding the walk does not
follow hides the name.

## Decision

- **daslang.** `@@f` and `@@mod::f`, typed or not, and `_::f`, record a bare use of `f`, or one qualified by `mod`; a
  splice `@@$c(...)` names nothing. A call, a constructor `T(...)`, a `new T` or an `@@` inside `quote`, `qmacro` or a
  `qmatch` pattern, which [ADR 3.141](./3.141-give-a-daslang-call-to-the-code-that-runs-it.md) records no call for, is
  a use of its name, sited at the `def` around it; a member call
  inside them records nothing. daslang sets `ValueUses::Imported` (ADR 3.34): the file's own function, else the one a
  file it requires exports, else a re-export of it, else the one such a file declares `private`.
- **Quirrel.** An argument, a slot's value, a shorthand `{ handler }`, a `return` and `::name` read a name; a name being
  declared, a slot's key, a member's field, an assignment's target, a member access's receiver, a `foreach` variable and
  an increment's operand do not. A parameter or a local of an enclosing function hides its name in the whole body;
  `::name` reads the root whatever hides it. A bare use binds the constant or the function its file declares outside
  every owner and body, a field of the enclosing class first (`OwnMembers::First`); a `from` import or a destructured
  `require` names a module the graph does not keep, so a name another module exports binds nothing.
- **Lua.** An argument, a value an assignment, a `return` or a loop takes, a field's value, `{ on_click = handler }`,
  an operand, a condition and an index's key read a name; an assignment's target, a callee and a table indexed through
  `.`, `:` or `[]` do not. A parameter hides its name in its function, as `self` does in a method declared with `:`
  and a local function its own name in its body; inside a function a local hides its name from the end of its
  declaration to the end of its block, so `local f = f` reads the `f` outside, and a loop variable inside its loop. At
  the chunk's top level no local hides a name. A use binds the function its file declares outside every function.
- **Rust.** An argument, an element, an operand, a range's bound, a condition, an indexed value or an index, a
  returned, a broken-out, a block's or a closure's last value, the value a `let`, a `let` condition, an assignment, a
  `const`, a `static`, a field, a shorthand field, a reference, a cast, a `match`, an arm or a `for` takes, either side
  of `+=` and its kin, the base of a field access or a method call, and an awaited or a `?` operand read a name;
  `Self::make` read so names the member of the type around it, and `Service::make` the member of `Service`. A pattern's
  name hides it from the end of what the binding reads on: a function's or a closure's parameter in its body, an arm's
  pattern in the arm, a `for`'s pattern in its body and not its iterator, an `if let` or a `while let` in the operands
  after it and the branch it runs on a match, a `let` to the end of its block; a function's own region ends the lookup.
  The walk keeps a bare read only where its own inline module declares the item outside every owner and body, and a
  read through `Self` or a type only where the file declares a member of the name under that type. Only the base of a
  field access is a use; the field is not.

## Why

- A function taken as a value is the only use many functions have: `dead_code` reported 7,426 fewer Quirrel
  definitions dead on the game-engine tree once Quirrel reads were uses, and every sampled one left was read as a value
  (2026-10-19).
- Each language's own bindings decide what a name means, so the walk hides a name exactly where its local does.
- A Rust read keeps a use only where the item exists in its module, so `None`, `String::from` and a local the patterns
  missed cost nothing.
- Compiled daslang names no `private` function of another module, so the last tier binds only a name no visible
  definition holds.

## Consequences

- A Rust read of a function another module defines records nothing, since `use` adds no import, and the graph binds a
  kept read to the first item of its name the file declares, whatever inline module holds it. Accepted.
- A static a Rust macro declares reads as the function of its name the file declares, as rustix's `weak!` does.
  Accepted.
- At Lua's chunk level a top-level local of any value hides nothing, so a namesake function binds its reads. Accepted.
- Quirrel extracts no variable, so a module variable's reads bind nothing. Accepted.

## Rejected

- **Lua `ValueUses::Imported`** — reaches nothing more on the three trees measured.
- **Lua `M.f` and `self.f` as uses of the table's method** — records 8 to 10 times the uses, nearly all of a table no
  method is declared on, for 10 more definitions reached.

## Revisit if

A language here gains imports the walk follows, as Rust's `use`, so a read could bind another module's item. Not
planned.
