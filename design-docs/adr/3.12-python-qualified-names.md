# Qualify Python by the module its path names

- **Date:** 2026-10-16
- **Governs:** `crates/kartta-lang-python/src/resolve.rs`, `crates/kartta-lang-python/src/walk.rs`,
  `crates/kartta-lang-python/src/banner.rs`, `crates/kartta-lang-python/src/lib.rs` (`CONVENTIONS`)
- **Pinned by:** `crates/kartta-lang-python/tests/resolve.rs`, `crates/kartta-lang-python/tests/extract.rs`

A Python file declares no package: its module is its path. `kartta-lang-python` qualifies every symbol by the module
its path names, in the resolver, so the extraction of a file's bytes stays shareable between paths, and it finds an
import's file as [ADR 3.182](/design-docs/adr/3.182-python-imports.md) decides.

## Decision

The [crate documentation](/crates/kartta-lang-python/src/lib.rs) lists every form each rule below takes: the
assignments that define a variable, the calls a class body makes, and the banner and docstring forms.

- **Modules.** The resolver qualifies every symbol by its module: the path with `/` turned to `.` and the `.py` or
  `.pyi` extension dropped, in any case, so a method `greet` of `Service` in `pkg/service.py` is
  `pkg.service.Service.greet`. A package's `pkg/__init__.py` is the module `pkg`, and a root `__init__.py` names no
  module. A `.pyi` stub names the module of the source it describes, so a stub and its source define the same names.
  The extraction from the bytes keeps the names local, `Service.greet`. An owner is the chain of classes alone,
  `Service` or `A.Worker`, joined at `.`.
- **Symbols.** A function, a method and a class are symbols. A definition nested in a function is qualified by the
  module alone, a nested class keeping its own methods under its name, is no member of a class around that function,
  and is local to the function's body. A variable is a symbol only where a bare name is assigned at module level, the
  first name of a chain alone. A class's fields follow [ADR 3.103](/design-docs/adr/3.103-python-class-fields.md). A
  decorated definition starts at its first decorator, and a name that starts with `_` is not exported.
- **Calls.** A bare call records its name, and a member call its attribute with the receiver: the name where the
  object is a name, `self.greet()`, and the empty receiver for anything else, `items[0].close()` or `make().run()`. A
  call belongs to the function around it. A call in a class body outside every method belongs to the class, and so
  does a call in the class's bases, which are looked up in the scope around the class, where Python evaluates them. A
  call outside every function and class, before the file's first definition too, is a call from file scope
  ([ADR 3.112](/design-docs/adr/3.112-file-scope-names.md)). A call in a default argument, `def f(x=make()):`, belongs
  to `f`, and its name is looked up in the scope of `f`. Which bare calls are local calls, and which record nothing,
  [ADR 3.102](/design-docs/adr/3.102-python-bare-calls.md) decides. Data sites follow
  [ADR 3.63](/design-docs/adr/3.63-python-data-sites.md).
- **Conventions.** Python's [`CONVENTIONS`](/crates/kartta-lang-python/src/lib.rs) set `OwnMembers::Unreached`, so a
  bare call never reaches a method of the caller's class; `.` as the owner chain separator; the built-in types' and
  the standard library's common methods as `runtime_methods`
  ([ADR 3.40](/design-docs/adr/3.40-runtime-method-calls.md)); `ValueUses::Imported`; and `self`, `cls` and `other`
  as own-type receivers ([ADR 3.41](/design-docs/adr/3.41-own-owner-receivers.md)).
- **File roles.** A `test_*`, `*_test` or `conftest` file, or one below a `test` or `tests` directory in any case, is
  test code, and so is every symbol in it, fixtures and helpers included; the rule follows pytest's naming conventions
  and reads no pytest configuration. A `*_pb2` or `*_pb2_grpc` file is protobuf output. A `@generated` or
  `DO NOT EDIT` marker outside a backtick span in the header, the comments and module docstring before the first
  statement, marks other generated code.
- **Entry points.** A free `def main` directly at module level is the entry point a script runs under
  `if __name__ == "__main__":`. A method whose name opens and ends with `__` is an entry point, as is a method that
  `property` or `cached_property` decorates or that an accessor of the property of its name decorates, `@size.setter`
  over `def size`. A free function is never one.
- **Fingerprint.** The fingerprint covers the walk and the grammar, as
  [ADR 3.120](/design-docs/adr/3.120-language-fingerprints.md) decides.

## Why

- A cache shares an extraction between every file with the same content, and two such files at two paths are two
  modules, so only the resolver, which sees the path, can qualify.
- An owner is what a receiver spells, so it is the chain of classes and not the module.
- The interpreter calls a special method, `__init__`, `__enter__` or `__eq__`, for an object it makes, a statement or an
  operator, and a property for an attribute read; no call spells their names, so a dead-code query would report each.
- A default argument's call is evaluated in the scope around the definition, and the pattern is rare enough to accept
  the wrong scope.
- A class body's calls at module level were file-scope calls: the class had no callees, `find_callers` listed the file,
  and [ADR 3.112](/design-docs/adr/3.112-file-scope-names.md)'s file-scope rule let the name reach every namesake in
  the file. Of the 57 pairs the class's calls added on the game-engine tree, 49 were right, and each of the 8 wrong ones
  is a guess at 60 the same call already makes from a method (2026-10-23, #187).

## Consequences

- A special-method spelling is a heuristic: a class's own `__custom__`, which the interpreter never calls, is an entry
  point too. Accepted.
- Qualifying by the module costs one string per symbol in the resolver, which no cache shares. Accepted.

## Rejected

- **Qualifying in the extraction** — the module would depend on the path, and a cache could not share the extraction
  of two files with the same content.
- **Every assignment as a variable** — tuple targets and class state would add symbols that nothing imports by name.
- **A synthetic initializer, `Settings.<body>`, owning a class body** — the same pairs and the same dead set, at the
  cost of 1,283 symbols in every outline and `find_symbols` on the game-engine tree, an entry flag so that `dead_code`
  does not report each, and impact walks that stop at it where the class's callers are what a change reaches
  (2026-10-23, #187).

## Revisit if

A cache stops sharing one extraction between files of the same content, so the extraction could qualify by the path
itself. High confidence it does not: the shared cache keys an extraction by its content
([ADR 2.1](/design-docs/adr/2.1-shared-cache-store.md)).
