# Bind the caller's own owner only on the receivers a language lists

- **Status:** accepted
- **Date:** 2026-10-19
- **Updated:** 2026-10-19
- **Initiative:** `03-code-graph`
- **Governs:** `kartta_lang::Conventions::own_type_receivers`, `crates/kartta-graph/src/scope.rs`
  (`member_of_the_caller_s_owner`), the `Conventions` of `kartta-lang-python`, `kartta-lang-ruby`, `kartta-lang-rust`
  and `kartta-lang-daslang`
- **Pinned by:** `crates/kartta-graph/tests/graph/calls.rs`
  (`a_language_that_lists_its_own_type_receivers_binds_the_caller_s_owner_only_on_one`,
  `a_member_call_of_an_unknown_type_picks_a_member_of_the_caller_s_owner`)

A member call whose receiver names no owner falls, past scope, to the member of the caller's own owner (ADR 3.7,
tier 7). That is the call a method makes on its own receiver, and a guess that any other value has the caller's type. A
language that lists the receivers it writes for a value of the caller's own type keeps the tier for those alone.

## Decision

- A member call whose receiver names no owner binds the member of the caller's own owner of its name, at 80, once the
  scope tiers bind nothing and the call's shape admits a candidate.
- Where a language lists `Conventions::own_type_receivers`, the tier takes only a listed receiver: Python `self`,
  `cls` and `other`; daslang `self`; Ruby and Rust `other` alone, because each records `self`, and Rust `Self`, as the
  name of the caller's owner, which binds at 85 as a receiver that names an owner (ADR 3.7, tier 5).
- Every other language lists none and keeps the tier for any receiver that names no owner, PHP, Lua and Quirrel among
  them.

## Why

- For the caller's own receiver the tier binds the call it makes, and `other`, the second operand of a comparison,
  mostly has the caller's type.
- For another value's name it guesses the caller's type, and the call tools show 80 as certain: Python's
  `sock.close()` inside an event loop bound `BaseEventLoop.close`. Of the Python sites the list takes out of the tier,
  72% of those sampled were wrong and 11% right (Python 3.9 standard library and C++ game-engine tree, 2026-10-19).
- Ruby's `other` alone takes out sites that were wrong in all but one of those sampled (Homebrew library, 2026-10-19).
- PHP's best list drops edges of which 75% are wrong, under the 90% a rule is taken at, and half the wrong ones are
  `parent::m()`, which no list of receivers binds (WordPress and Laravel, 2026-10-19).

## Consequences

- A value built from the caller's own type under another name loses its member: about one sampled Python site in ten,
  as `p = Profile()`, and one in six a composite's children, as `e.streamline()` for each `e` of `self.exprs`.
- `super.m()` in daslang and `parent::m()` in PHP bind the caller's override, not the base's member (#186).
- A bare Ruby `new` in a class method names no owner, so `new.getopts` binds nothing (#210).
- The tier takes the first member of the owner in path order, so a site in a later copy of a class binds the first
  copy's member (#201).

## Rejected

- **Python `self` and `cls` without `other`** — takes 25 more sites out of the tier, each on a value of the caller's
  type (2026-10-19).
- **The empty receiver for a Python value, the contract C++ and TypeScript keep** — took 282 edges at 57% right,
  because the receiver's owner tier (85) and the receiver's spelling (60) read the name it drops (2026-10-19).
- **Ruby with no list** — takes 3,233 more sites on `other` out of the tier, most of them on a value of the caller's
  type (Homebrew library, 2026-10-19).
- **Ruby `new` beside `other`** — keeps 12 right sites, but a parameter can take the name, as
  `Gem::Requirement#concat(new)` does (#210).
- **PHP `$this`, `self` and `static`, with `$other`, `$this` alone, or with `parent`** — no variant reaches 90%;
  `$this` alone also drops the 17 right `self::__construct()` calls of WordPress's PHP 4 constructors.
- **A Lua or a Quirrel list** — every Lua module names its table `M`, and Quirrel's comparators and monads take their
  own type, so most of the Lua edges such a list drops are right, and under half of the Quirrel ones (2026-10-19,
  #185).

## Revisit if

`parent::m()` and `super.m()` bind the base's member (#186): PHP's list then drops fewer wrong edges than it loses
right ones and adds guesses, which needs a new measurement. Medium confidence for the languages that list none.

## History

- 2026-10-19 — Ruby lists `other` alone (#184)
- 2026-10-19 — the caller's-own-owner tier takes only the receivers Python, Rust and daslang list (#182)
