# Bound each MCP tool's answer by a default limit

- **Status:** accepted
- **Date:** 2026-10-18
- **Updated:** 2026-10-18
- **Initiative:** `04-consumer-surfaces`
- **Governs:** `crates/kartta-mcp/src/server.rs` (the limit constants), `crates/kartta-mcp/src/params.rs`
- **Pinned by:** `crates/kartta-mcp/tests/stdio.rs`, `crates/kartta-mcp/tests/graph.rs`

Each answer of [ADR 4.1](./4.1-answer-agents-through-an-mcp-server-with-the-tools-their-prompts-name.md)'s server
lands whole in an agent's context. The tools below stop at a default limit, the prompts' own for the tools they name,
and the answer counts what the limit cut ([ADR 4.24](./4.24-count-in-each-mcp-answer-what-it-left-out.md)), so a cut
answer costs the agent a second call where it needs more.

## Decision

- `find_files` and `glob_files`: no default limit; a `max_results` omitted or zero lists every match, and a list the
  cap cut ends with a line saying so ([ADR 4.10](./4.10-close-a-cut-path-list-with-a-line-no-path-can-read-as.md)).

- `grep`: 100 matching lines, a line cut to 1 KiB around its match with the bytes it lost, files over 4 MiB skipped; an
  unscoped search excludes `**/vendor`, `**/node_modules`, `**/dist` and `**/__pycache__`.
- `list_dir`: one level, 1000 entries; it does not enter `vendor`, `node_modules`, `dist`, `build` or `__pycache__`.
- `find_symbols`: 20 hits; keyword matches that underfill the limit are topped up by fuzzy hits marked `fuzzy=true`.
- `read_definitions`: 3 definitions of each of at most 10 names, a body at most 500 lines, each cut at 1,024 bytes;
  a definition ranks `same-directory`, `vendored` or `other` by directory, not by the imports of the asking file.
- `find_callers`: 3 hops; `find_callees`: 1 hop, `at=` only on a direct callee, since the walk records the line of each
  call but not which callee further out made it; both stop at 500 symbols.
- `find_call_path`: 8 calls, 20,000 symbols. `find_implementations`: 500. `find_importers`: 3 includes away.
- `find_references`: every site counted, 100 listed and 50 more files named
  ([ADR 4.11](./4.11-group-a-symbol-s-references-by-file-the-busiest-first.md)).
- `impact_of_edit` and `impact_of_change`: ADR 3.22's walk at 3 hops and 500 symbols. `impact_of_edit` lists 50 direct
  callers and callees; `impact_of_change` lists 20 changed symbols and 20 hotspots, and 10 direct callers of each, or
  their directories past 30 callers. A change arrives as regions or a diff
  ([ADR 4.20](./4.20-read-a-change-from-the-new-side-of-a-unified-diff.md)).
- `find_unused`: ADR 3.23 over every kind, under an optional `path_prefix`, 50 listed in path order across the graphs;
  an answer that judged every definition and found each reached says so.
- `index_repo` and `index_stats` count each graph's `calls`, `uses` and `includes`, not resolved edges, which ADR 3.7
  does not build. With `coverage`, `index_stats` resolves every call (ADR 3.24) each time it is asked, and adds a
  `<coverage/>` record for each language that holds a file.

## Why

- The tools the prompts name keep the prompts' defaults, so an answer has the size those prompts were written for.
- The walk records the line of each call but not which callee further out made it, so a callee past the first hop
  answers no line.

## Consequences

- An agent that needs a callee past the first hop, or more than a limit lists, makes a second call. Accepted.

## Rejected

- **`find_callees` 3 hops deep by default, as `find_callers`** — a callee past the first hop carries no line of its
  call, and the question asked is what a body calls.
- **Coverage on every `index_stats`, or cached per build** — every first call would pay 0.1 to 0.4 s on the measured
  trees and a resolution's memory for counts most calls do not read, and a cache saves only a repeat.

## Revisit if

The prompts in use change the defaults they pass, or agents raise a tool's limit on most of its calls. Medium
confidence; how often agents raise a limit is not measured.
