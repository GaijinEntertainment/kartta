# Bind a runtime method's call only to a member that scope reaches

- **Date:** 2026-10-17
- **Governs:** `crates/kartta-graph/src/resolve.rs` (`is_runtime_method`, `resolve_by_name`, `resolve_outside_scope`,
  `names_a_library_method_on_a_value`), `crates/kartta-graph/src/scope.rs` (`receiver_spells_owner`),
  `crates/kartta-lang-jsts/src/runtime.rs`, `crates/kartta-lang-quirrel/src/runtime.rs`,
  `crates/kartta-lang-python/src/runtime.rs`, `crates/kartta-lang-rust/src/runtime.rs`,
  `kartta_lang::Conventions::runtime_methods`, `kartta_lang::Conventions::library_methods`
- **Pinned by:** `crates/kartta-graph/tests/graph/calls.rs` (`a_member_call_of_a_runtime_method_binds_no_free_function`,
  `a_member_call_of_a_runtime_method_binds_a_member_only_where_scope_reaches_it`,
  `a_member_call_of_a_runtime_method_binds_the_one_callable_whose_owner_its_receiver_spells`,
  `a_member_call_of_a_runtime_method_binds_no_free_function_a_barrel_re_exports`,
  `a_method_call_of_a_library_method_on_a_value_binds_the_one_method_of_its_name_only_as_a_guess`), each language's
  `the_runtime_methods_ascend_without_a_repeat_and_name_*`, Rust's
  `the_library_methods_ascend_without_a_repeat_and_name_the_standard_library_s`,
  `crates/kartta-languages/tests/engine.rs`
  (`a_rust_call_on_a_value_binds_the_runtime_method_whose_owner_its_name_spells`,
  `a_rust_call_of_a_standard_library_method_on_an_untyped_value_binds_the_one_method_of_its_name_as_a_guess`)

`line.trim()` calls the runtime's `trim`, not a function of the repository, and the method's name says nothing of which
type the value has. A member call of a method that a language's runtime gives its values binds a member of the name only
where scope reaches one, or the one callable whose owner its receiver spells; one of a method the standard library
declares, on a value of no type the graph names, binds that callable only as a guess.

## Decision

- **The lists.** `Conventions::runtime_methods` lists, in ascending order, the methods a language's runtime gives its
  own values: ECMAScript's built-in objects and the DOM's interfaces for TypeScript and JavaScript; the built-in types
  for Quirrel, with the methods the game engine binds on the values it hands its scripts
  ([ADR 3.145](/design-docs/adr/3.145-quirrel-runtime-methods.md)); the built-in types and the standard library's
  common values for Python; the standard library's methods and associated functions for Rust. Every other language
  lists none: Go's member calls take a member alone already
  ([ADR 3.39](/design-docs/adr/3.39-member-call-free-functions.md)), daslang's method syntax calls free functions, and
  Lua keeps no list.
- **No free definition.** A member call whose callee is listed binds no free definition at any tier, and no re-export
  chain.
- **A receiver an import binds.** A receiver that names an import binding names a module, not a value, and the module's
  export of the name binds, as `strings.trim()` after `import * as strings` does
  ([ADR 3.171](/design-docs/adr/3.171-receiver-call-binding.md), tier 2).
- **A member scope reaches.** Such a call binds a member of its name only through the caller's file, imports, package
  and includes, the owner its receiver names, or the caller's own owner on a receiver the language allows
  ([ADR 3.41](/design-docs/adr/3.41-own-owner-receivers.md)). It binds the one callable of the name, at 60, only where
  the receiver's last segment spells that callable's owner in any case: `session.seek()` binds `Session.seek`, and
  Rust's `watcher.drain()` binds `Watcher::drain`.
- **An included file's member.** Where a language sets `IncludedRuntimeMembers::SpelledOrOwn`, a member that a file
  the caller includes declares binds only where the receiver or the caller's owner reaches its owner, as
  [ADR 3.185](/design-docs/adr/3.185-included-runtime-members.md) decides.
- **Nothing else.** Otherwise the call binds nothing and counts as not admitted. It never binds by nearness.
- **A library method on a value.** `Conventions::library_methods` lists, in ascending order, every method the
  language's standard library declares; Rust lists those of `core`, `alloc` and `std` that take a `self` receiver,
  public or of a public trait. A method call of one that the runtime list leaves to the tiers, on a value the graph
  cannot type, `found.start()` or `f().start()`, binds the one callable of its name at 15 instead of 60, unless its
  receiver spells that callable's owner. Only Rust marks a method call, so only Rust's calls take this rule.

## Why

- The runtime answers these calls on the value itself: every sampled Quirrel, Python and Rust site the lists unbound
  called the runtime (C++ game-engine tree and Go monorepo, 2026-10-17, #64).
- A free function a barrel re-exports is no more what a value holds than one an include defines.
- The one callable and nearness still bound the runtime's namesakes, a Quirrel array's `append()` to a generated
  `OutputText.append` and Python's `str.format()` to a tool's `Identity.format`; of the sites the scope rule then
  unbound, under 1% were right (2026-10-19).
- A Rust value whose type the graph cannot name is as often one of the standard library's or of a crate outside the
  tree, and the one workspace method of a name the library also declares was then wrong: 24 of 30 sampled bindings the
  library rule moves were, `dir.path()` on a temporary directory binding tokio's `DirEntry::path`, while 59 of 60
  sampled on this repository and rust-analyzer that it keeps at 60 were right (this repository, the Go monorepo
  snapshot, tokio, rust-analyzer, wasmtime and the cargo registry, 2026-10-25, #290).

## Consequences

- A call of a repository member named like a runtime method binds nothing where scope does not reach the member:
  `reader.read()` on a socket reader, 6 sites in three copies of one tool, and seven Rust `Index::get` calls from `ix`
  values.
- Inside jQuery, the calls of jQuery's own methods that the DOM names too, `jQuery(this).replaceWith()`, bind nothing,
  the right ones with the wrong.
- A runtime method's call on a value still binds a namesake member of the caller's own file, as `marker.show()` binds
  `g_live_panel.show` in its own file. Accepted.
- A Rust call of a repository method named like a library method, on a value of the repository's type, binds only as a
  guess: about a fifth of the 1,189 bindings the library rule moved, as tokio's `read.filled()` on its own `ReadBuf`.
  Accepted.

## Rejected

- **The lists at the proximity steps alone** — leaves the same calls bound by the caller's file, the one callable and
  the includes: 78% of the sites the lists unbind on both trees (2026-10-17).
- **The TypeScript and JavaScript list without the DOM's methods** — keeps jQuery's methods named like the DOM's at the
  price of 1,338 more sites bound to a namesake, `document.body.appendChild()` among them (2026-10-17).
- **A near free function only where the caller's file includes its file** — unbinds the right calls nearness finds
  with the wrong ones, and lets the members near the caller take 20,482 more guesses (2026-10-17).
- **A member in either near directory before a free function** — unbinds 182 sites on both trees and leaves every
  runtime call with no member near it bound (2026-10-17).
- **The members in the caller's directory alone** — at most a sixth of the sampled sites right in any language
  (2026-10-19).
- **A guess tier for every runtime call** — keeps every one of these sites, shown as a guess.
- **The receiver's spelling at every step** — binds 39% of its sites right (2026-10-19).
- **A Rust method call on any untyped value at 15, or bound to nothing** — moves 16,961 bindings where the library rule
  moves 1,189, and the ones outside the library's names are right (2026-10-25, #290).
- **The library's methods in the runtime list** — binds nothing for the fifth of these calls that the one method answers
  right.

## Revisit if

A language's extraction records the type a value holds for its member calls, as Go's type paths and C++'s declared
locals do, so that the type rather than the name picks the member. High confidence that the name alone stays unsafe.
