# Name the definition that holds an unowned symbol in an outline

- **Date:** 2026-10-20
- **Governs:** `crates/kartta-mcp/src/render/symbols.rs` (`outline`, `holder`, `holds`), the `file_outline` tool
- **Pinned by:** `crates/kartta-mcp/tests/outline.rs`

A local of a body, a member of an inline type or an object literal, and an item of a module block carry no owner, so an
outline of owners alone reads them as top-level definitions. The outline marks each with `in=`, the definition that
holds it, judged from the lines the outline already answers, so the graph stores nothing more.

## Decision

- **The mark.** A `<symbol/>` with no owner carries `in=`, the qualified name of the innermost listed definition
  holding it.
- **What holds what.** A definition holds another that starts strictly inside its lines. A function, a method or a
  macro also holds a field or a method that starts on its first or last line: a member of an inline type in its
  signature.
- **Shared lines.** Definitions declared together, as `int a, b;`, a Go `var (...)` group, a `typedef struct` or a
  DSHL `shader a, b`, share their lines, so none of them holds another.
- **Unmarked.** A definition with neither `owner` nor `in` starts outside every other listed definition, or on such a
  line.
- **One pass.** The outline walks its definitions once in source order beside a stack of the open ones. The C ABI's
  `outline` keeps its fields, and a consumer there nests the definitions by the lines it answers
  ([ADR 4.2](/design-docs/adr/4.2-c-abi-wire.md)).

## Why

- The graph keeps these definitions, and every language but daslang, DSHL and BLK declares some: the outline of
  `bindings/node/src/kartta.ts` listed 17 of them beside its classes (2026-10-20, #232).
- An agent navigates to a nested callable, a Quirrel local function, a React handler, a test in a Rust `mod tests`, so
  the outline keeps them and says where they sit.
- The lines already decide nesting, so the mark costs no build work and no stored field; of the marks sampled against
  the source, all but one of 30 C++ ones were right, the wrong one a function whose span ran past the next.

## Consequences

- A definition on its holder's first or last line that is not a member of a callable's signature stays unmarked, as
  every definition of minified code is. Accepted.
- A definition whose holder is not a definition, as the locals of an anonymous function, stays unmarked. Accepted.

## Rejected

- **Leaving these symbols out** — drops 3,186 nested callables an agent navigates to on the measured trees, and the
  outline would have to count what it dropped.
- **A callable holding every definition on its first or last line** — marks minified code, where in a minified jQuery
  597 of the 611 marks its syntax tree decides were wrong.
- **Each walker recording its locals**, as Go, Rust and Python do for call scoping — a change to nine extractions and to
  how their calls bind, for nesting the outline's lines already show.

## Revisit if

An extraction records holders for its own needs, so the outline can read them in place of judging by lines.
