# Name a Rust method call's receiver by the type its parameter or field of `self` is declared as

- **Date:** 2026-10-23
- **Governs:** `crates/kartta-lang-rust/src/walk/declared.rs`, `crates/kartta-lang-rust/src/walk/bindings.rs`
  (`declared_type`), `crates/kartta-lang-rust/src/walk/calls.rs` (`named_target`, `member_target`)
- **Pinned by:** `crates/kartta-lang-rust/tests/extract.rs`
  (`a_method_call_on_a_parameter_records_the_type_the_parameter_is_declared_as`,
  `a_method_call_on_a_parameter_keeps_the_value_s_receiver_where_the_file_cannot_tell_its_type_is_the_tree_s`,
  `the_use_of_a_parameter_s_module_decides_its_type_before_a_namesake_or_a_function_body_s_use`,
  `a_method_call_on_a_field_of_self_records_the_type_the_struct_beside_the_impl_declares_it_as`),
  `crates/kartta-languages/tests/engine.rs`
  (`a_rust_call_on_a_parameter_binds_the_method_of_the_type_the_parameter_is_declared_as`,
  `a_rust_call_on_a_field_of_self_binds_the_method_of_the_field_s_declared_type_never_the_caller_s`)

A method call on a parameter, `ranking.offer()` in `fn offer(ranking: &mut Ranking)`, or on a field of `self`,
`self.index.refresh_paths()` beside `struct Engine { index: Index }`, names a value whose type a declaration spells. The
walk records that type as the receiver, which the owner tier binds, but only where the file shows the type may be one
of the tree, since that tier binds by name and crates declare namesakes of the standard library's types.

## Decision

- **The declared type.** The walk keeps the type each parameter of a `fn` is declared as, for a name or `mut name`
  pattern. A method call on the name records the type's last segment, which the receiver-owner tier of
  [ADR 3.171](/design-docs/adr/3.171-receiver-call-binding.md) binds at 85.
- **A field of `self`.** A method call on a named field of `self`, `self.index.m()`, records the type the field is
  declared as, where the impl around the call names its type by a bare name and the struct or union of that name is
  declared beside the impl, in the same module or block. Any other named field, one whose struct is declared elsewhere
  or whose type gives none, records its name after a `.`, `.index`, as a value does
  ([ADR 3.56](/design-docs/adr/3.56-rust-call-receivers.md)), so the caller's own owner tier does not take it. A tuple
  field, `self.0.m()`, and a longer chain, `self.a.b.m()`, keep the empty receiver.
- **Shapes that name a type.** The shapes that name a type: `T`, `&T`, `&mut T` and a path; the base of `T<..>`,
  lifetimes alone included; the pointee of `Box`, `Rc` and `Arc`; the type of the `impl` or trait around the call for
  `Self`; and the trait of an `impl Trait` or `dyn Trait` of one bound. A type parameter of the function, of the `impl`
  or trait around it, or of the struct that declares the field, a path through one or through `Self`, `T::Item`, a
  tuple, and any pattern other than a name give no type.
- **The innermost binding.** The innermost binding decides: a `let`, a closure's parameter or a pattern that binds the
  name again hides the type, and a name a closure in a macro's arguments binds is no parameter.
- **A type the tree may hold.** A type is kept only where the file shows it may be the tree's. A name a `use` brings is
  shown where the `use`'s first segment is no toolchain crate, `std`, `core`, `alloc`, `test` or `proc_macro`; a `use`
  inside a function body reaches no signature, and inside an inline module that module's `use`s decide before the
  file's. A path is shown where its first segment is `crate`, `self`, `super` or a module the file declares, or is no
  toolchain crate, by itself or through the file's `use` of it. A name no `use` brings is shown where the file declares
  a type of the name, or where the file has a top-level glob and the name is none of the prelude's `Box`, `Option`,
  `Result`, `String` and `Vec`. Any other type leaves the receiver the value's name after a `.`
  ([ADR 3.56](/design-docs/adr/3.56-rust-call-receivers.md)).

## Why

- `ranking.offer()` recorded `.ranking`, which names no owner, so `find_callers` of `Ranking::offer` listed 6 callers
  and counted the call of kartta-fs's `offer` ambiguous, while the same call written `Ranking::offer(ranking)` bound
  (this repository, 2026-10-23, #253).
- `self.index.refresh_paths()` recorded the empty receiver, which the caller's own owner tier binds, so the call bound
  `Engine::refresh_paths` instead of `Index::refresh_paths`; on wasmtime the field rule adds 2,335 pairs and removes
  788, 29 of 30 sampled added and 30 of 30 sampled removed right (2026-10-25, #248).
- The owner tier binds by name, and a registry's crates declare namesakes of the standard library's types: a parameter
  of `std::fs::File` bound tokio's `File`, a `Vec` allocator-api2's (cargo registry of 488 crates, 2026-10-23, #253).
- 446 of the 464 pairs the rule added or raised on this repository are right, 96% (2026-10-23, #253).

## Consequences

- A call on a typed `let` or a chain keeps the value's name (#484, #485), and so does a call on a field whose struct
  another file declares.
- A field of a standard library type, `child: std::process::Child`, keeps `.child`, which the tiers that read no
  receiver still bind to a namesake: the caller's file, the caller's own owner's method there included, and the name's
  one callable.
- Finding a field's declaration walks up from the call to its impl and scans the items beside it, once per such call:
  Rust extraction of wasmtime took 2.30 s against 2.22 s, medians of 8 rounds on 3 threads (2026-10-25, #248).

## Rejected

- **A type parameter's bound** — binds serde's `Serializer`, `Deserializer` and `Visitor` to whichever of ciborium,
  postcard or serde_json is nearest: 19 of 30 sampled pairs right in the registry (2026-10-23).
- **A closure's typed parameter** — about 18 of 30 sampled right.
- **A typed `let`** — 19 of 30 sampled right; it is #484's case.
- **A type surviving a shadowing `let`** — the pairs it adds are right mostly by chance.
- **No type through any glob** — the pairs it removes are mostly right.

## Revisit if

The owner tier tells a standard library type from a namesake that a crate the caller is built with declares, so that
the namesake no longer takes the call. Not planned.
