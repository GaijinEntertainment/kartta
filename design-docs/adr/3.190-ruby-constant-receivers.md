# Bind a Ruby call on a constant or a literal only within the class it names

- **Date:** 2026-10-25
- **Governs:** `crates/kartta-graph/src/resolve.rs` (`resolve_call`, `constant_receiver_reaches`, `spelled_from`),
  `crates/kartta-lang-ruby/src/walk.rs` (`call`, `literal_class`), `kartta_lang::BareReceivers::Constants`
- **Pinned by:** `crates/kartta-graph/tests/graph/calls.rs`
  (`a_call_on_a_constant_binds_a_member_of_the_class_it_names_or_of_a_base_of_that_class`),
  `crates/kartta-languages/tests/ruby_core_receivers.rs`, `crates/kartta-lang-ruby/tests/ruby.rs`
  (`a_literal_receiver_names_the_class_of_the_value_it_makes`)

`Hash.new(0)` calls Ruby's runtime and `"a".freeze` a method of `String`, so a project's `OptionParser#new` or
`Options#freeze` is a namesake, not the callee. A Ruby call whose receiver is a constant or a literal binds only a
member of the class that receiver names, or of a class that one derives from, at the cost of the methods a class gains
at run time.

## Decision

- **Constants.** Where `Conventions::bare_receivers` is `BareReceivers::Constants`, as Ruby's is, a receiver whose last
  segment starts with an ASCII capital names a constant. Ruby records a constant's path and a literal's class as the
  receiver ([ADR 3.15](/design-docs/adr/3.15-ruby-member-names.md)).
- **The class it names.** The classes and modules the receiver names are those qualified as the receiver, or as the
  receiver inside a scope that encloses the caller: `Version` inside `module Gem` names `Gem::Version`, and elsewhere
  only a `Version` of that whole name. A receiver written from the root, `::Version`, names only the type of that whole
  name, and tier 5 of [ADR 3.171](/design-docs/adr/3.171-receiver-call-binding.md) binds only its members.
- **What binds.** Whatever tier binds such a call, the binding stands only where the definition's owner is such a
  class or one it derives from; otherwise the call binds nothing and counts as not admitted. A class the graph does
  not hold reaches nothing, so `Hash.new` and `File.open` bind nothing where the tree defines no `Hash` or `File`.
- **Values and the caller's own type.** A constant of which the graph holds only values, `DEFAULTS.merge`, keeps
  every tier's binding. So does the caller's own type, `self.x` in a method or a call with no receiver in a type's
  body, since a block a library runs with another `self` writes its calls the same way.

## Why

- A constant or a literal names its class, and the runtime's classes hold none of the project's methods: of 30
  sampled pairs the change removes on Homebrew's library, 26 had no such relation in the source, and all 30 sampled of
  the pairs it adds hold one (2026-10-25, #465).

## Consequences

- A method a class gains at run time binds nothing from a constant: `T.let` binds sorbet-runtime's `T.let` where
  Homebrew's `class << self; prepend TNoChecks` answers it, 626 pairs on Homebrew's library. Accepted.
- A constant that aliases a module names no class the graph holds, so `MacOS::Xcode.installed?` binds nothing where
  `::MacOS = OS::Mac` defines no symbol ([ADR 3.15](/design-docs/adr/3.15-ruby-member-names.md)): 35 sites on
  Homebrew's library. Open.
- Each such call that a tier binds reads the definitions of its receiver's name once more, and the ancestors of the
  classes found, which the cascade keeps per owner. Accepted.

## Rejected

- **Only a class outside the graph** — Homebrew reopens `Array`, `Hash` and `String`, so `[...].freeze` kept its
  guess: 846 of its 848 pairs to a project's `freeze` stayed (2026-10-25).
- **The caller's own type as well** — unbinds the calls of a DSL block that a library runs on another object, as
  `description` inside `cmd_args do`, 2 of 30 sampled removed pairs (2026-10-25).
- **A class whose qualified name ends in the receiver, wherever it lies** — `Version.new` in Homebrew's code bound
  `Gem::Version.new`, and `[...].each` bound `BinData::Array#each`, 621 more pairs (2026-10-25).

## Revisit if

Ruby's extraction reads what a class gains at run time: a `prepend` on its singleton class or `define_method`. Not
planned.
