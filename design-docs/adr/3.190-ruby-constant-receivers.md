`Hash.new(0)` calls Ruby's runtime and `"a".freeze` a method of `String`, so a project's `OptionParser#new` or
`Options#freeze` is a namesake, not the callee. A Ruby call whose receiver is a constant or a literal binds only a
member of the class that receiver names, or of a class that one derives from, at the cost of the methods a class gains
at run time.

## Decision

- **Constants.** Where `Conventions::bare_receivers` is `BareReceivers::Constants`, as Ruby's is, a receiver whose last
  segment starts with an ASCII capital names a constant. Ruby records a constant's path and a literal's class as the
  receiver ([ADR 3.15](/design-docs/adr/3.15-ruby-member-names.md)).
- **The class it names.** The classes and modules the receiver names are those qualified as the receiver, or as the
  receiver inside a scope that encloses the caller: `Version` inside `module Gem` names `Gem::Version`, and elsewhere
  only a `Version` of that whole name. A receiver written from the root, `::Version`, names only the type of that whole
  name, and tier 5 of [ADR 3.171](/design-docs/adr/3.171-receiver-call-binding.md) binds only its members.
- **What binds.** Whatever tier binds such a call, the binding stands only where the definition's owner is such a
  class or one it derives from; otherwise the call binds nothing and counts as not admitted. A class the graph does
  not hold reaches nothing, so `Hash.new` and `File.open` bind nothing where the tree defines no `Hash` or `File`.
- **Values and the caller's own type.** A constant of which the graph holds only values, `DEFAULTS.merge`, keeps
  every tier's binding. So does the caller's own type, `self.x` in a method or a call with no receiver in a type's
  body, since a block a library runs with another `self` writes its calls the same way.
- **A scoped write defines the constant on the module its path spells.** `Foo::BAR = 5` belongs to `Foo`, read as the
  `Foo` of `def Foo.x` ([ADR 3.15](/design-docs/adr/3.15-ruby-member-names.md)), and `::BAR = 5` to no type.
  `self::B = 1` and `a::B = 1` name a module only a run shows, so the walk records no definition.
- **A call on such a constant binds through the class it holds.** The write records `Foo.` for `A::B = Foo`, `Foo` for
  `A::B = Foo.new`, and the empty path for any other value, `Class.new` included. Where no class has the receiver's
  spelling, a call on it binds as on that receiver, so nothing where the graph holds no such class; on the empty path,
  or where its writes name two classes, every tier's binding stands at `FIRST_PARTY`. A receiver that does not spell it,
  `TOPLEVEL_BINDING` for `IRB::TOPLEVEL_BINDING`, finds no value in it.
- **A call never binds a constant.** A name after a `::` with parentheses or arguments sends a method
  (`method_call`, `parse.y:5306`, Ruby 3.4.12).
- **`self.class` reaches the caller's class and what stands above it.** A call on the caller's own class written from
  the root, as `self.class` records it, binds a class method of that class, else the member of the nearest type above
  it, and never an instance method of a class. A method of a module binds at whatever tier finds it, as a class gains
  those at run time, and a member of a class it does not derive from binds nothing.

## Why

- A constant or a literal names its class, and the runtime's classes hold none of the project's methods: of 30
  sampled pairs the change removes on Homebrew's library, 26 had no such relation in the source, and all 30 sampled of
  the pairs it adds hold one (2026-10-25, #465).
- A scoped write sets a constant as a plain one does: `compile_cpath` (`compile.c:5953`, Ruby 3.4.12) puts the module
  the path evaluates to and `setconstant` sets the name there, on the module an alias holds, with `NameError` for an
  owner not yet defined, and both forms are a syntax error in a `def` (`const_decl`, `parse.y:14888`), all run on
  3.4.12.
- A scoped constant read as a plain value bound by name: on Homebrew's library 37 of 70 added pairs were right. Through
  its class, all 62 pairs above `FIRST_PARTY` are right, as are the 35 name guesses it removes (2026-11-01, #659).
- `Gem::URI = Bundler::URI` stands in a `rescue LoadError` beside `module Gem::URI`, so a class of the spelling goes
  first: without it 321 right pairs moved to the fallback, most of them on `Gem::URI` (2026-11-01, #659).
- `self.class` holds the class of the object (`rb_obj_class`, `object.c:297`, Ruby 3.4.12), which is the caller's class
  or one below it, and a method on it runs on the class object, so `self.class.name` is `Module#name` however the class
  defines `def name`. On Homebrew's library, Rails and RuboCop, of the 76 distinct pairs the rule removes 29 of 30
  sampled are false, the 32 it adds are right, and all 30 sampled of the 422 it raises to 85 are right (2026-11-01,
  #521).

## Consequences

- A method a class gains at run time binds nothing from a constant: `T.let` binds sorbet-runtime's `T.let` where
  Homebrew's `class << self; prepend TNoChecks` answers it, 626 pairs on Homebrew's library. Accepted.
- A path through a constant that aliases a module names no class the graph holds, so `MacOS::Xcode.installed?` binds
  nothing though `MacOS.version` binds: 69 lines on Homebrew's library (2026-11-01, #656). Open.
- A first name that Ruby finds in a module around the write keeps its spelling, `Ext::Parser::Config` for
  `JSON::Ext::Parser::Config`, 1 write on Homebrew's library, Rails and RuboCop, and `self::B = 1` defines nothing, 3
  writes there, one of them in a `Struct.new` block. `A::B ||= 1` and a list write, `A::B, A::C = 1, 2`, define nothing
  and stand nowhere outside a string there (2026-11-01, #659). Accepted.
- A scoped constant of no named class stays a guess: of 43 such pairs on Homebrew's library 22 are right, and
  `Reline::IOGate = Reline::IO.decide_io_gate` binds `IOGate.cursor_pos` to a namesake (2026-11-01, #977).
- A class read as the write spells it reaches no class of that name from another scope: `A::B = C.new` inside
  `module A` means `A::C`, and a call in `class D` then looks for `C`. No such write stands on Homebrew's library,
  Rails or RuboCop (2026-11-01, #659). Accepted.
- A plain constant records no class, so `FOO_ACTIONS.each` keeps a namesake at its tier: 1,364 pairs on those trees, 26
  of 30 sampled wrong (2026-11-01, #977).
- A class method only a subclass defines, or one `class_attribute` makes, binds nothing from `self.class`, nor does a
  method a reopened `Module` holds: of the 76 pairs above 2 are such a right pair, `self.class.module_parents`. A call
  in a module's method or in a class written as a path keeps the owner tier: on those trees it binds the module itself
  on 6 pairs, 5 of them false (#1015), and 227 more pairs of path-written classes stay as they were, most of them
  vendored (#1014).
- Each such call that a tier binds reads the definitions of its receiver's name once more, and the ancestors of the
  classes found, which the cascade keeps per owner, and each call on a constant reads them once before the tiers.
  Accepted.

## Rejected

- **Only a class outside the graph** — Homebrew reopens `Array`, `Hash` and `String`, so `[...].freeze` kept its
  guess: 846 of its 848 pairs to a project's `freeze` stayed (2026-10-25).
- **The caller's own type as well** — unbinds the calls of a DSL block that a library runs on another object, as
  `description` inside `cmd_args do`, 2 of 30 sampled removed pairs (2026-10-25).
- **A class whose qualified name ends in the receiver, wherever it lies** — `Version.new` in Homebrew's code bound
  `Gem::Version.new`, and `[...].each` bound `BinData::Array#each`, 621 more pairs (2026-10-25).
- **A scoped write that defines nothing** — keeps every symbol in a file of its type, but `def Foo.x` already leaves it,
  and 62 right pairs bind nothing on Homebrew's library (2026-11-01).
- **A scoped constant as a plain value** — needs no value type, but `MacOS.version` bound `Formula.version`, 33 of 70
  added pairs wrong on Homebrew's library (2026-11-01).
- **The constant as a call's target** — `Gem::URI(uri)` moved from the method to the constant, 133 pairs on Homebrew's
  library (2026-11-01).
- **`self.class` as the constant's spelling, `Formula.`** — `Version#major_minor` bound `Gem::Version.new`, and 9 of the
  28 distinct added pairs were false, `self.class.hash` a class's own `def hash` (2026-11-01).
- **Only the class's own hierarchy for `self.class`** — binds no name guess, but drops `self.class.decorator` on a
  module's `ClassMethods`, 5 of 30 sampled removed pairs right (2026-11-01).
- **`self.class` in a class written as a path too** — no walk finds the base of `class Gem::Cargo < Gem::Builder`, so
  `self.class.shellsplit` bound nothing, 21 right sites on Homebrew's library (2026-11-01).

## Revisit if

Ruby's extraction reads what a class gains at run time: a `prepend` on its singleton class or `define_method`. Not
planned.
