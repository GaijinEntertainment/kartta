# Answer the references of a field or a value by access

- **Status:** accepted
- **Date:** 2026-10-18
- **Updated:** 2026-10-23
- **Initiative:** `03-code-graph`
- **Governs:** `Graph::references`, `SiteQuery`, `crates/kartta-graph/src/calls.rs`
- **Pinned by:** `crates/kartta-graph/tests/graph/typed.rs`, `crates/kartta-graph/tests/graph/members.rs`

"Who reads or writes `Config.Timeout`?" asks for the sites of a field by what each does to it. The uses of
[ADR 3.34](/design-docs/adr/3.34-field-and-value-uses.md) answer it through `Graph::references`, which an
access narrows, and the answer counts every site it turned away; the counts ride on the resolution the query already
runs.

## Decision

- Fields, variables and constants are referents of `Graph::references`, which takes a `SiteQuery`: a confidence floor,
  a limit, and an optional access that keeps the readers (reads, updates and uses as a type), the writers (writes and
  updates), the updates or the uses as a type, and drops calls.
- A site carries its access, so a read and a write on one line are two sites.
- The answer counts every site by kind past the floor whatever the access keeps, the uses as a type apart from the
  reads ([ADR 3.174](/design-docs/adr/3.174-type-use-access.md)).
- Its `ambiguous` counts, for a member, the uses of its name that the tiers left ambiguous, and, for any root, the
  calls of the name that `Walk::ambiguous` counts, so `find_references` and `find_callers` give one number for them.
- [ADR 4.11](/design-docs/adr/4.11-mcp-reference-listing.md) states how `find_references` renders the
  sites.

## Why

- "Who sets it" and "where is it used" are both asked of a field, and an access on each site answers either from one
  query.
- An answer that leaves sites out says how many (CLAUDE.md, `<answers>`), and the resolution the query runs already
  holds each site's kind and every ambiguous one.

## Consequences

- An access narrows what is listed, not what is resolved: a query for the writers of a busy field binds its every use.
  Accepted.

## Rejected

- **Writes only** — answers "who sets" but not "where is it used".
- **A new tool for field uses** — `find_references` already promises the question, and a tool description costs every
  session.
- **One record per site in `find_references`** — up to 11 times the tokens where one function touches the field many
  times.

## Revisit if

Agents ask for a field's sites by a distinction the four accesses do not draw. Medium confidence.
