# Record no Quirrel call through a parameter or a local

- **Date:** 2026-10-16
- **Governs:** `crates/kartta-lang-quirrel/src/walk.rs` (`call`, `bare_call`, `declared_names`, `finish`)
- **Pinned by:** `crates/kartta-lang-quirrel/tests/extract.rs` (`a_call_through_a_parameter_or_a_local_is_not_a_callee`,
  `a_call_through_a_value_keeps_a_function_or_a_class_its_file_defines_or_the_slot_it_destructures`,
  `a_computed_callee_records_no_call`, `member_calls_keep_the_whole_receiver_expression`)

A Quirrel call of a name that a parameter or a local holds calls whatever value the name holds, which no name tier can
know. Such a call is not recorded unless the file defines a function or a class of the name, which is most often the
value the file passes, so the graph loses the calls whose value it cannot know rather than guess a namesake for them.

## Decision

- **A spelled callee.** A call names its callee only where the syntax spells it: a bare name, a root-table `::f`, or
  the field of a member call, whose receiver is the whole receiver expression as written. A computed callee, `a[k]()`
  or `f()()`, records nothing.
- **Parameters and locals.** A bare call of a name that a parameter, a `catch` or `foreach` variable, or a `let`,
  `local` or `const` of an enclosing function declares is not recorded. A name declared anywhere in a body hides it in
  the whole body, and a nested function or class declared in a body is such a local too.
- **The file's own definitions.** The call is kept where the file defines a free function or a class of the name, a
  symbol with no owner.
- **Destructured locals.** A local that destructures a table, `let { build } = cfg`, takes the slot of its name, and
  its call is kept. A destructured parameter holds a value like any other parameter.
- **Requires.** A `require("spec")` or `require_optional("spec")` with one string literal is an import and no call
  ([ADR 3.9](/design-docs/adr/3.9-quirrel-imports.md)).

## Why

- The value a parameter or a local holds is not in the file's text, so every name tier binds such a call to a
  namesake: `cb?(res)` in `doBuyUnlock(unlockName, cb = null)` bound a table slot of another script's window.
- A file that defines a free function or a class of the name most often passes that definition, such as the `sendResp`
  that `matching/api.nut` hands its handlers.
- A destructured local takes the slot a factory or a module hands out by its name, which is the definition the call
  reaches.
- On the game-engine tree the rule removes 403 caller-callee pairs and adds none, 23 of 30 sampled wrong (2026-10-23,
  #390).

## Consequences

- A call through a value that does hold a definition of the name elsewhere loses its edge: 7 of the 30 sampled pairs
  removed were right. Accepted.

## Rejected

- **No call through any local or parameter** — drops the same-file calls of nested functions and of the definitions a
  file passes as an argument, mostly right: 2,288 pairs leave, 1,717 of them within the file.
- **Every local and parameter but the ones a function or a class binds, the file's own definitions not kept** — 845
  pairs leave, 20 of 30 sampled wrong; the calls of a definition the file passes are among them, 24 of 30 sampled
  right.
- **A destructured local as a value** — drops the slots a factory or a module hands out by name, more right than wrong,
  `let { setSkinCustomTags } = mkSkinCustomTags(unitName)` among them.

## Revisit if

The walk learns which definition a parameter or a local holds, as a call through it would then name a known value. Not
planned.
