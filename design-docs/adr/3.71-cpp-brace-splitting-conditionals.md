# Read a conditional that splits a brace with its first branch taken

- **Date:** 2026-10-22
- **Governs:** `crates/kartta-lang-cpp/src/repair.rs` (`untaken_branches`, `ConditionalScan`, `BraceSplit`,
  `InitializerList`, `recovery_of`)
- **Pinned by:** `crates/kartta-lang-cpp/src/repair.rs`
  (`a_conditional_whose_first_branch_unbalances_its_braces_is_read_with_that_branch_taken`,
  `a_function_whose_conditional_branches_each_open_a_brace_ends_at_its_own_brace`,
  `a_function_whose_conditional_splits_a_call_and_a_brace_ends_at_its_own_brace`,
  `only_a_first_branch_that_leaves_a_brace_open_splits_where_an_error_holds_the_directive`,
  `a_comment_holds_no_directive`, `a_raw_string_holds_no_brace`,
  `a_constructor_whose_initializer_list_holds_a_conditional_keeps_its_class_members`,
  `a_class_whose_only_constructor_lists_a_conditional_ends_at_its_own_brace`,
  `an_initializer_list_inside_one_branch_of_a_conditional_keeps_its_directives`,
  `a_conditional_the_grammar_reads_inside_a_parsed_initializer_list_is_left_as_written`)

The C++ grammar reads each branch of a preprocessor conditional as a run of whole statements. A first branch that
leaves a brace open, `#ifdef _XBOX` `{` `#else` `if (x) {` `#endif`, makes the `#else` an unknown directive inside the
block it opened, or, where the branch also leaves a call or a condition open, a bare token of the error that swallows
it; the later branch's brace then opens a block nothing closes, and the definition runs to the end of the file, as the
grammar runs `PxcBruteForceOverlapBackface` from line 753 to 1379. The second parse reads such a file as the
preprocessor would with its first branches taken, at the price of the code in the branches not taken.

## Decision

- **What fires the repair.** The repair fires where the first tree holds a branch directive, `#else`, `#elif`,
  `#elifdef` or `#elifndef`, as an unknown directive, or as a bare token of an error.
- **What it blanks.** It then blanks, before the second parse
  ([ADR 3.169](/design-docs/adr/3.169-cpp-second-parse-repairs.md)), every conditional of the file that has a later
  branch and whose first branch leaves a brace open: its opening directive and everything from its first later branch
  through its `#endif`. Where an unknown directive fired it, so is every conditional whose first branch closes a brace
  it did not open, `} else if (a) {`.
- **An initializer list.** Where the first tree holds an error and a conditional that opens between the items of a
  list, after code that ends in `,` or `) :` or before a first branch that opens with `,` or `:`, each conditional
  inside a constructor's initializer list, from the `:` after a `)` to the body's `{`, is read with its first branch
  taken, and the list's other directives, `#pragma warning(push)` among them, are blanked with it. An opening the
  grammar holds as an error inside an initializer list it parsed fires nothing. A list that a `;` ends, or that starts
  inside one branch of a conditional, is left as written.
- **Comments and strings.** A directive inside a comment or a string literal, a raw string included, is none, and a
  brace there counts for nothing.

## Why

- Every such conditional, not only the misread one, because blanking one changes how the grammar reads the next:
  repairing the misread one alone ended four tinyexr functions inside a later `#else`, `DecodeTiledLevel` among them
  (#245).
- The first branch keeps the code a definition's braces enclose; of the misread conditionals' definitions, 27 of 28
  whose end changed now end at their closing brace, and 467 regain their namespace or class, 30 of 30 sampled right
  (C++ game-engine tree, 2026-10-22, #245).
- A bare token fires the repair in 8 game-engine files, and there it ends `TIFFClientOpen` at line 502 rather than 749
  and gives 79 names their namespace back (2026-10-24, #367).
- A first branch that closes a brace and opens it again, doctest's `} namespace doctest {`, stays as written after a
  bare token: blanking it there takes the namespace off about 150 names of `doctest.h` (#367).
- A conditional inside an initializer list splits the one declaration the list belongs to, which no branch completes,
  so the constructor is lost and its class can close at it or be lost too; with the first branch taken, 35
  constructors come back on the game-engine tree, with the classes of Jolt's `Constraint` and bullet's
  `btIndexedMesh`, and 30 of 30 sampled added calls are right (2026-10-29, #407).

## Consequences

- The code of a branch not taken leaves the extraction: its definitions, calls and uses, in the 64 game-engine files
  an unknown directive repairs and the 6 a bare token does (#245, #367). Accepted.
- 775 of the 43,356 game-engine files hold a bare branch token and pay a byte scan of their conditionals, and 8 of
  them a second parse they did not take before (2026-10-24, #367). Accepted.
- A definition can still end wrong where the misreading has another cause: curl's `ossl_connect_step2` (accepted).
- A taken list's conditionals leave the uses their conditions read, 170 macro names on the game-engine tree and none a
  definition the graph holds, and the code of their later branches, 85 uses there (2026-10-29, #407). Accepted.
- The opening check picks 437 of the 17,088 game-engine files whose first tree holds an error for a byte scan of
  their conditionals, and with the search of [ADR 3.169](/design-docs/adr/3.169-cpp-second-parse-repairs.md) under a
  class body's conditionals, which alone costs 0.83%, C++ extraction takes 1.48% more instructions (2026-10-29,
  #407). Accepted.
- A constructor whose file's first tree fails at its top level, or that a macro precedes out of its class, still
  loses its list (#412, #409): PhysX 3.4's `SphereAABBTest_SIMD`, `MBP::MBP` and `PxSceneDesc::PxSceneDesc`.

## Rejected

- **Take the first branch of every conditional the tree misread, whatever its braces** — changes 136 files and drops
  671 definitions, most of them alternatives the grammar would have read (#245).
- **Take the last branch** — loses 4,049 calls where the first gains 122 (#245).
- **Keep every branch and blank only the braces a branch leaves unmatched** — binds 53 calls more, but ends 7
  definitions fewer at their brace, `Curl_netrc_scan` and PhysX's `stab` among them, and leaves 76 more names without
  their namespace (#245).
- **Fire on a bare token only where its own conditional's first branch leaves a brace open** — the same extraction on
  every game-engine file, for a match of each token against the scan's conditionals (#367).
- **Scan the conditionals of every file whose first tree holds an error for initializer lists** — the same constructors
  and classes for 2.07% more instructions of C++ extraction alone, 17,088 files scanned where the opening directive
  picks 437 (#407).
- **Keep an initializer list's other directives** — gtest's `UnitTestImpl` constructor keeps its `#pragma warning`
  lines, and the 25 names of the namespace after it lose `internal::` (#407).
- **Take the conditionals of a list that starts inside a conditional's branch** — PhysX's `PxTransform`, whose
  constructor writes one list per branch, loses its class and four of its members (#407).

## Revisit if

A tree-sitter-cpp release reads a conditional's branches as alternatives rather than as runs of statements. Medium
confidence that none will soon.
