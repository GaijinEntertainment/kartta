# Bind a bare call through the scope that offers its name, then the nearest callable

- **Date:** 2026-10-16
- **Governs:** `crates/kartta-graph/src/resolve.rs` (`resolve_by_tiers`, `resolve_by_name`, `resolve_outside_scope`,
  `bodies_values`, `imports_from_outside`), `crates/kartta-graph/src/scope.rs` (`resolve_by_proximity`),
  `kartta_lang::Conventions` (`own_members`, `inherited_members`)
- **Pinned by:** `crates/kartta-graph/tests/graph/calls.rs`, `crates/kartta-languages/tests/engine.rs`
  (`a_rust_method_call_binds_the_one_method_of_its_name_whatever_value_a_body_declares_of_it`)

A call that its receiver or qualifier does not place, past tiers 2 to 5 of
[ADR 3.7](/design-docs/adr/3.7-call-resolution.md), names a definition by name alone. Tiers 1, 6 and 7 bind it where
the language's scope finds the name, then guess the one callable nearest the caller, at the confidence of a guess.

## Decision

Each tier binds at the confidence given, from `kartta_graph::confidence`:

- **Tier 1, a local call.** A local call binds the local its scope declares, at 80.
- **Tier 6, scope.** The caller's file (80); then, where a package is not a directory, a bare call of a name that an
  import of code the graph does not hold binds ends the cascade with nothing bound, as `useState()` with `useState`
  from `react` binds no project namesake; then its dot imports (95), a glob of a module's file (95,
  [ADR 3.45](/design-docs/adr/3.45-module-file-bindings.md)), its
  package directory (75), the one file it includes that offers the name (70), and the re-export chains of those files
  (65). A file that offers the name on two owners, or two files that offer it, leave the call to the tiers below. Where
  a package is a directory, a bare call that these tiers do not bind binds nothing.
  [ADR 3.42](/design-docs/adr/3.42-transitive-include-reach.md) reads includes through the files
  they include. A PHP static call on a class outside the graph binds through these tiers but the caller's file alone,
  and binds nothing below them
  ([ADR 3.167](/design-docs/adr/3.167-php-outside-class-calls.md)).
- **Tier 7, the nearest callable.** Where the call's shape admits a candidate at all, a member of the caller's own owner
  (80, or 15 off a PHP list, [ADR 3.41](/design-docs/adr/3.41-own-owner-receivers.md)), the one callable of the name
  (60), then the nearest of the caller's directory (50), its parent directory (30) and the code outside vendored code
  (15) that holds a callable of the name: its one callable binds, and several bind nothing. Where values are call
  targets, a variable or a constant local to a body counts among the callables of its name at each of these steps that
  would hold it, though it binds nothing, except against a macro invocation or a method call
  ([ADR 3.171](/design-docs/adr/3.171-receiver-call-binding.md)), which calls no value. These ADRs narrow what these
  tiers take:
  - [ADR 3.39](/design-docs/adr/3.39-member-call-free-functions.md), a member call and a free
    function;
  - [ADR 3.171](/design-docs/adr/3.171-receiver-call-binding.md), a method call and a type;
  - [ADR 3.184](/design-docs/adr/3.184-rust-module-path-calls.md), a Rust member call and a free function;
  - [ADR 3.40](/design-docs/adr/3.40-runtime-method-calls.md), a runtime method, and a library method on a value,
    whose one callable, and the one member the files the caller includes offer at tier 6, bind at 15;
  - [ADR 3.185](/design-docs/adr/3.185-included-runtime-members.md), a runtime method and an included file's member;
  - [ADR 3.43](/design-docs/adr/3.43-cpp-calls-on-values.md), a C++ call on a value;
  - [ADR 3.44](/design-docs/adr/3.44-namespace-call-targets.md), a namespace;
  - [ADR 3.46](/design-docs/adr/3.46-test-definition-binding.md), a test definition;
  - [ADR 3.42](/design-docs/adr/3.42-transitive-include-reach.md), a callable no include reaches;
  - [ADR 3.179](/design-docs/adr/3.179-rust-crate-reach.md), a Rust definition of
    a crate the caller's crate is not built with, which also gates tier 6;
  - [ADR 3.192](/design-docs/adr/3.192-call-argument-counts.md), a name a call's arguments narrowed, which decides how
    its nearest callable binds.
- **Dot imports and members.** A dot import comes before the package directory for every call without a receiver.
  `own_members` and `inherited_members` decide what a bare call inside a member reaches, as their doc comments in
  `crates/kartta-lang/src/language.rs` state, and the vendored flag keeps vendored code out of the last proximity step.

## Why

- The scope tiers follow how the language's own scope finds a bare name, the file before its imports and its imports
  before its includes, and the nearness steps rank the guesses below every tier that scope decides.
- Go rejects a package that declares a name a dot import also brings in, so a dot import and the package meet only in a
  test package beside the one it tests, where the dot import is meant.
- A bare call of a name an import of outside code binds goes to that code, never to a project namesake.
- A body's value of the name says calls of that name may call values the graph does not follow: with the TS/JS
  locals left out of the count, 21 of 49 new guesses on the Go monorepo snapshot were right (2026-10-24, #449).

## Consequences

- An unqualified C++ operator call binds by name, not through its argument types (#303).
- A callable whose name a body's value elsewhere shares binds by no guess at the step that holds that value, though
  the value is not what the call calls. Accepted.

## Rejected

- **A package index of every declared name** — took 51 MB on the Go monorepo of 119,888 Go files (2026-10-16), where
  the name index filtered by directory answers the same.

## Revisit if

A language's scope finds a bare name through a step these tiers do not model, or ranks its steps in another order.
Medium confidence, since each new language brings its own lookup.
