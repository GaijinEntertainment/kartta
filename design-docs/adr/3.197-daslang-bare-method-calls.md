# Read a bare daslang call in a method as a call on self

- **Date:** 2026-11-01
- **Governs:** `crates/kartta-lang-daslang/src/lib.rs` (`CONVENTIONS`), `kartta_lang::InheritedMembers`
- **Pinned by:** `crates/kartta-languages/tests/daslang_inherited_members.rs`

A bare call in a daslang method reaches a member of the class or of a class above it, though it records no receiver. The
graph follows the compiler's order for functions: a global function its file offers answers first, then the member. It
holds no native and no variable of a function type, so it gets the shapes those decide wrong, a handful on dagor.

## Decision

- **The order.** Under `InheritedMembers::Found`, a global function of the name its file offers, of a count it can take,
  binds first, and else the member of the class or of the nearest class above it, a `def static` included, through the
  bare-call tiers of [ADR 3.172](/design-docs/adr/3.172-bare-call-binding.md).
- **A plain function.** A plain function reaches no member.

## Why

- Daslang's own order for a bare call runs the global lookup first (`src/ast/ast_infer_type.cpp:6306`), then a local, a
  parameter or a global variable of a block, lambda or function type (`:6389`), and only then, in a function with a
  class first argument, the field of that name on `self`, else a `def static` of the class or a parent (`:6404`). On
  dagor the rule adds 26 pairs and removes none, 25 of 26 right (2026-11-01, #881).

## Consequences

- A call of an inherited member's name binds the member where a native global takes it, since the graph holds no native:
  `error("...")` in `ByteStream.read` reaches `builtin_error`, not `Serializer.error`. 1 dagor pair. Accepted.
- A member the caller's own file holds stands ahead of a global function of a required file, the file tier reading
  first, and a bare call in a `def static` with no class first argument, or one of the name of a local of a function
  type, reaches a member the compiler does not promote it to. None of the 26 dagor pairs turns on either. Accepted.

## Rejected

- **Record `self` as a bare call's receiver** — a receiver ends the call at the class, where the compiler reads the
  global functions first (`src/ast/ast_infer_type.cpp:6306`), and takes it out of
  [ADR 3.194](/design-docs/adr/3.194-daslang-call-scope.md)'s scope.

## Revisit if

The graph holds daslang's native functions, or a variable's type. High confidence in the order, read from the compiler.
