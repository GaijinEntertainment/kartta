# Name a Rust call's receiver only where its syntax spells it

- **Status:** accepted
- **Date:** 2026-10-16
- **Updated:** 2026-10-22
- **Initiative:** `03-code-graph`
- **Governs:** `crates/kartta-lang-rust/src/walk/calls.rs` (`call_target`, `member_target`, `path_receiver`,
  `value_receiver`), `crates/kartta-lang-rust/src/walk/settle.rs` (`settle_paths`)
- **Pinned by:** `crates/kartta-lang-rust/tests/extract.rs`
  (`a_call_belongs_to_the_function_around_it_and_self_names_the_impl_type`,
  `a_scoped_or_macro_call_names_its_last_segment`, `a_member_call_on_an_unnamed_expression_keeps_an_empty_receiver`,
  `a_member_call_on_a_lowercase_value_records_its_name_after_a_dot_and_on_an_item_or_other_its_name`),
  `crates/kartta-lang-rust/tests/modules.rs`
  (`a_scoped_receiver_names_the_type_the_file_declares_or_keeps_its_last_segment`,
  `a_self_path_call_records_no_receiver`)

A call's receiver is what the cascade of [ADR 3.7](./3.7-resolve-calls-when-a-query-asks.md) binds through, and one
file's bytes tell a value from a type or a module only by how the call is written. The Rust walk records a receiver
that the syntax spells, marks a lowercase value's name so that it names no module, and resolves nothing through a
`use`; the resolver binds the paths instead.

## Decision

- `self.m()` and `Self::f()` name the owner of the `impl` or `trait` around them, and follow it when an impl's owner
  settles (ADR 3.11).
- A scoped call names the type or module its path names in the file under the inline-module chain, `a::Worker::run()`
  naming `a::Worker` and `super::W::new()` in `a::inner` naming `a::W`, and otherwise the path's last segment,
  `Graph::build()` naming `Graph`. A path whose last segment is `self`, `super` or `crate` names a module and records no
  receiver. No receiver is resolved through a `use`.
- A bare call, `helper()`, records no receiver. A member call on anything but a name, `x.y.z()` or `f().g()`, records
  the empty receiver.
- A member call on a lowercase name other than `other` records the name after a `.`, `.socket` for `socket.connect()`,
  which names no module, import or owner; how the graph binds it is
  [ADR 3.39](./3.39-bind-a-member-call-to-a-free-function-only-where-a-value-can-hold-one.md)'s and
  [ADR 3.40](./3.40-bind-a-runtime-method-s-call-only-to-a-member-that-scope-reaches.md)'s. A capitalised name, a unit
  struct or a static, `Fish.write()` or `SETTINGS.get()`, records the name, and so does `other`, the receiver the
  conventions list for a value of the caller's own type.
- A method call on a parameter of a declared type records that type instead, as
  [ADR 3.55](./3.55-name-a-rust-method-call-s-receiver-by-its-parameter-s-declared-type.md) decides.
- A macro invocation is a call of the macro, with no receiver.
- [ADR 3.53](./3.53-record-no-rust-call-through-a-value-and-bind-a-body-s-item-as-a-local-call.md) decides the calls
  that bind a body's own item and the calls through a value, and
  [ADR 3.54](./3.54-read-the-calls-a-rust-macro-s-arguments-write-from-its-tokens.md) the calls a macro's arguments
  write.

## Why

- A value's name alone reads as the module a path call names: a value named like an imported module bound through the
  import, tokio's `socket.connect()` taking nix's `connect`, and one named like an owner bound that owner's members, a
  value `str` taking the `len` of nix's `impl ... for str` (cargo registry of 488 crates, 2026-10-22).
- A capitalised operand is an item the graph holds by that name, and `other` is the conventional name of a second value
  of the caller's own type.

## Consequences

- A call on a local, a field or a chain names no type and binds only a runtime method or by the tiers that need no
  receiver (#484, #248, #485).

## Rejected

- **Resolving a receiver through a `use` in the extraction** — `use crate::m::Worker; Worker::run()` would name
  `m::Worker` only by reading the files the path leads to, which one file's extraction does not have; the resolver
  binds the kept path instead
  ([ADR 3.50](./3.50-bind-a-rust-path-into-another-crate-through-its-library-s-module-files.md)).

## Revisit if

The walk learns the type a local, a field or a chain holds (#484, #248, #485), so more receivers than a parameter's can
name a type. The issues are open.
