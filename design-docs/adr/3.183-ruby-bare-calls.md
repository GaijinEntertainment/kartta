# Read a Ruby bare name as a call unless an earlier binding makes it a local

- **Date:** 2026-10-23
- **Governs:** `crates/kartta-lang-ruby/src/locals.rs`, `crates/kartta-lang-ruby/src/walk.rs` (bare names)
- **Pinned by:** `crates/kartta-lang-ruby/tests/ruby.rs`
  (`a_bare_word_is_a_call_unless_a_binding_before_it_makes_it_a_local`,
  `every_binding_form_makes_a_bare_word_a_local`, `a_binding_reaches_the_rest_of_its_scope_and_the_blocks_inside_it`)

A Ruby call with no receiver, no arguments and no parentheses, `setup`, parses as a name, the same as a read of a local
variable, and Ruby tells them apart by the source before it. The walk keeps the names each scope binds and reads a bare
name no binding reaches as a call, at about 19 bytes of heap for each bare call, and with a local bound at run time read
as a call.

## Decision

- **A bare name is a call unless an earlier binding makes it a local.** A bare name no binding reaches is a call with
  no receiver, wherever a value stands, a receiver included: `items` in `items.each`.
- **Scopes.** The walk keeps the names bound in each scope: a `def` and the body of a class, a module or a `class << x`
  see no binding around them, and a block or a lambda sees the bindings of the scopes around it.
- **Bindings.** A parameter of any kind, an assignment, a `for` target, a `rescue => e`, a pattern capture and a named
  group of a regexp literal matched with `=~` bind a name from where they stand to the end of their scope.
- **Names that never call.** Inside a block or a lambda, `it` and `_1` to `_9` read its implicit parameters, and
  `__FILE__`, `__LINE__` and `__ENCODING__` are never calls.
- **Members and receivers.** How a member is qualified and a call's receiver recorded is
  [ADR 3.15](/design-docs/adr/3.15-ruby-member-names.md).

## Why

- A method called only by its bare name has a caller, and the bindings of each scope tell such a call from a variable
  read as Ruby's own parser does: on Homebrew's library, its vendored Ruby aside, the walk records the 38,703 bare
  calls Prism finds and none of its 77,545 local reads, and the graph gains 3,197 pairs, 112 of 114 sampled right
  (2026-10-23, #192).

## Consequences

- Each bare call is a stored call site, about 19 bytes of heap. Accepted.
- A bare call in a block another object runs, `sig { override }`, binds a namesake, and a local bound at run time,
  `binding.local_variable_set`, reads as a call. Accepted.

## Rejected

- **No call for a bare name** — a method called only as `setup` has no caller, and Homebrew's library makes 38,703
  such calls.

## Revisit if

The extraction runs code, and so sees a local that a binding sets at run time and the object a block runs on. Not
planned.
