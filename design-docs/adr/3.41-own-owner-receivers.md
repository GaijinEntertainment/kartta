# Trust the caller's own owner only on the receivers a language lists

- **Date:** 2026-10-19
- **Governs:** `crates/kartta-graph/src/scope.rs` (`member_of_the_caller_s_owner`), the `Conventions` of
  `crates/kartta-lang-python`, `crates/kartta-lang-ruby`, `crates/kartta-lang-rust`, `crates/kartta-lang-daslang`,
  `crates/kartta-lang-php` and `crates/kartta-lang-quirrel`, `kartta_lang::Conventions::own_type_receivers`,
  `kartta_lang::Conventions::unlisted_receivers`
- **Pinned by:** `crates/kartta-graph/tests/graph/calls.rs`
  (`a_language_that_lists_its_own_type_receivers_binds_the_caller_s_owner_only_on_one`,
  `a_member_call_of_an_unknown_type_picks_a_member_of_the_caller_s_owner`,
  `the_caller_s_owner_binds_the_copy_of_its_member_nearest_the_caller`,
  `the_caller_s_owner_binds_no_class_of_its_name_in_another_scope`),
  `crates/kartta-languages/tests/php_own_receivers.rs`,
  `crates/kartta-languages/tests/quirrel_inherited_members.rs`

A member call whose receiver names no owner falls, past scope, to the member of the caller's own owner
([ADR 3.172](/design-docs/adr/3.172-bare-call-binding.md), tier 7).
That is the call a method makes on its own receiver, and a guess that any other value has the caller's type. A language
that lists the receivers it writes for a value of the caller's own type keeps the tier for those alone, at the price of
a value of that type under another name.

## Decision

- **The tier.** A member call whose receiver names no owner binds the member of the caller's own owner of its name, at
  80, once the scope tiers bind nothing and the call's shape admits a candidate. Of several, it binds the one in the
  caller's file, then in its directory, then the first in path order, as a receiver's owner does
  ([ADR 3.171](/design-docs/adr/3.171-receiver-call-binding.md), tier 5).
- **The caller's own owner.** It is the one the caller's qualified name spells, `A\App` for `A\App::f`, and a class of
  the same name in another scope, `B\App`, binds nothing here. A member this tier turns away is left to the tiers after
  it, so the one callable of the name still binds at 60.
- **Listed receivers.** Where a language lists `Conventions::own_type_receivers`, the tier takes only a listed
  receiver: Python `self`, `cls` and `other`; daslang `self`; PHP `$this`, `self` and `static`; Ruby and Rust `other`
  alone, because each records `self`, and Rust `Self`, as the name of the caller's owner, which binds at 85 as a
  receiver that names an owner ([ADR 3.171](/design-docs/adr/3.171-receiver-call-binding.md), tier 5). Any other
  receiver that names no owner binds nothing here and goes on to the tiers after it.
- **Receivers kept off the list.** Quirrel lists `this` to start a walk at the caller's class
  ([ADR 3.193](/design-docs/adr/3.193-receiver-class-members.md)), and its `Conventions::unlisted_receivers` keep the
  tier for every other receiver that names no owner, at 80; a field of `this` whose writes settle a class names that
  class instead, and any other field binds the caller's own member as a guess
  ([ADR 3.198](/design-docs/adr/3.198-quirrel-field-receivers.md)).
- **Languages that list none.** Every other language lists none and keeps the tier for any receiver that names no
  owner, Lua among them.

## Why

- For the caller's own receiver the tier binds the call it makes, and `other`, the second operand of a comparison,
  mostly has the caller's type.
- For another value's name it guesses the caller's type, and the call tools show 80 as certain: Python's
  `sock.close()` inside an event loop bound `BaseEventLoop.close`. Of the Python sites the list takes out of the tier,
  72% of those sampled were wrong and 11% right (Python 3.9 standard library and C++ game-engine tree, 2026-10-19,
  #182).
- Ruby's `other` alone takes out sites that were wrong in all but one of those sampled (Homebrew library, 2026-10-19,
  #184).
- A class of the caller's owner's name in another file is a copy or a namesake, and the caller's own file holds the
  class it is in: all 42 pairs the nearest choice adds, on Symfony, Laravel and the C++ game-engine tree's Python and
  Quirrel, bind the caller's own file's member in place of another file's (2026-10-23, #201).
- Another scope's namesake is not the caller's: a base is the class the file names, which the graph reads in full
  ([ADR 3.14](/design-docs/adr/3.14-php-includes.md)), or a class outside the tree. Of the 25 Laravel and Symfony pairs
  the namesake still bound, 24 are wrong, `$diff->add()` in Eloquent's `Collection` binding
  `Illuminate\Support\Collection::add` among them, and so are the 4 Python pairs of the C++ game-engine tree it moves
  (2026-11-01, #524).
- With a PHP variable's and property's class read ([ADR 3.199](/design-docs/adr/3.199-php-variable-classes.md)), every
  one of the 12 pairs a PHP receiver off the list still bound to the caller's own class is wrong, as
  `$mechanic->car()` in Laravel's `User`, which runs `Mechanic::car` (Laravel and Symfony, each read, 2026-11-01, #926).

## Consequences

- A value built from the caller's own type under another name loses its member: about one sampled Python site in ten,
  as `p = Profile()`, and one in six a composite's children, as `e.streamline()` for each `e` of `self.exprs`.
- A right PHP call of the caller's own class on a receiver off the list, whose class the walk does not read, binds
  nothing: none of the 12 pairs is one (Laravel and Symfony, 2026-11-01). Accepted.

## Rejected

- **Python `self` and `cls` without `other`** — takes 25 more sites out of the tier, each on a value of the caller's
  type (2026-10-19).
- **The empty receiver for a Python value, the contract C++ and TypeScript keep** — took 282 edges at 57% right,
  because the receiver's owner tier (85) and the receiver's spelling (60) read the name it drops (2026-10-19).
- **Ruby with no list** — takes 3,233 more sites on `other` out of the tier, most of them on a value of the caller's
  type (Homebrew library, 2026-10-19).
- **Ruby `new` beside `other`** — keeps 12 right sites, but a parameter can take the name, as
  `Gem::Requirement#concat(new)` does (#210).
- **PHP's other receivers at 15, ahead of the guesses by nearness** — all 12 pairs it binds are wrong (Laravel and
  Symfony, 2026-11-01, #926).
- **PHP `$this` alone, or a PHP list with `$other` or `parent`** — `$this` alone drops the 17 right
  `self::__construct()` calls of WordPress's PHP 4 constructors, no pair on Laravel or Symfony has `$other` as its
  receiver, and `parent` binds its base first.
- **A Lua list** — every Lua module names its table `M`, so most of the edges such a list drops are right (2026-10-19,
  #185).
- **A Quirrel list that narrows the tier, by dropping or guessing** — its comparators and monads take their own type:
  11 of the 44 pairs off the list are right on the game-engine tree, so a demotion is right on 75%, under the bar a
  tier move is taken at (2026-11-01, #857).

## Revisit if

A PHP tree holds right calls of the caller's own class on receivers off the list whose class the walk does not read, in
numbers a false edge would be worth trading for. Medium confidence for the languages that list none.
