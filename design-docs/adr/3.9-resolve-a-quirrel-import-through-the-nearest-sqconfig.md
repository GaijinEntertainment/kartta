# Resolve a Quirrel import through the nearest .sqconfig, and name a function value by its binding

- **Status:** accepted
- **Date:** 2026-10-16
- **Revised:** 2026-10-23
- **Initiative:** `03-code-graph`

Quirrel scripts the UI and game logic of the game trees the code graph reads. Most of its functions are values — a
table slot, a `let`, the target of `<-` — and its imports name files through mounts that the script tooling reads from
a `.sqconfig` file, not through paths a reader can follow from the script alone.

**A function value takes the name of its binding.** The name a caller writes is the binding's, `hud.draw` or
`let build = function() {...}`, so that is the symbol's name; a function declared with a name of its own keeps it. A
member of a named or bound class is a method of the class, and an assignment to a field access binds a method of the
whole receiver expression as written, `gui.Widget.build` one of `gui.Widget`. A data slot with a plain name, of a class
or of a table that a file-scope `let` or `local` binds, is a field of that owner; a computed `[k] = v` or quoted
`"k": v` slot names no field. A function value with no binding and no name names no symbol, so its calls and uses
belong to the function around it, or to the file at the top level (revised 2026-10-23).

**A call names its callee only where the syntax spells it**: a bare name, a root-table `::f`, or the field of a member
call with the receiver expression as written. A computed callee, `a[k]()` or `f()()`, records nothing.

**An import resolves through the nearest `.sqconfig` in the script's directory or above it, and that file alone**, as
the script tooling reads it. `%name/rest` names `rest` below the directory the config mounts as `name`; any other
specifier that ends in `.nut` names the file beside the script, else the file below the first of the config's base
paths that holds it, and any other specifier without `.nut` is a native module. Both forms read `\` as `/`, and the
loader appends no extension to either. A config does not fall back to the specifier's shape: what the tooling would
not load is no include. A config that cannot be read still governs its scripts, with no mount and no base path,
because what it mounts is unknown and a guess from another config or from the shape could name a file the tooling
never loads. A script no `.sqconfig` governs resolves by the specifier's shape — `%root/rest` and any slashed or `.nut`
specifier name the file under the nearest directory of the script that holds them, `./` and `../` name the file
relative to the script, each with `.nut` appended when the path as written names none, and a bare name names no file.
A directive that names no file is an import, kept as written, so a dependency on a native module stays visible. Of a
config, only the `mount` and `base_path` lines are read: the tooling also follows its `include` lines and `\` line
continuations, which are not followed here, so a mount or a base path stated through either resolves nothing.

On the game-engine tree this was built against, 7,661 of 8,785 scripts sit under one of 82 `.sqconfig` files, and
52,062 of 63,009 directives resolve to a file; the rest name native modules (`math`, `eventbus`, `dagor.workcycle`),
which no script provides. Symbols, calls and includes match the reference extraction on every one of the 8,785 files.

**Revised 2026-10-17: under a governing `.sqconfig`, a place the loader tries takes the one file that differs from it
only in ASCII case.** The loader reads shipped scripts from a vromfs whose lookup lowercases the path, so a specifier
that differs from its file only in case loads there. Each place is asked in the loader's order, the file beside the
script, then each base path, or the place below a mount, exactly first and then through
`Repository::files_ignoring_case` (ADR 3.30), so a file in another case beside the script wins over a base path's exact
one, as the loader takes it; several files of one place abstain. A mount name keeps its case, and so does the `.nut`
suffix that tells a script from a native module; the rest of a path, a mounted path's suffix too, matches without case.
A script no `.sqconfig` governs still matches case: its mounts are a guess from the directories around it, and a lookup
without case would widen the guess. On that tree neither form gains an include: under a config every specifier that
names a file names it in its own case, and the guessed form, measured with a lookup without case too, gains none either.

**Revised 2026-10-23: a function value with no binding and no name gives its calls and uses to the site around it.**
The first form of the rule gave such calls no caller, which predates ADR 3.23's revision of 2026-10-19: since then a
call with no caller lists its file as the caller, so a lambda that a named function returns or passes credited the
file and left the function without its callees. Its calls and uses belong to the innermost function around it, and to
the file only at the top level; a value with a binding or a name of its own keeps its symbol. On the game-engine tree
52,788 calls and 31,499 uses of 3,399 scripts move from the file to a named function, and no other part of any
extraction changes. 13,205 caller-callee pairs are gained: of 60 sampled, every caller is the function around the
call and 52 callees are right; the 8 wrong ones come from tiers that bind the same call shapes inside a function, 4 to
a stub of the Quirrel compiler's test data at the unique-name tier, 2 member calls such as `uiColor.get()` to a free
`get` at the parent-directory tier, a call of a parameter, and a member call to a namesake in another game's tree.
`find_unused` reports 9,596 Quirrel definitions for 10,458, and the parity plan's `find_callers` answers list 267
file-scope callers for 341. The reference engine drops every call of such a value, so none of the pairs gained is one
it answers.

**Revised 2026-10-23: a module table owns a function it declares, and a function its slot binds stays free.**
`let t = { function f() {} }` declares the method `t.f`, as `key = 1` in the same table is the field `t.key`, so
`t.f()` binds through the owner and a query for `t.f` finds it; a free `f` had bound every bare `min()` of the tree to
the `Math.min` of the compiler's test data. On that tree 399 functions of 88 tables in 78 scripts become methods, and
calls and uses change only the name of their site. Keyed by call site, 913 pairs leave and 276 arrive, 214 of those at
the receiver tier; of 30 sampled of each, 29 leaving were wrong, 21 of them `min`, the right one a member call that a
second method of its name now leaves ambiguous, and 30 arriving are right. Of the reference engine's pairs, 513 that
`main` shares leave: 452 `min`, 34 `writeFile` of a local alias bound to a code generator's table, 13 `get`, and 14
others, among them right member calls such as `psn.profile.listFriends()` whose free namesake became a method. A
function that a slot binds, `{ f = @() 1 }`, stays free. Owned as well, it moves 1,392 more functions under an owner,
and 154 pairs leave, 22 of 30 sampled right: a module returns such a table, and an importer calls its slots by the
bare names a `from` import takes, which reach no member of a table; 358 pairs arrive, 25 of 30 sampled right. A
non-function file-scope `let`, `let TOP = 1`, declares no symbol, as before: the tree holds about 35,000 such
declarators beside its 104,217 Quirrel symbols, 21,970 of them a call's result such as a `require`, and naming them is
a decision of its own.

**Revised 2026-10-23: a call through a parameter or a local is no call, unless the file defines the name.** A bare
call of a name that a parameter, a `catch` or `foreach` variable or a `let`/`local` of an enclosing function declares
calls whatever value the name holds, and the name tiers bound it to any namesake: `cb?(res)` in
`doPurchase(name, cb = null)` bound a table slot of another script's window. Such a call is not recorded,
unless the file defines a free function or a class of the name, which is most often the value the file passes; a local
that destructures a table, `let { build } = cfg`, takes the slot of its name and keeps its call. On the game-engine
tree 2,872 calls of 1,213 scripts leave the extraction, and no symbol, use, directive or file of another language
changes. 403 caller-callee pairs leave, none added; of 30 sampled, 23 were wrong and 7 bound the very function a caller
passes in, such as the `reply` that a module `api.nut` hands its handlers. The reference engine holds 224 of the 403.
Measured beside it:

- Every local and parameter, nested functions included: 2,288 pairs leave, 1,717 of them within the file, where the
  call of a nested `function helper() {}` binds right.
- Every local and parameter but the ones a function or a class binds: 845 leave, 20 of 30 sampled wrong.
- The same, a destructured local keeping its call: 562 leave, 23 of 30 wrong, 159 of them within the file, where 24 of
  30 sampled bound the definition the file passes.
- The rule as taken, a destructured local dropping its call too: 170 more leave, 13 of 30 wrong, the rest a factory's
  or a module's slot of that name, `let { setTags } = mkTags(name)`.

**Revised 2026-10-23: the runtime methods name the game engine's native values.** ADR 3.7 keeps a member call of a
runtime method off free functions. Quirrel's list named only the built-in types, so a member call on a native value
the engine hands its scripts bound a free namesake: `uiColor.get()` on a watched state the free `get` of
a state script, `blk.setFrom()` a table slot of the controls scripts, `obj.getScene()` an editor's `getScene`. The
list takes the methods the engine binds from its sources: `Watched`, `Computed` and `NativeWatched` from
`prog/gameLibs/quirrel/frp/frp.cpp`, `DataBlock` from `prog/gameLibs/quirrel/bindQuirrelEx/sqratDataBlock.cpp`, the
entity manager and templates from `prog/gameLibs/ecs/scripts/sq/sqcoredaECS.cpp`, and the GUI object a game binds. It leaves out `isEmpty`, `isEqual`, `isValid`, `isVisible`,
`isEnabled`, `getName`, `getTypeName` and `size`, which the scripts' own helper modules and classes define and call
through members: 94 of 96 `isEmpty()` pairs the full lists unbind are `u.isEmpty()` of the scripts' helper module.
On the game-engine tree 4,556 pairs leave and 18 arrive, members of an included class such as `PanelSettings.setValue`
that a call on the GUI object a game binds reaches; the watched state's methods take 3,243 of them, every one of 60 sampled wrong, and
the other values 1,313, 27 of 30 sampled wrong. Of the 30 sampled over all, 29 were wrong. The reference engine holds
3,854 of the 4,556 and none of the 18. With the full lists the other values unbind 1,766 pairs, 31 of 40 sampled
wrong. With both revisions `find_unused` reports 10,483 Quirrel definitions for 9,596, the free `get` and `set` among
them, and the parity plan's answers differ in 153 calls, every one of them a Quirrel answer. With 8 threads the
tree builds in 4.10 s warm against 4.09 s and 20.0 s cold against 19.5 s, within the spread of either side, with 1,101
MiB resident against 1,104 MiB.

**Revised 2026-10-23: Squirrel's `extends` is no use.** Quirrel writes a base as `class C(B)`; its grammar reads
Squirrel's `class C extends B {}` as names inside an ERROR, each of which was a use, `extends` included. An `extends`
inside an ERROR records nothing, and the base stays a use. No script of the game-engine tree, nor of the other Quirrel
trees checked, writes the form, so no extraction changes on them; dropping every name inside an ERROR instead would
drop the base too, and 101,182 uses of 37 deliberately broken scripts of the compiler's test data.

**Revised 2026-10-23: the compiler's test data is test code.** The Quirrel compiler keeps its test scripts under
`testData/`, 845 files on the game-engine tree, and AssetViewer's `Tests/` holds a script that registers its test
cases. Neither directory was named, so their stubs counted as product code and bound the game scripts' calls of their
names: of the 1,533 pairs from outside `testData/` into it, 1,217 callers took the stub of `Computed`, 109 of `Point2`
and 83 of `cos`. The rule names both as they are spelled, beside `test` and `tests`, and still matches no substring, so
`latestData/` stays product code. It marks 2,521 more definitions as test code, 2,515 under `testData/`, and alone moves
no pair, since those stubs bound at the one callable of the name and the steps nearest the caller, which read no test
flag until ADR 3.7's revision of the same day. With that revision 1,528 Quirrel pairs leave, 1,526 at the one callable
and 2 at the parent directory, and none arrive; each of 30 sampled binds a stub of a native, `Computed`, `Point2`,
`get_setting_by_blk_path` or `math.min`. Leaving the test definitions out of those tiers instead binds 6,004 others,
5,885 of them `loc()` calls taking outerSpace's own `loc` for the native localizer.

## Considered Options

- **Every `.sqconfig` above the script merged** — finds more files, and some of them the tooling never loads for that
  script, which is a wrong edge.
- **Shape fallback under a governing config** — resolves specifiers the config does not mount, again to files the
  tooling would not load.
- **A function value named by its own name or by its position** — the name no caller writes, so calls never meet it.
- **Case-insensitive matching through a scan of every file** — a pass over the tree per resolver for the few
  specifiers that differ only in case.
- **A lookup without case for the guessed form too** — no include gained on that tree, and a match in another case
  under a guessed mount is a guess on a guess.
- **A module table that owns its slot-bound functions too** — loses the bare calls an importer makes of a module's
  API, about 110 right pairs on that tree, for 358 pairs at 25 of 30 right.
- **A table member owned but kept a free function in kind** — binds exactly as a method does, since the owner and not
  the kind keeps a bare call away.
- **No use for any name inside an ERROR** — drops the base of `class C extends B` with the keyword.
- **No call through any local or parameter** — drops the same-file calls of nested functions and of the definitions a
  file passes as an argument, mostly right.
- **A destructured local as a value** — drops the slots a factory or a module hands out by name, more right than wrong.
- **Every method the engine binds on those values** — unbinds the scripts' own helpers of a shared name,
  `u.isEmpty()` among them, at 31 of 40 sampled wrong for the values beside the watched state.

Revisit when a script tree mounts its roots somewhere other than a `.sqconfig`, or when a script no `.sqconfig` governs
names a file in another case alone.
