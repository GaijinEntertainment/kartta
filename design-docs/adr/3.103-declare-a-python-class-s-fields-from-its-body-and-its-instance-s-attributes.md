# Declare a Python class's fields from its body and its instance's attributes

- **Status:** accepted
- **Date:** 2026-10-16
- **Updated:** 2026-10-18
- **Initiative:** `03-code-graph`
- **Governs:** `crates/kartta-lang-python/src/walk.rs` (`assignment`, `OwnReceiver`, `attribute_assignment`,
  `declare_attributes`)
- **Pinned by:** `crates/kartta-lang-python/tests/extract.rs`

A Python class declares most of its data where `__init__` assigns `self.size = size`, not in its body, and a read or a
write of an attribute ([ADR 3.34](./3.34-record-each-read-and-write-of-a-field-or-a-value.md)) needs a field to bind to.
The Python walk ([ADR 3.12](./3.12-qualify-python-by-the-module-its-path-names.md)) declares a field for each name a
class body assigns and each attribute a method assigns on its instance, at the cost of fields that are state rather than
declared data.

## Decision

1. A class body's assignment to a bare name is a field of the class, `name: str = ""` and `count = 0` alike, the first
   name of a chain alone, as at module level.
2. An attribute that a method assigns on its first parameter, whatever its name, is a field of the class around the
   method, and so is one that a function or a lambda nested in the method assigns on that name. A static method has no
   such parameter. A nested function's or lambda's parameter of that name, or a binding of the name in the method or a
   scope inside it before the assignment, a `nonlocal` declaration aside, hides the receiver.
3. Each such attribute is declared once, at its first assignment, after the members of the class body, so a method, a
   property or a class-body field of the name keeps its symbol. The members of two classes of one name, local to two
   functions, stay apart.
4. An augmented assignment declares nothing: it reads the attribute first, which a class body, a base or a plain
   assignment declares.

## Why

- With annotated attributes alone, most of a class's data had no symbol, so "who sets this attribute" had no answer: on
  the 1,215 Python files of the game-engine tree the fields grow from 721 to 4,571 with these rules (2026-10-18).
- The first parameter is the instance however a method names it, and a function nested in the method reaches it
  through the same name.

## Consequences

- A call through such an attribute, `self.items.append(1)`, stays a member call that binds nothing, and its miss
  counts as a name the graph does not admit as a callee rather than an undefined one: 4,170 calls on the game-engine
  tree (2026-10-18). Accepted.

## Rejected

- **Annotated class attributes alone** — the annotation declares the fields of a dataclass or a pydantic model, but a
  class's other data lives in its methods' assignments and had no symbol.

## Revisit if

A consumer needs a field to tell declared data from state a method keeps. None asks.
