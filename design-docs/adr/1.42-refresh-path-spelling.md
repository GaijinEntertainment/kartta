# Refresh a path under the name the disk holds

- **Date:** 2026-10-20
- **Governs:** `crates/kartta-fs/src/spelling.rs`, `crates/kartta-fs/src/index/scoped.rs` (`Index::respelling`,
  `Rewalk::on_disk`)
- **Pinned by:** `crates/kartta-fs/tests/refresh.rs`
  (`a_path_spelled_in_another_case_refreshes_the_entry_the_disk_holds`,
  `every_name_of_a_path_spelled_in_another_case_takes_the_disk_s_spelling`,
  `a_path_in_either_unicode_normalization_form_refreshes_the_entry_the_disk_holds`,
  `a_rename_that_changes_only_case_leaves_the_new_spelling_alone`,
  `paths_that_differ_only_in_case_stay_apart_where_the_disk_holds_both`)

A volume that folds case finds an entry by a name in another case than the one it holds, while the index holds each name
as the walk listed it and looks a path up byte for byte. A path named to `Index::refresh_paths`
([ADR 1.16](/design-docs/adr/1.16-scoped-refresh.md)) in another spelling therefore takes the name the filesystem
answers for it, on macOS and Windows, at one call per part a call asks about. Linux takes a path as spelled.

## Decision

- **Respelling a part.** On macOS and Windows, a part the index does not hold takes the name the filesystem answers for
  it, and the path so respelled widens again as [ADR 1.16](/design-docs/adr/1.16-scoped-refresh.md) widens a path. Each
  of its names is respelled at most once. So `dir/f.rs` refreshes an indexed `Dir/f.rs`.
- **A part under another name is gone.** A part the walk finds on disk under another name than its own is gone, as a
  part no longer on disk is, so a rename that changed only a name's case leaves the new name alone.
- **How the filesystem answers.** macOS answers through `getattrlist` with `ATTR_CMN_NAME`, which names the entry the
  lookup found, a hard link by its own name, in the Unicode normalization form the volume holds, so a path in the other
  normalization form takes the disk's form too. Windows answers through `FindFirstFileExW`.
- **Once a call.** A part is asked once a call however many paths come to it; `Index::parts_of` answers the same parts.
- **Linux** takes a path as spelled.
- **Case-sensitive volumes.** A volume that keeps case apart answers each name as spelled, so `Dir/f.rs`, `dir/f.rs`
  and a new `DIR/f.rs` stay three entries, as a build makes them.

## Why

- A path in another case matched nothing the index held, widened to the first name it spelled otherwise, and the walk
  took that name as spelled, so the index held a second copy of everything below it: a file named through
  `flightModels/WeaponPresets/` for `weaponPresets/` added 12,177 entries on the game-engine checkout (2026-10-20,
  #257).
- A rename that changes only case is reported by `FSEvents` with the old name beside the new one, and the old name still
  finds the entry; only the disk's own answer tells the two apart.
- One `getattrlist` took 1.1–1.8 µs on macOS, about an lstat of the same file (2026-10-20, #257).
- A Linux volume folds case only in a directory that opts into it or on a mount of a folding volume, and no call there
  answers a name short of listing the directory.

## Consequences

- A part found on disk costs one more call to the filesystem, and a part the index does not hold a second (accepted).
- On Linux, a path spelled in another case on a folding volume still makes a second copy (accepted).
- The Windows cost was not measured (accepted).

## Rejected

- **Compare folded names in the index on a volume that folds** — asks nothing for a part the index holds, but a part it
  does not hold scans its parent's entries, 557 µs against 186 µs for a new file in a directory of 12,176 files; its
  fold is not the volume's, so a name in the other normalization form still makes a second copy, a case-only rename
  keeps the old name, and it has to learn which volumes fold.
- **Ask `realpath` or `F_GETPATH`** — `realpath` answers every name of the path and follows a final symlink, and
  `F_GETPATH` needs the entry opened; each costs several times the one name `getattrlist` answers.

## Revisit if

A consumer on Linux follows a tree on a volume that folds case. Medium confidence: no consumer is known to, and the
folding cases there are opt-in directories and mounts of foreign volumes.
