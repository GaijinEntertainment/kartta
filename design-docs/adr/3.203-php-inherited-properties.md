# Read a PHP property a class's own body leaves open up its parents at resolve time

- **Date:** 2026-11-01
- **Governs:** `crates/kartta-lang-php/src/walk.rs` (`name_field_receivers`, `name_field_types`),
  `crates/kartta-graph/src/scope.rs` (`class_of_an_inherited_field`), `Receivers::InheritedFields`
- **Pinned by:** `crates/kartta-languages/tests/php_property_receivers.rs`,
  `crates/kartta-lang-php/tests/field_classes.rs`

A call on a property a parent or a trait declares names no class its file can read, so it took the name tiers, which
bound the caller's own member, a namesake or nothing. A file's walk cannot read another file, so the walk marks the call
and leaves each property's class on its symbol, and the graph reads the class up the parents at resolve time, at the
price of a walk per marked call.

## Decision

- **The mark.** Where the table of [ADR 3.202](/design-docs/adr/3.202-php-property-classes.md) holds nothing of the name
  and the class has parents, the walk spells the receiver `->name`. A property the table says none of keeps the empty
  receiver: a type that names no class, or a write of no class in the class's own body.
- **The value type.** Each declared property the table gives a class holds it as its value type. The declaration answers
  whether a type or the writes in its own class's body gave the class, so a parent's writes read as ADR 3.202 reads a
  class's own.
- **The spelling.** `self` and `parent` become the classes they name where the property is declared. `new static` stays
  `static`. `self` and `parent` of a trait give none, and neither does an anonymous class written to a property, which
  its file alone names.
- **The read.** The graph takes the nearest type that declares a field of the name, from the caller's class up through
  its traits and then the class it extends, and its value type becomes the receiver, so the call binds as one on an own
  property does. A `self::$name` and a `$this->name::m()` are read the same way.
- **What answers nothing.** The empty receiver stays where the nearest declaration holds no class, whatever stands above
  it, where that declaration is `private` to a type above the caller's class, and where no type of the graph declares
  the name. A `private` property of a trait the caller's class uses, directly or through another trait, answers.

## Why

- A class holds its parents' properties in its own table, so the nearest declaration is the property, and a child
  redeclares a typed one with the same type alone (`do_inherit_property`, `Zend/zend_inheritance.c`). A parent's
  `private` one takes the dynamic path in the child and reads as undefined (`zend_get_property_offset`,
  `Zend/zend_object_handlers.c`). A trait's is copied into the class that uses it (`zend_do_traits_property_binding`,
  `Zend/zend_inheritance.c`), so one a parent uses stays that parent's. All read at php-src 8.5.12 and run on
  `php:8.5.12-cli`.
- `new static` makes the class of the object it runs on, which a read on `$this` calls too: a parent's `new static` run
  on a child read the child's method on the image.
- The graph walks a class's parents at resolve time already, and a field symbol has a value type, so the read takes no
  new record kind and no pass.
- On Laravel and Symfony the read adds 2,131 pairs, removes 165 and promotes 644 to 85, from a census of 3,177 sites.
  All of 30 sampled added, of 30 more off the dominant target and of 30 moved are right; 27 of 30 removed are, and the
  other 3 bound an implementor of the declared interface (2026-11-01, #924).

## Consequences

- A write that names no class in the child leaves the empty receiver though a parent's type holds the class: 43 sites
  below a typed parent and 13 below a written one on the two trees, since the graph does not tell a typed value type
  from a written one (2026-11-01, #963).
- The read follows declarations, so a class between the declaration and the caller that writes the property goes unread
  and the call binds the declaration's class, a false edge where the two differ, as Laravel's `Command` writes the
  `$output` its trait declares. A property a parent writes and never declares holds no symbol, so a child's call on it
  keeps the empty receiver. Neither is counted (#964).
- A trait's method reading a property the using class declares reads nothing, as a trait names no class below it: 275
  sites on the two trees (2026-11-01, #962).
- A Symfony build and resolve goes from 124.87 G to 124.96 G instructions and from 137.09 G to 137.28 G, and from
  60.20 MB to 60.32 MB of heap at its peak, for the value types, the longer receivers and a walk per marked call
  (2026-11-01, #924). Accepted.

## Rejected

- **`parent::$c` and `Other::$c` through this read** — the 0 and 5 sites on the two trees are those #930 measured, so a
  spelling of a starting class serves none of them (2026-11-01, #924).
- **`static` as the class that declares the property** — the child's method answers a read on `$this`, and the keyword
  names it where the declaring class would bind the parent's.
- **A stop past a declaration with no class** — a child's `protected $c;` shares the slot a parent writes, but none of
  the sites on the two trees reaches a class of the graph through one (2026-11-01, #924).

## Revisit if

The graph tells a declared type from a written class, which would answer the 43 sites below a typed parent. High
confidence for a declared type, medium for the writes.
