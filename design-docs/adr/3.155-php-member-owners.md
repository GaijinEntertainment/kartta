# Own a PHP member by its type's bare name

- **Date:** 2026-10-16
- **Governs:** `crates/kartta-lang-php/src/walk.rs` (qualification, `call_target`, `closure_binding`,
  `object_creation`), `crates/kartta-lang-php/src/lib.rs` (`Conventions`)
- **Pinned by:** `crates/kartta-lang-php/tests/php.rs` (`every_declaration_is_qualified_by_its_namespace`,
  `a_qualified_scope_is_the_receiver_of_its_last_segment`, `a_qualified_function_call_calls_its_last_segment`,
  `a_construction_calls_the_class_by_its_bare_name`, `a_bare_call_reaches_no_member_of_its_own_class`,
  `a_closure_bound_to_a_variable_makes_the_calls_in_its_body`),
  `crates/kartta-languages/tests/php_own_receivers.rs` (`a_php_call_on_a_variable_binds_no_class_constant_of_its_name`,
  `a_php_constant_is_no_call_s_target_through_any_receiver`)

After a `use`, a PHP static call names its class by the bare name, `Service::make()`. A member is qualified by its
namespace and owned by its type's bare name, so that receiver names its owner without the file's `use` map, at the
cost of one owner for two classes of one name in different namespaces.

## Decision

- **Qualification and owner.** A declaration is qualified by the namespace in effect, `App\Service`, and a member by
  its type as well, `App\Service::greet`. The member's owner is the type's bare name, `Service`.
- **Qualified names in calls.** A qualified scope, `\App\Service::make()`, records its last segment, `Service`, as the
  receiver, so that it names the same owner. A qualified function call, `\App\run()`, and a construction,
  `new \App\User()`, call the last segment of the name, but for a construction of an alias
  ([ADR 3.14](/design-docs/adr/3.14-php-includes.md)); `new self`, `new static` and `new parent`, in any case, call
  nothing.
- **Bare calls.** A bare call never reaches a method of its own class (`OwnMembers::Unreached`).
- **Constants.** A call binds no constant, class or global, whatever its receiver (`values_are_call_targets` is off).
- **Closures.** A closure assigned to a variable, `$f = function () {}`, is a callable named by the variable, which
  makes the calls in its body. A closure passed as an argument is not, and the calls in its body are calls of the
  callable around it.
- **Anonymous classes and outside classes.** The name of an anonymous class, which owns its members too, is
  [ADR 3.156](/design-docs/adr/3.156-php-anonymous-classes.md). What a static call on a bare name that no class of the
  graph is named binds is [ADR 3.167](/design-docs/adr/3.167-php-outside-class-calls.md).

## Why

- The bare name is what a static call writes as its receiver after a `use`, so a member owned by it binds that call
  with no lookup of the caller's imports.
- PHP calls a method of the caller's own class only through `$this`, `self` or `static`, so a bare call that reached
  one would be a wrong edge.
- PHP looks a call's name up in a function table, a class's or the global one, and never among constants
  (`zend_std_get_method`, `zend_std_get_static_method`, `ZEND_INIT_NS_FCALL_BY_NAME`). A closure a constant holds runs
  as `(C::F)()`, whose callee is an expression and no name. So every pair on a constant is wrong, and the constant also
  stands beside the method the call means: all 4 such pairs on Symfony and Laravel were wrong, and the 6 the rule adds
  in their place, as `$test->preFoo()` to the listener, are right (2026-11-01, #795).
- A closure passed as an argument runs as part of the call around it, while one assigned to a variable is called by
  that name.

## Consequences

- Two classes of one name in different namespaces share an owner, so a call on that name can bind a member of either.
  Accepted.

## Rejected

- **An owner qualified by its namespace, `App\Service`** — a static call writes the bare name after a `use`, so the
  receiver would name no owner without resolving the file's imports.
- **Dropping the constant in `member_of_the_caller_s_owner` alone** — a constant also binds at 80 as the same file's one
  member of the name, a tier that runs before that one (#795).

## Revisit if

Two classes of one name in different namespaces join their members on a real tree. Not seen yet.
