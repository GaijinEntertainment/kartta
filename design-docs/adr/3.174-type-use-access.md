# Mark a use as a type apart from a read

- **Status:** accepted
- **Date:** 2026-10-23
- **Updated:** 2026-10-23
- **Initiative:** `03-code-graph`
- **Governs:** `kartta_lang::Access::Type`, the walks of `kartta-lang-go` and `kartta-lang-python`,
  `Graph::references` (`SiteQuery` access)
- **Pinned by:** `crates/kartta-lang-go/tests/extract.rs`
  (`a_type_named_in_a_declaration_or_a_composite_literal_is_a_use_as_a_type_and_in_a_conversion_a_call`),
  `crates/kartta-lang-python/tests/extract.rs`
  (`an_annotation_or_a_base_names_a_type_as_one_and_a_member_taken_through_a_class_reads_it`)

A type is named by a declaration and read by code that takes a member through it, and only the walk tells the two
apart. A use as a type is the fourth access of a use of
[ADR 3.34](/design-docs/adr/3.34-field-and-value-uses.md), apart from a read, so an agent reads which
sites take the type as a value; the languages that record no declaration's type mark none.

## Decision

- A use as a type reads no value. Go records each type its declarations, composite literals, allocations, conversion
  operands and type arguments name as a use as a type, and Python each name inside an annotation or a class's bases.
  Every other language records a type only where code reads it, as a read: `EventType.Created` reads `EventType`.
- A site carries its access, so a read and a use as a type on one line are two sites. `Graph::references` keeps the
  uses as a type among the readers, and an access filter of its own keeps them alone; its answer counts them apart
  from the reads ([ADR 3.175](/design-docs/adr/3.175-data-references-by-access.md)).

## Why

- Only the walk knows whether code named a type or read it: of 78 sampled sites that `find_references` had marked
  `type` and marks `read` on the C++ game-engine tree and the Go monorepo, 75 read the symbol (2026-10-23).
- The fourth access takes the access bits' free value, so a use costs nothing more.

## Consequences

- A Go type argument of a generic function taken without a call, `errorIs[*pkg.T]`, reads as an index and is recorded
  as a read. Accepted.

## Rejected

- **A type's every site outside a call taken as a use as a type** — marks `EventType.Created` and a class passed as a
  value as uses as a type, as 75 of the 78 sampled sites were.
- **The language's `TypeUses` deciding the mark** — Python records an annotation and a read of a class alike, and all
  31 of its sampled sites read the class.

## Revisit if

A third language's walk records the types its declarations name, and its sites of a type split otherwise than reads
and uses as a type. Medium confidence.
