# Mark a use as a type apart from a read

- **Date:** 2026-10-23
- **Governs:** `crates/kartta-lang/src/extraction.rs` (`Access`), `crates/kartta-lang-go/src/walk.rs`,
  `crates/kartta-lang-python/src/walk.rs`, `kartta_lang::Access::Type`, `Graph::references` (`SiteQuery` access),
  `crates/kartta-graph/src/stats.rs`
- **Pinned by:** `crates/kartta-ffi/tests/dispatch.rs` (`access_keeps_the_uses_as_a_type_alone_or_among_the_reads`),
  `crates/kartta-lang-go/tests/extract.rs`
  (`a_type_named_in_a_declaration_or_a_composite_literal_is_a_use_as_a_type_and_in_a_conversion_a_call`,
  `a_type_argument_of_an_uncalled_generic_function_is_a_use_as_a_type`, `an_index_of_a_slice_or_a_map_reads_its_index`),
  `crates/kartta-lang-python/tests/extract.rs`
  (`an_annotation_or_a_base_names_a_type_as_one_and_a_member_taken_through_a_class_reads_it`,
  `a_call_in_an_annotation_or_in_a_list_of_bases_reads_the_names_around_its_callee`)

A type is named by a declaration and read by code that takes a member through it, and only the walk tells the two
apart. A use as a type is the fourth access of a use of [ADR 3.34](/design-docs/adr/3.34-field-and-value-uses.md),
apart from a read, so an agent reads which sites take the type as a value; the languages that record no declaration's
type mark none.

## Decision

- **A use as a type reads no value.** Go records each type its declarations, composite literals, allocations,
  conversion operands and type arguments name as a use as a type, and Python each name inside an annotation or a
  class's bases outside a call: a call there is an expression, so its arguments and the path to its callee are reads.
  Every other language records a type only where code reads it, as a read: `EventType.Created` reads `EventType`.
- **A Go type argument outside a call.** `errorIs[*pkg.T]` parses as the index of a value, so outside a call an index is
  a type argument only as what a value's index does not spell, on a name no local and no `var` or `const` of the file
  binds: a list of two or more, a type's syntax, an instantiation of one of these, a name the file declares as a type,
  or a pointer to such a name or to a selector. A bare name on an imported name, `pgx.RowToStructByName[Row]`, is one
  too. Any other index is read.
- **One access a site.** A site carries its access, so a read and a use as a type on one line are two sites.
  `Graph::references` keeps the uses as a type among the readers, and an access filter of its own keeps them alone; its
  answer counts them apart from the reads ([ADR 3.175](/design-docs/adr/3.175-data-references-by-access.md)).
- **On every surface.** The MCP answer and the wire spell the access `type` and count it as `types`, both take it as a
  filter, and `Stats` counts it apart from `reads`.

## Why

- Only the walk knows whether code named a type or read it: of 78 sampled sites that `find_references` had marked
  `type` and marks `read` on the C++ game-engine tree and the Go monorepo, 75 read the symbol (2026-10-23, #278).
- The fourth access takes the access bits' free value, so a use costs nothing more.
- A Blender property is a call in an annotation, `x: EnumProperty(items=options)`, and passes values: 69 of the 2,164
  Python uses as a type on the game-engine tree sat in such a call, 30 of 30 sampled reads (2026-10-31, #792).
- An index outside a call is mostly a value's: the rule moves 229 uses on the Go monorepo snapshot, all type arguments,
  212 of them `pgx`'s row functions, where the test a call applies moves 695 (2026-10-31, #530).

## Consequences

- A Go type argument spelled as a selector outside a call, `errorIs[pkg.T]` or `pgx.RowTo[pkg.T]`, has the tree of a map
  keyed by a constant and is recorded as a read. A sibling file's constant keying an imported map, `pkg.Table[key]`, is
  recorded as a use as a type. Accepted.
- A name in any other expression a Python annotation holds stays a use as a type, the test of `x: A if ready else B`
  included, and a class a call in a list of bases takes is a read, `class Hub(with_metaclass(HubMeta))`. Accepted.

## Rejected

- **A type's every site outside a call taken as a use as a type** — marks `EventType.Created` and a class passed as a
  value as uses as a type, as 75 of the 78 sampled sites were.
- **The language's `TypeUses` deciding the mark** — Python records an annotation and a read of a class alike, and all
  31 of its sampled sites read the class.
- **The test a call applies to its index, outside a call** — takes a constant keying a map for a type: 7 of 7 bare
  operands outside the vendored code indexed a sibling file's map, and `Providers[catalog.DeepSeek]` is the selector's
  common shape.
- **The wire folding a use as a type into a read** — it says less than the engine and the MCP answer, and moving a
  `read` to `type` later breaks every wire consumer.

## Revisit if

A third language's walk records the types its declarations name, and its sites of a type split otherwise than reads
and uses as a type. Medium confidence.
